# Implement StatusService

Read-only projection of run state + open-finding counts for the `status` command. Must not mutate state (VR-008).

## Acceptance Criteria

- `get_status()` returns current phase, iteration, open-findings count, last gate result, and run mode.
- When no run exists, reports idle.
- Never writes to RunStateStore or FindingsStore.
- Unit tests with stub stores confirming read-only behaviour and correct projections.
