# Implement FindingIngest mappers

Map raw output from the two finding sources to the Finding DTO:

1. **spec-lint mapper**: parses `spec-lint --format json` output (array of `{code, severity, artifact, message}`) and maps each to a Finding, stamping `id`, `phase`, `iteration`, `source=spec-lint`.
2. **semantic mapper**: parses reviewer agent output (structured finding blocks from `inspect-spec`) and maps each to a Finding with `source=semantic`.

The orchestrator stamps `id` (monotonic allocator), `phase`, and `iteration`; sources never mint IDs (VR-007).

## Acceptance Criteria

- `map_spec_lint(json_output, phase, iteration)` returns a list of Finding entities.
- `map_semantic(reviewer_output, phase, iteration)` returns a list of Finding entities.
- All returned findings have `status=open` and valid fields per schema.
- Unit tests with fixture outputs covering both mappers, including edge cases (empty output, malformed).
