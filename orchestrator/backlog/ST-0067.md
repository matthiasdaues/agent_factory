# De-symlink and merge root .pre-commit-config.yaml with orchestrator's dev hooks

Root `.pre-commit-config.yaml` is currently a symlink to
`factory/config/pre-commit-config.yaml` — generic hooks
(mdformat/ruff-check/ruff-format via `uvx`, plus spec-lint/arch-lint/
backlog-lint/matrix-lint/statemachine-lint/index-lint pointed at
root-level paths that don't exist yet in this repo).
`orchestrator/.pre-commit-config.yaml` has its own scoped dev hooks
(mdformat/ruff-check/ruff-format via `uv run --project orchestrator`, plus
arch-lint/backlog-lint/matrix-lint/statemachine-lint pointed at
`orchestrator/docs`, `orchestrator/backlog`, `orchestrator/model-matrix.conf`
— but using stale bare `scripts/` entry paths). Neither config alone covers
both halves of the repo correctly. Merge them into one real file at the
root.

**Priority:** must-have

## Analysis

This story has no application-code seam — the output is a config file, so
"implementation" means a one-time manual merge of two `.pre-commit-config.yaml`
sources into the root file, per the acceptance criteria.

- Removed the root symlink (`.pre-commit-config.yaml` -> `factory/config/ pre-commit-config.yaml`) and wrote a real file in its place.
- Copied `factory/config/pre-commit-config.yaml` verbatim except adding
  `exclude: ^orchestrator/` to `mdformat`, `ruff-check`, `ruff-format`. The
  other four root-generic hooks (`spec-lint`, `arch-lint`, `backlog-lint`,
  `matrix-lint`, `statemachine-lint`, `index-lint`) are untouched — still
  root-scoped and inert.
- Appended `orchestrator/.pre-commit-config.yaml`'s hooks with `-orchestrator`
  suffixed ids. `mdformat-orchestrator`/`ruff-check-orchestrator`/
  `ruff-format-orchestrator` keep their `uv run --project orchestrator ...`
  entries unchanged (never referenced `scripts/`, so nothing stale there) and
  gain `files: ^orchestrator/` (the dev config had no `files:` filter on
  these three, only `types`/`types_or`).
  `arch-lint-orchestrator`/`backlog-lint-orchestrator`/`matrix-lint-orchestrator`/
  `statemachine-lint-orchestrator` keep their existing `files:` patterns
  unchanged (already `orchestrator/`-prefixed in the dev config) but their
  `entry:` is fixed from the stale bare `scripts/<name>` to `factory/scripts/ <name>`, matching the root generic hooks' own `python3 factory/scripts/ <name> ...` invocation style (judgment call: kept the `python3` prefix for
  consistency with the sibling non-orchestrator hooks in the same file,
  rather than relying on the scripts' executable bit).
- Added the new `spec-lint-orchestrator` hook (orchestrator's dev config had
  none). Judgment call: the acceptance criteria's literal entry string
  (`factory/scripts/spec-lint orchestrator/docs/spec`) doesn't match
  `spec-lint`'s actual CLI, which takes `--spec-dir` as a flag (default
  `docs/spec`), not a positional argument — used `python3 factory/scripts/ spec-lint --spec-dir orchestrator/docs/spec` instead so the hook actually
  runs, consistent with how `statemachine-lint-orchestrator` passes the same
  directory via `--spec-dir`.

## Acceptance Criteria

- Root `.pre-commit-config.yaml` is a real file, not a symlink (the
  symlink to `factory/config/pre-commit-config.yaml` is removed).
- The three generic hooks (`mdformat`, `ruff-check`, `ruff-format`) gain
  `exclude: ^orchestrator/` so they stop double-touching orchestrator's
  files with the wrong (unpinned) tool versions.
- Orchestrator's hooks are appended with namespaced ids —
  `mdformat-orchestrator`, `ruff-check-orchestrator`,
  `ruff-format-orchestrator`, `arch-lint-orchestrator`,
  `backlog-lint-orchestrator`, `matrix-lint-orchestrator`,
  `statemachine-lint-orchestrator` — each scoped with `files: ^orchestrator/`
  (or the hook's existing tighter pattern re-prefixed with `orchestrator/`)
  and invoking `factory/scripts/<name>` (not bare `scripts/<name>`).
- A new `spec-lint-orchestrator` hook is added:
  `factory/scripts/spec-lint orchestrator/docs/spec`, scoped
  `files: ^orchestrator/docs/spec/` — orchestrator's dev config currently
  has no spec-lint hook at all.
- The root's existing generic (non-orchestrator-scoped) spec-lint,
  arch-lint, backlog-lint, matrix-lint, statemachine-lint, and index-lint
  entries are left untouched — still inert, reserved for whenever factory
  grows its own docs/backlog.
- `pre-commit run --all-files` (or a dry run against the merged config)
  runs without a config-parse error.
