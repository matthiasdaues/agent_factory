# Add --dry-run flag to phase advance

Add a `--dry-run` flag to `../factory/scripts/phase advance` that checks all entry conditions for the target state and exits 0/1 accordingly, without writing the marker.

## Acceptance Criteria

- `phase advance --dry-run` exits 0 when advance would succeed.
- `phase advance --dry-run` exits 1 when advance would fail.
- The marker file is byte-for-byte unchanged after `--dry-run`.
- Output reports pass/fail and condition names (same format as real advance).
