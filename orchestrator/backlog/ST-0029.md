# Update PhaseRunner for working-tree gate model

Refactor `PhaseRunner.run_phase()` to use the working-tree gate model:

1. **After author exits**: call `gate.verify(cwd, result.exit_code)` instead of `gate.run(artifacts, branch, phase)`.
2. **Confabulation detection** (VR-025): if `gate_result.hook == "confabulation"`, halt immediately.
3. **Clean tree before retry** (VR-026): if the gate reports dirty tree on failure, run `git checkout . && git clean -fd` before the next iteration.
4. **Remove staging/commit logic** from the gating section — agents commit their own work.
5. **Remove empty-commit detection** from the gate path — agents handle this internally.
6. **Remove gate output parsing/ingest** — pre-commit findings are no longer orchestrator-visible; they are resolved inside the agent subprocess.

This is the most complex change. The state machine structure (Authoring → Gating → Reviewing → RetryOrHalt) stays the same; only the gating implementation changes.

**Priority:** must-have

## Acceptance Criteria

- PhaseRunner calls `verify()` instead of `run()` on the gate
- Confabulation (exit 0 + dirty) halts the run
- Dirty tree is cleaned (`git checkout . && git clean -fd`) before retry
- Gate findings ingest removed (no more `ingest_gate_output`)
- Resume paths (GATING, REVIEWING) still work correctly
- State machine tests updated for the new gate contract
