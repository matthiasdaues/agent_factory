# Implement JsonRunStateStore and RunLock

Atomic read/write of `.orchestrator/run.json` (write-then-rename). Lock file for the single-run invariant (BR-017). Creates/selects the run branch.

## Acceptance Criteria

- `save(run_state)` writes atomically (temp file + rename), validates against RunState schema.
- `load()` returns the current RunState or None if absent.
- `exists()` returns whether a run.json is present.
- `RunLock.acquire(run_id)` creates the lock file with PID and start time.
- `RunLock.release()` removes the lock file.
- `RunLock.is_held()` returns True if a lock exists with a live PID.
- Stale lock (dead PID) is reclaimable with a warning (ATAM-R09).
- Unit tests covering: save/load round-trip, atomic write, lock acquire/release, stale lock reclaim.
