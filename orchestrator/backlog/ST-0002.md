# Define all core port interfaces

Extend the existing `ports.py` (which already has `CLIAdapter` and `InvocationResult`) with the remaining port protocols from ch5: `GateRunner`, `FindingsStore`, `RunStateStore`, `RunLock`, `AgentRegistry`, `PromptComposer`, `Logger`, `BacklogStore`, `ModelMatrix`, `Clock`.

Each port is a `typing.Protocol` with `@runtime_checkable`, minimal per Interface Segregation. Method signatures match the interface-contracts schemas.

## Acceptance Criteria

- All ports importable from `orchestrator.ports`.
- Each port is a Protocol with the methods the core calls.
- The existing `CLIAdapter` and `InvocationResult` are preserved unchanged.
- `GateRunner.run()` returns a `GateResult` entity.
- `FindingsStore` supports `ingest`, `supersede_prior`, `open_count`, `list_open`.
- `RunStateStore` supports `load`, `save` (atomic), `exists`.
- `RunLock` supports `acquire`, `release`, `is_held`.
- `AgentRegistry` supports `resolve(phase, role)` returning agent name + outputs.
- Unit tests confirm each port can be satisfied by a trivial stub.
