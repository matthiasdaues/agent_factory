# Implement the retry-or-halt branch

After dispatch, when `phase advance` fails (out-gate unmet): call `phase retry`. If retry succeeds, re-dispatch. If retry refuses (cap hit), halt with the FSM's escalation message.

## Acceptance Criteria

- Given phase advance fails after dispatch, when phase retry returns 0, then the same agent is re-dispatched.
- Given phase advance fails and phase retry returns non-zero, then run-playbook exits 1 with the halt_conditions message.
- Given the FSM declares max_iterations 3 and iteration is 3, the halt message includes the state name and iteration count.
