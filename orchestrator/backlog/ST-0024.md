# Implement call-to-action templates in FilePromptComposer

Update `FilePromptComposer.compose()` to accept `InvocationContext` and append a `# Call to Action` section as the final prompt block. Implement the five hardcoded f-string templates:

1. **Author, iteration 0**: "Begin the {phase} phase. Execute the workflow defined in your Agent Definition above, starting at Step 1."
2. **Author, iteration 1+**: "This is iteration {n} of the {phase} phase. Address the findings listed above, then re-execute your workflow."
3. **Reviewer, iteration 0**: "Review the {phase} artifacts. Follow the review workflow in your Agent Definition. File findings per the specified format."
4. **Reviewer, iteration 1+**: "This is iteration {n} of the {phase} review. The author has addressed prior findings. Re-review the artifacts and file any remaining issues."
5. **Standalone** (`run-step`): "Execute the workflow defined in your Agent Definition above."

**Priority:** must-have

## Acceptance Criteria

- `compose()` appends a `# Call to Action` section after findings (or after context if no findings)
- Each of the 5 templates is selected based on `InvocationContext.role`, `InvocationContext.iteration`, and whether context is standalone
- Templates are unit-tested: correct template selected for each combination
- Backward-incompatible: old `compose()` signature without `InvocationContext` no longer works
