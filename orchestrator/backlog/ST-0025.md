# Update PhaseRunner to pass InvocationContext to PromptComposer

Update all `self._composer.compose()` calls in `PhaseRunner.run_phase()` to construct and pass an `InvocationContext(phase, role, iteration)`. The author invocation uses `AgentRole.AUTHOR` and the reviewer invocation uses `AgentRole.REVIEWER`. The iteration is `phase_record.iteration`.

**Priority:** must-have

## Acceptance Criteria

- Author `compose()` call passes `InvocationContext(phase=phase_record.name, role=AgentRole.AUTHOR, iteration=phase_record.iteration)`
- Reviewer `compose()` call passes `InvocationContext(phase=phase_record.name, role=AgentRole.REVIEWER, iteration=phase_record.iteration)`
- Existing PhaseRunner tests updated to provide `InvocationContext`-aware mock composers
- No change to control flow — only the prompt content changes
