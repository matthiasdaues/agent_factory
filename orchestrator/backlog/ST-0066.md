# Fix stale scripts/ and model-matrix.conf paths in the init template

`orchestrator/pre-commit-config.yaml` (no dot) is the template copied into
new projects by a future `orchestrate init` — distinct from
`orchestrator/.pre-commit-config.yaml`, this repo's own dev config. Its
hooks currently reference bare `scripts/spec-lint`, `scripts/arch-lint`,
`scripts/backlog-lint`, `scripts/matrix-lint`, `scripts/statemachine-lint`
and a bare `model-matrix.conf`, matching the pre-pivot agent_hq layout.
Update it to match agent_factory's actual canonical conventions —
`factory/scripts/*` and `config/model-matrix.conf` — so this template
doesn't propagate a second stale `scripts/` copy into future projects.

**Priority:** should-have

## Analysis

Template YAML currently holds references to bare `scripts/` directory and bare `model-matrix.conf`, matching pre-pivot agent_hq layout. These paths do not match agent_factory's canonical structure:

- agent_factory places gate scripts at `factory/scripts/` (not root `scripts/`)
- agent_factory places model matrix at `config/model-matrix.conf` (not root)

Changes required:

1. Rewrite all gate script `entry` lines to use `factory/scripts/<name>` (5 hooks affected: spec-lint, arch-lint, backlog-lint, matrix-lint, statemachine-lint)
2. Update `matrix-lint` hook's `--matrix` argument from `model-matrix.conf` to `config/model-matrix.conf`
3. Update `matrix-lint` hook's `files:` pattern from `^model-matrix\.conf$` to `^config/model-matrix\.conf$`
4. Preserve mdformat/ruff entries and header comment as-is
5. Do not touch `orchestrator/.pre-commit-config.yaml` (dev config, separate file)

## Acceptance Criteria

- Every hook `entry` in `orchestrator/pre-commit-config.yaml` that invokes
  a gate script uses `factory/scripts/<name>` (e.g.
  `python3 factory/scripts/spec-lint`), not bare `scripts/<name>`.
- The `matrix-lint` hook's `--matrix` argument and `files:` pattern point
  at `config/model-matrix.conf`, not bare `model-matrix.conf`.
- `mdformat`/`ruff-check`/`ruff-format` entries are left as project-root-relative
  (`uv run mdformat`, `uv run ruff check --fix`, `uv run ruff format`) —
  those are not part of the stale-path bug and are out of scope here.
- The file's header comment ("paths are project-root-relative") stays
  accurate given the corrected paths.
- No other file changes — `orchestrator/.pre-commit-config.yaml` (the dev
  config) is untouched by this story.
