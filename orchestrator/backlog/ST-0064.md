# Flag ADR-0010 for supersession in the todos ledger

`orchestrator/docs/adr/0010-separate-tooling-from-project-directory.md`
describes the old agent_hq distribution model — a global clone,
`uv tool install`, symlinks into each project directory. That no longer
matches agent_factory's actual model, where `factory/` is copied wholesale
into a project by `init-factory`. The real shipping/distribution mechanism
for orchestrator hasn't been designed yet (out of scope for this round), so
ADR-0010 is not rewritten now — it is flagged as a todo for whenever that
design work happens. Depends on ST-0062: the ledger this entry is added to
lives at `orchestrator/docs/spec/todos.md`, which doesn't exist at that
path until the docs move lands.

**Priority:** could-have
