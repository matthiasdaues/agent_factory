# Implement PromptComposer

Composes the agent prompt from three sources: the agent definition file (resolved via AgentRegistry), project/root context (CONTEXT.md), and any open findings from the prior iteration. The composed prompt is what gets passed to `CLIAdapter.invoke()`.

## Acceptance Criteria

- `compose(agent, context_paths, findings)` returns a single prompt string.
- Includes the agent definition content.
- Appends project context (CONTEXT.md).
- When findings are provided, appends them as structured feedback for the author.
- When no findings, omits the findings section.
- Unit tests with fixture files covering: compose with findings, compose without, missing context file handled gracefully.
