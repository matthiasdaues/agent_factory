# Implement FileModelMatrix

Reads the operator-curated model-matrix.conf (facts + policy sections). Implements the `ModelMatrix` port that `ModelResolver` queries. Uses the same parser logic as matrix-lint.

## Acceptance Criteria

- `get_tier(classification_or_phase)` returns the tier for a given classification or phase name.
- `get_model(cli, tier)` returns the concrete model for a CLI and tier.
- `get_on_missing()` returns `halt` or `auto`.
- `configured_clis()` returns the set of CLIs with facts.
- Reuses the INI parser from matrix-lint (or shares the parsing logic).
- Unit tests covering: tier lookup, model lookup, on_missing, missing tier returns None.
