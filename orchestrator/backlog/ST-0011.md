# Implement PreCommitGateRunner

Stages the phase's declared artifact paths, commits on the run branch from a clean tree, runs `pre-commit`, and maps the result to a `GateResult`.

The critical logic is the **errored-vs-findings discriminator** (ATAM-R02/T-12): `pre-commit` returns non-zero for both a crash and findings. The runner distinguishes by output: parseable findings → `passed=false` (loop); traceback/no output → `errored=true` (halt).

## Acceptance Criteria

- Stages only declared artifact paths (VR-016).
- Commits against the run branch from a clean tree.
- Empty commit (unchanged artifacts) detected, returns `GateResult(passed=False, errored=False)` with a no-progress flag.
- Gate findings: parses hook output, returns `GateResult(passed=False, error_count=N)`.
- Gate error (traceback, missing tool): returns `GateResult(errored=True)`.
- Gate timeout: returns `GateResult(errored=True, timed_out=True)`.
- Gate pass: returns `GateResult(passed=True, error_count=0)`.
- Re-stages once for auto-fixing hooks (ext. 5c).
- Unit tests with a mock git/pre-commit covering all discriminator cases.
