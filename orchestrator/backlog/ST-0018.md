# Implement CLI entry point with argparse

The composition root: parse commands via stdlib `argparse` (ADR-0006), validate arguments, wire adapters to the core, own exit codes. Subcommands:

- `run-step <agent>` — single agent step (UC-01, FR-A1).
- `run-phase <phase>` — author↔reviewer loop (UC-02, FR-A2).
- `status` — report run state (UC-05, FR-A4).
- `resume` — continue interrupted run (UC-06, FR-A5).
- `approve` / `reject` — phase gate decision (UC-04, FR-A6).

Global flags: `--model`, `--adapter`, `--cap`. (`run-all` and the unattended `--yes` flag are deferred, NG6 — removed in ST-0061.)

## Acceptance Criteria

- Each subcommand parses and dispatches to the correct core component.
- `--model` is forwarded to the adapter / ModelResolver.
- Unknown commands print help and exit non-zero.
- Invalid agent/phase names are rejected before any subprocess (VR-011).
- Unit tests (or integration tests) covering argument parsing and dispatch for each subcommand.
