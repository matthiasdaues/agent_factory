# Add halted_from field to PhaseRecord

Add `halted_from: Optional[PhaseStatus] = None` to the `PhaseRecord` dataclass. Update `JsonRunStateStore` serialization/deserialization to persist this field. When `_halt()` sets `PhaseStatus.HALTED`, it must record the previous status in `halted_from` before overwriting.

**Priority:** should-have

## Acceptance Criteria

- `PhaseRecord.halted_from` field exists, defaults to `None`
- `JsonRunStateStore` serializes and deserializes `halted_from`
- Existing run.json files without `halted_from` load correctly (backward compat)
- `_halt()` in PhaseRunner sets `halted_from` to the current status before setting `HALTED`
