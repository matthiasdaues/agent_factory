# Implement MarkdownAgentRegistry

Parses `agents/*.md` front-matter to resolve each phase's author/reviewer and their declared `outputs`. Rejects an unknown agent name before any subprocess (VR-011, BR-011).

## Acceptance Criteria

- `resolve(phase, role)` returns agent name and list of output paths.
- Unknown agent name raises an error before any subprocess is launched.
- Parses YAML front-matter from agent markdown files.
- Maps the four phases to their correct author/reviewer agents per the phase model.
- Unit tests with fixture agent files covering: resolve happy path, unknown agent rejection, front-matter parsing.
