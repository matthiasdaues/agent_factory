# Implement release CLI command

Add the `release` subcommand to the CLI. It:

1. Loads the run state
2. Validates VR-029: `mode == halted` and `halted_from` is present
3. Restores `phase.status = halted_from`
4. Resets `phase.iteration = 0`
5. Sets `run.mode = paused`
6. Clears `halted_from`
7. Saves the run state
8. Reports the restored status to the operator

The operator then runs `resume` to continue.

**Priority:** should-have

## Acceptance Criteria

- `orchestrate release` restores the halted phase to its pre-halt status
- Iteration count is reset to 0
- Run mode changes from `halted` to `paused`
- VR-029 enforced: refuses if `halted_from` is absent or mode is not `halted`
- Integration test: halt → release → resume cycle works
