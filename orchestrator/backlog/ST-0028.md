# Update GateRunner port for working-tree verification

Update the `GateRunner` protocol in `ports.py` to match the working-tree gate model. Replace the `run(artifact_paths, branch, phase, timeout_s) → GateResult` method with `verify(cwd: Path, exit_code: int) → GateResult`. Keep `artifacts_changed()` for the resume path. Remove the `branch` and `timeout_s` parameters that the orchestrator no longer needs (agents own their commits).

**Priority:** must-have

## Acceptance Criteria

- `GateRunner` protocol has `verify(cwd: Path, exit_code: int) → GateResult`
- `artifacts_changed()` remains on the protocol
- Old `run()` signature is removed
- The docstring references ADR-0013
