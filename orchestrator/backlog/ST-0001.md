# Define domain entity dataclasses

Implement the pure-state domain entities from the entity model as frozen or mutable dataclasses: `Run`, `Phase`, `Iteration`, `Finding`, `GateResult`, `AgentInvocation`, `Approval`, `Story`. No I/O, no behaviour beyond construction and field access.

Each entity mirrors its schema in interface-contracts.md. `Finding` uses the JSON Schema fields; `GateResult` carries `passed`, `errored`, `timed_out`, `hook`, `error_count`; `Story` carries the StoryFrontmatter fields.

## Acceptance Criteria

- All entity classes importable from `orchestrator.entities`.
- Field types match the interface-contracts schemas exactly.
- Entities are pure data — no filesystem, subprocess, or network calls.
- Unit tests confirm construction, field access, and invalid-value rejection for enum fields.
