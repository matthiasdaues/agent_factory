# Implement abort CLI command

Add the `abort` subcommand to the CLI. It:

1. Loads the run state
2. Sets `run.mode = complete` (or a new terminal status)
3. Releases the run lock
4. Reports that the run has been aborted

This is the escape hatch for runs that cannot be recovered via `release` + `resume`.

**Priority:** should-have

## Acceptance Criteria

- `orchestrate abort` terminates the active run
- The run lock is released
- The run state reflects the aborted status
- Refuses if no active run exists
