# Implement --playbook, --cli, and --from-state arguments

Parse CLI arguments: `--playbook` (defaults to reading marker or greenfield-development), `--cli` (claude or copilot, default claude), `--from-state` (bootstrap marker at that state if no marker exists).

## Acceptance Criteria

- `--playbook bug-fix` uses bug-fix.fsm.yml.
- `--cli copilot` passes --cli copilot to trigger.
- `--from-state IMPLEMENT_FIX` creates a fresh marker at that state when no marker exists.
- If a marker already exists, `--from-state` is ignored.
