# Implement FileInvocationLog (Logger)

Appends one JSON line per invocation to `.orchestrator/log.jsonl`. Fields: agent, role, adapter, exit_code, duration_ms, timed_out, auth_error, config_error, gate outcome. Never read to drive control flow — purely observability.

## Acceptance Criteria

- `log(invocation_record)` appends one JSON line.
- Log file is created on first write.
- Each line is valid JSON matching the AGENT_INVOCATION entity fields.
- Append-only: no truncation or overwrite.
- Unit tests covering: first write creates file, multiple writes append, each line is valid JSON.
