# Implement MarkdownBacklogStore

Reads/writes `backlog/ST-NNNN.md` — parses only the YAML frontmatter for routing (id, deps, classification, status, outputs); the prose body is left for the agent. Implements the `BacklogStore` port.

## Acceptance Criteria

- `list_stories()` returns all stories with their frontmatter fields.
- `get_story(id)` returns a single story's frontmatter.
- `update_status(id, new_status)` rewrites the frontmatter status field without touching the prose body.
- Frontmatter parsing uses the same parser logic as backlog-lint.
- Unit tests with fixture stories covering: list, get, update_status, missing story error.
