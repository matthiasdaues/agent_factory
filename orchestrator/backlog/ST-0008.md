# Implement ApprovalService

Records an `approve` or `reject` decision at a paused phase gate. Approval advances the phase to Complete; rejection halts.

## Acceptance Criteria

- `approve(phase)` transitions status from `awaiting-approval` to `complete`.
- `reject(phase)` transitions status to `halted`.
- Raises an error if the phase is not in `awaiting-approval` state.
- Presents a gate for approval only when the gate passed and open findings == 0 (BR-007).
- Unit tests covering approve, reject, and invalid-state error.
