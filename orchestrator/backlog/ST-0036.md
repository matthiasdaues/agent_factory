# Define MenuNode entity and the menu-tree model

Add the `MenuNode` domain entity (`id`, `label`, `type` ∈ {menu, display, function}, `is_default`) and a declarative construction of the menu tree from `cli_specification.md` v1.2.0. The tree is pure state — it holds structure and default markers, not behaviour — so the `MenuController` (ST-0039) can traverse it and the renderer can paint it.

**Priority:** must-have

## Acceptance Criteria

- A `MenuNode` dataclass exists with `id`, `label`, `type`, and `is_default`, matching the entity model.
- The root menu declares the seven children `init`, `configure`, `run-step`, `run-phase`, `status`, `manage-run`, `backlog` in the order the specification lists.
- Exactly one child per menu may carry `is_default` (the `★` item); the tree builder rejects more than one.
- The tree is data only — no node embeds a service call or terminal logic.
- Unit tests assert the tree shape against the `cli_specification.md` menu tree.

## Analysis

**Entity shape** — `MenuNode` is a frozen dataclass with:

- `id: str` — unique node path (e.g., "orchestrate", "init", "run-step")
- `label: str` — display text (e.g., "Run a single agent")
- `type: MenuNodeType` — enum: menu, display, function
- `is_default: bool` — marks the pre-selected item (★) in a menu
- `children: List[MenuNode]` — optional, present only for menu-type nodes

**Tree structure** — root menu "orchestrate" with 7 children in spec order:

1. init → menu
2. configure → menu
3. run-step → menu
4. run-phase → menu
5. status → menu
6. manage-run → menu
7. backlog → menu

Per spec, these are all menu-type nodes (no leaf functions at root depth yet).

**Validation** — the tree builder validates that each menu node has at most one `is_default=True` child. Raises ValueError if violated.

**Public API** — `src/orchestrator/menu_tree.py` exports:

- `MenuNodeType` enum
- `MenuNode` dataclass (lives in entities.py)
- `build_root_menu()` function returning the root MenuNode

**Implementation path**:

1. Add `MenuNodeType` enum and `MenuNode` dataclass to entities.py
2. Create menu_tree.py with tree builder and validation
3. Write unit tests asserting tree shape and validation
