# Implement config-error halt on trigger exit 2

When trigger returns exit code 2 (resolution error), halt immediately without retry. Print the agent name, CLI, and trigger's stderr. Exit 2.

## Acceptance Criteria

- Given trigger returns exit code 2, then no retry is attempted.
- The orchestrator's exit code is 2 (distinct from halt=1 and success=0).
- The error message includes which agent and which CLI failed.
