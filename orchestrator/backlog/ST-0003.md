# Implement LoopPolicy

The LoopPolicy component owns three things: the iteration cap (default 3, configurable), the supersede-prior-open step (BR-014), and the loop-exit predicate (latest-iteration open findings == 0, SF-04). It guarantees termination.

## Acceptance Criteria

- `should_loop(iteration, cap)` returns `True` when `iteration < cap`.
- `supersede_prior(store, phase, iteration)` marks prior open findings as superseded via the FindingsStore port.
- `should_exit(store, phase, iteration)` returns `True` when `open_count == 0`.
- Unit tests with a stub FindingsStore covering: loop continues, cap reached halts, zero findings exits, nonzero findings loops.
