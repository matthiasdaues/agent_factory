# Wire resume and status commands end-to-end

Integration test for `resume` and `status` commands against a real filesystem run state.

## Acceptance Criteria

- `status` on no run reports idle.
- `status` during a paused run reports phase, iteration, open findings, last gate result.
- `resume` on a halted run re-enters the phase at the last checkpoint.
- `resume` skips already-completed phases (VR-005).
- `resume` re-runs the gate if tracked artifacts changed since checkpoint (BR-013).
- Resume is idempotent at sub-phase granularity (ATAM-R07): already-committed iteration is not re-committed; already-ingested reviewer is not re-run.
- Tests use stub adapters, real filesystem stores, temp directories.
