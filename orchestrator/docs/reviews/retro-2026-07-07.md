- **Updating one pre-commit config without the other**. Dev config and template must move together — they declare the same hooks. Evidence: added `statemachine-lint` to dev config, forgot the template.

- **Replacing Mermaid with Structurizr for diagram types where Mermaid is more expressive**. Structurizr dynamic views are linear numbered steps — no return arrows, no loop/alt blocks, no notes. Sequence diagrams stay in Mermaid. Evidence: built 3 dynamic views, exported, then had to restore Mermaid sequence diagrams.
