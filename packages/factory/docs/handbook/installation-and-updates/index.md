# Installation and updates

This chapter covers `init-factory`, `update-factory`, and `remove-factory` in a project that already has its own files.

<!-- handbook-index:start -->

## How-to guides

- [Use the factory in an existing repository](existing-repository.md): Install the factory into a repository that already has its own history, .gitignore, and pre-commit configuration.
- [Update the factory](update-the-factory.md): Bring an installed .agent-factory/factory/ up to date with a newer checkout, and keep your own changes.
- [Remove the factory](remove-the-factory.md): Reverse the whole installation and get a clean git status back.
