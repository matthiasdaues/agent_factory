# Files that init-factory creates

| File                                         | Holds                                                                                                                                                                                                                                                                                                                                                      | Appears                                                                                                                                                                                                             |
| -------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `.agent-factory/config/project.json`         | The project identity: a stable UUID `project_id`, the name `project_name` you gave at installation, and your declared test command. Every usage record carries `project_id`, so a record stays attributable when the folder moves. The list `safety_critical_paths` feeds the tier rubric: work whose outputs match one of its globs gets the strong tier. | At installation. You do not edit it by hand in normal use.                                                                                                                                                          |
| `.agent-factory/config/model.conf`           | The model matrix: which AI model handles which tier, per CLI. [Model matrix](model-matrix.md) describes it.                                                                                                                                                                                                                                                | At installation. The installer writes a `CONFIGURE-ME` placeholder for each tier of each selected CLI, and the fitting walk-through helps you replace them.                                                         |
| `.agent-factory/config/project-context.json` | A deterministic scan of the project's languages, frameworks, CI, linters, test runners, and documentation structure. The fitting uses it to confirm what the scan found.                                                                                                                                                                                   | Once, at installation. A greenfield project gets an empty scan with `fitting.status: "greenfield"`.                                                                                                                 |
| `docs/testing.yaml`                          | The `test_command` of the project.                                                                                                                                                                                                                                                                                                                         | When `init-factory` finds one clear test entry point, such as a `Makefile` test target, `pytest.ini`, or a `package.json` test script. With several candidates it asks you to choose. With none it creates no file. |
| `docs/agent-context.md`                      | The routing of agents to your project's knowledge. [What the agent context does](../agent-context/what-agent-context-does.md) explains it.                                                                                                                                                                                                                 | Not at installation. The `capture-context` skill creates it during the fitting.                                                                                                                                     |

The files under `.agent-factory/config/` are local configuration, not project source. They are git-ignored and belong to your machine.

## Everything init-factory installs

`init-factory` writes an `agent_factory related` block into `.gitignore`. The table has one row per rule the block can hold. Each rule matches every untracked file or link at its path, including one that existed before the installation, unless a later rule in `.gitignore` re-includes the path. A file that Git already tracks stays tracked.

| Rule                                                                                                     | The installer writes it                                                                                                                                                                                                                                                                                                               |
| -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `/.agent-factory/`, `/.current-work/`                                                                    | Always.                                                                                                                                                                                                                                                                                                                               |
| `/session-scratchpad.md`                                                                                 | Always.                                                                                                                                                                                                                                                                                                                               |
| `/.claude/`                                                                                              | When you install for Claude Code.                                                                                                                                                                                                                                                                                                     |
| `/.pi/`                                                                                                  | When you install for Pi.                                                                                                                                                                                                                                                                                                              |
| `/AGENTS.md`                                                                                             | When you install for Pi or Codex and the root `AGENTS.md` is a symlink after the install step. The installer keeps a symlink whose target is a factory orientation file or points it at the orientation file of the current install. It leaves any other symlink as it is. An existing regular file gets a marker block and no rule.  |
| `/.github/hooks`, `/.github/agents`                                                                      | When you install for Copilot, as whole folders, including a folder that existed before.                                                                                                                                                                                                                                               |
| `/.github/skills`, `/.github/playbooks`, `/.github/rulebooks`, `/.github/scripts`, `/.github/INDEX.yaml` | When you install for Copilot. A link replaces the path when the folder is new. When the folder existed before, the rule names each link the installer made in it.                                                                                                                                                                     |
| `/.github/copilot-instructions.md`                                                                       | When you install for Copilot and the file is a symlink after the install step, new or existing. The installer keeps a symlink whose target is a factory orientation file or points it at the orientation file of the current install. It leaves any other symlink as it is. An existing regular file gets a marker block and no rule. |
| `/.codex/playbooks`, `/.codex/rulebooks`, `/.codex/scripts`, `/.codex/INDEX.yaml`                        | When you install for Codex, as whole paths, including a folder that existed before.                                                                                                                                                                                                                                                   |
| `/.codex/hooks/<script>`, `/.codex/agents/<agent>.toml`                                                  | When you install for Codex, one rule per hook script link and per generated agent. The folders get no rule.                                                                                                                                                                                                                           |
| `/.codex/hooks.json`                                                                                     | When you install for Codex and the file did not exist before.                                                                                                                                                                                                                                                                         |
| `/.opencode/plugins/agent-factory.ts`                                                                    | When you install for OpenCode. The folder `.opencode/plugins/` gets no rule.                                                                                                                                                                                                                                                          |
| `/.agents/skills/<skill-name>`                                                                           | When you install for Codex, one rule per skill link. The folders `.agents/` and `.agents/skills/` get no rule.                                                                                                                                                                                                                        |

A rerun of `init-factory` keeps the rules that the previous run wrote. Everything outside the block is yours to commit: `.gitignore` itself, `.pre-commit-config.yaml` with its hook block, and `docs/testing.yaml`, the test declaration of the project.

| What                 | Where                                                                                                                                                                                                                                                                                                   | Tracked?                                                                          |
| -------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| Toolset copy         | `.agent-factory/factory/`                                                                                                                                                                                                                                                                               | No                                                                                |
| CLI symlinks         | `.claude/`, `.github/`, `.pi/`, `.codex/`, `.agents/` — pointing into `.agent-factory/factory/`                                                                                                                                                                                                         | No                                                                                |
| Git safety guardrail | `.claude/hooks/block-dangerous-git.sh`, `.github/hooks/`, `.pi/extensions/`, `.codex/hooks/`                                                                                                                                                                                                            | No                                                                                |
| Step guard hooks     | `.claude/hooks/step-guard.sh`, `.github/hooks/step-guard.*`, `.pi/extensions/step-guard.ts`, `.codex/hooks/step-guard.sh`                                                                                                                                                                               | No                                                                                |
| Freshness check      | `.claude/hooks/check-factory-freshness.sh`, `.github/hooks/`, `.pi/extensions/`, `.codex/hooks/` — auto-runs `update-factory` when `.agent-factory/factory/` is stale                                                                                                                                   | No                                                                                |
| Usage capture hooks  | `.claude/hooks/capture-usage.sh` (Stop/SubagentStop), `.github/hooks/capture-*.sh`, `.pi/extensions/capture-usage.ts`, `.codex/hooks/capture-codex-usage.sh`                                                                                                                                            | No                                                                                |
| Orientation file     | `.claude/CLAUDE.md`, `.github/copilot-instructions.md`, `AGENTS.md` — prepends a marker block if the file is a regular file; keeps a symlink whose target is a factory orientation file or points it at the orientation file of the current install, whoever made it; leaves any other symlink as it is | No, except a `.github/copilot-instructions.md` or `AGENTS.md` that existed before |
| Generated agents     | `.github/agents/*.md` (Copilot, with tools: frontmatter), `.codex/agents/*.toml` (Codex, native format)                                                                                                                                                                                                 | No                                                                                |
| Hook config          | `.claude/settings.json` (hook entries), `.codex/hooks.json` (hook entries)                                                                                                                                                                                                                              | No, except a `.codex/hooks.json` that existed before                              |
| Pre-commit hooks     | `.pre-commit-config.yaml` — `agent_factory_hook-*` block                                                                                                                                                                                                                                                | Yes                                                                               |
| Gitignore block      | `.gitignore` — `agent_factory related` section                                                                                                                                                                                                                                                          | Yes                                                                               |
| Project config       | `.agent-factory/config/project.json` (name + UUID), `.agent-factory/config/project-context.json` (scan results)                                                                                                                                                                                         | No                                                                                |
| Test regime          | `docs/testing.yaml` — `test_command` if a single unambiguous entrypoint is detected                                                                                                                                                                                                                     | Yes                                                                               |
| Usage runtime        | `.agent-factory/usage/runtime/` — hash-verified tokenizer venv                                                                                                                                                                                                                                          | No                                                                                |
| Usage lifecycle      | `.agent-factory/usage/control/` — registration fence and capture state                                                                                                                                                                                                                                  | No                                                                                |
| Install manifest     | `.agent-factory/install.json`                                                                                                                                                                                                                                                                           | No                                                                                |
| Install checksums    | `.agent-factory/checksums.json` — per-file SHA-256 for modification detection by `update-factory`                                                                                                                                                                                                       | No                                                                                |

You can run `init-factory` again safely. When `.agent-factory/factory/` exists, it stays as it is. Run `.agent-factory/factory/scripts/update-factory` instead.
