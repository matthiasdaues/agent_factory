# install-agent-factory

## Name

`install-agent-factory` — Install Agent Factory from a release source.

## Synopsis

```text
.agent-factory/factory/scripts/install-agent-factory [<arguments> ...]
```

Use `--help` for argument values and defaults supported by your installed version.

## Arguments and options

- `--from-local`. Local Agent Factory source tree to install from.
- `--from-remote`. Remote release base URL to download from.
- `--target`. Target project directory.
- `--version`. Release version (valid only with --from-remote).
