# \_docs_assemble.py

## Name

`_docs_assemble.py` — Assemble the chapters and assets used by the architecture PDF renderer.

## Synopsis

```text
.agent-factory/factory/scripts/_docs_assemble.py [<arguments> ...]
```

This command is used by Factory automation. Its caller supplies the runtime context.

## Arguments and options

- `--docs`
- `--out`
- `--views`. directory with freshly exported Structurizr SVGs
- `--factory-css`
- `--project`
- `--sha`
- `--branch`
- `--built-at`
- `--dirty`
