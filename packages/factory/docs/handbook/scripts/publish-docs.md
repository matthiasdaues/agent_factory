# publish-docs

## Name

`publish-docs` — Build a checked PDF from a project's arc42 documentation.

## Synopsis

```text
.agent-factory/factory/scripts/publish-docs pdf
```

Run from the project root with Docker available. Reads `docs/publish-docs.yaml` and writes the PDF to `docs/dist/`.
