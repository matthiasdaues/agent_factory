# mdformat

## Name

`mdformat` — Format Markdown with the Factory's formatter and plugins.

## Synopsis

```text
.agent-factory/factory/scripts/mdformat [<mdformat arguments> ...]
```

Use `--check` to report formatting differences or `--number <path>` to format files in place. Requires `uvx`.
