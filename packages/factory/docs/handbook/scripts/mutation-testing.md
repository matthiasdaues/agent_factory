# mutation-testing

## Name

`mutation-testing` — Run a project's mutation tests and check the configured result.

## Synopsis

```text
.agent-factory/factory/scripts/mutation-testing [<arguments> ...]
```

Use `--help` for argument values and defaults supported by your installed version.

## Arguments and options

- `--story-id`. story ID, e.g. ST-0318
- `--testing-yaml`. path to testing.yaml
- `--report-dir`. directory for the result file
