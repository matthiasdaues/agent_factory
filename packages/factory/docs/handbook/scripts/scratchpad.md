# scratchpad

## Name

`scratchpad` — Append a dated note to the session scratchpad.

## Synopsis

```text
printf '%s\n' "<note>" | .agent-factory/factory/scripts/scratchpad
```

Appends the note under the current date in the session scratchpad.
