# statemachine-lint

## Name

`statemachine-lint` — Check state-machine descriptions and their correspondence to diagrams.

## Synopsis

```text
.agent-factory/factory/scripts/statemachine-lint [<arguments> ...]
```

Use `--help` for argument values and defaults supported by your installed version.

## Arguments and options

- `files`. Markdown files to check (default: scan --spec-dir recursively)
- `--spec-dir`. Root directory to scan for .md files (recursive)
