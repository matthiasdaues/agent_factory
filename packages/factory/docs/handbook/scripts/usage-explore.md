# usage-explore

## Name

`usage-explore` — Open the explorer for a persisted usage database.

## Synopsis

```text
.agent-factory/factory/scripts/usage-explore <path.duckdb> [<port>] [--no-watch]
```

Run from the project root with a database produced by a persisted usage query.
