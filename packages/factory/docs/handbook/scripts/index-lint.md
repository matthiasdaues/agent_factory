# index-lint

## Name

`index-lint` — Generate or check the Factory catalog from source metadata.

## Synopsis

```text
.agent-factory/factory/scripts/index-lint [<arguments> ...]
```

Use `--help` for argument values and defaults supported by your installed version.

## Arguments and options

- `--agents-dir`
- `--skills-dir`
- `--playbooks-dir`
- `--rulebooks-dir`
- `--out`
- `--check`. verify only, don't write; exit 1 if stale
