# migrate-layout

## Name

`migrate-layout` — Move an older Factory installation to the current directory layout.

## Synopsis

```text
.agent-factory/factory/scripts/migrate-layout [<arguments> ...]
```

Use `--help` for argument values and defaults supported by your installed version.

## Arguments and options

- `target`. Project root (default: current directory)
- `--dry-run`. Show what would happen without making changes
