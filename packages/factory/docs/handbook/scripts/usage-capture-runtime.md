# usage-capture-runtime

## Name

`usage-capture-runtime` — Launch usage capture through its installed Python runtime.

## Synopsis

```text
.agent-factory/factory/scripts/usage-capture-runtime <usage-capture arguments> ...
```

This command is used by Factory automation. Its caller supplies the runtime context.

Used by CLI hooks. Requires the capture runtime already provisioned in the installation.
