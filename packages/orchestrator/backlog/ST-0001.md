# Implement the step-execution while loop

The core of `run-playbook`: a while loop that reads the marker, resolves the current state, and branches on agent/final/null. Calls `phase advance --dry-run` to detect already-satisfied gates. Self-chains on advance.

## Acceptance Criteria

- Given a marker at a state with an agent, when run-playbook is invoked, then trigger is called with that agent name.
- Given a marker at a final state, when run-playbook is invoked, then it exits 0 with a done message.
- Given a marker at a null-agent state, when run-playbook is invoked, then it exits 0 with a human-gate message.
- Given phase advance --dry-run passes, trigger is never called (skip dispatch).
