# The backlog glossary links the Attempt to the wrong entity, and EPIC 3 (This refers to an epic that was cancelled on 2026-10-29. The number is now assigned to a new epic) lists the Dispatch Engine twice

**What is wrong:** Two edits in `backlog/epics.md` left defects:

- `epics.md:18`: the term Attempt now links to the Task Instance entity
  (`entity-model.md#task_instance`). The entity model has its own
  `ATTEMPT` section, which defines the term.
- `epics.md:330` and `:333`: the EPIC 3 (This refers to an epic that was cancelled on 2026-10-29. The number is now assigned to a new epic) boundary table has two rows for the
  Dispatch Engine. The second one replaced the Agent Gateway row (DEC-19).

**Fix:** Point the Attempt term to `entity-model.md#attempt`. Merge the two
Dispatch Engine rows into one row that names both tasks: it creates the
durable dispatch intent, publishes offers through the Outbox Publisher, and
receives `COMMAND_ACK` through the Inbox Receiver.
