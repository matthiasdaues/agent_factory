# `OUTBOX.agent_id` copies a column that `TASK_INSTANCE` does not have

**What is wrong:** The column comment of `OUTBOX.agent_id` says it is "a
copy of the task instance's `agent_id` for Commands"
(`entity-model.md:1298`). `TASK_INSTANCE` has no `agent_id`. Since DEC-12,
the Agent of a run is `ATTEMPT.agent_id`, and the `OUTBOX` row names its
Attempt by `(task_instance_id, attempt_no)`.

**Fix:** Change the comment to "a copy of the Attempt's `agent_id` for
Commands, the only address for control messages".
