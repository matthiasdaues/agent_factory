# The shared feature file does not parse, because DOM-04 uses Or steps

**What is wrong:** The Scenario "Invalid Domain configuration is rejected"
(gigacron.feature:178-187) joins three alternative requests with `Or`. Gherkin
has no `Or` keyword. The official parser (`gherkin-official`) refuses the
whole file:

```text
(184:7): expected: #EOF, #TableRow, #DocStringSeparator, #StepLine, ... got 'Or the administrator creates a Domain with an invalid timezone'
(185:7): expected: ... got 'Or the administrator creates a Domain with a liveness threshold that is not greater than the heartbeat interval'
```

The Rule predates this proposal, but `gigacron.feature` is now the one shared
file for every proposal. While it does not parse, no Gherkin tool can read any
Rule in it, including the 14 Rules of this proposal. With the two steps read
as `And`, the file parses into 38 Rules and 145 Scenarios. `spec-lint` does not
catch the error.

**Fix:** Turn the Scenario into a Scenario Outline with an Examples table of
the three invalid inputs (invalid name, invalid timezone, liveness threshold
not greater than the heartbeat interval), or into three Scenarios. Keep the
`@`-references. Then run the official parser over the file.
