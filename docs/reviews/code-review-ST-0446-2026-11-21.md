# Code review of ST-0446, check a measuring command with the four checks of gate-setup-proof

## Verdict

ST-0446 passes the code review. No finding blocks the story. The review filed two `minor` defects as register files, IMPL-0076 and IMPL-0077, and records five notes.

`gate-setup-proof` builds its two commits in a detached worktree, runs `crap-score` three times, and judges the four checks from the exit codes and the rows. An honest stub passes, each of the four lying stubs fails exactly its check, and the branches stay where they were. Both findings concern the edges of the worktree's lifetime. A stop signal to the proof can leave the measuring command running (IMPL-0076). The proof runs some of the project's git hooks in its worktree, and a failing `post-checkout` hook leaves the worktree registered (IMPL-0077).

Next, the developer agent commits this report and the two register files on `story/ST-0446`. IMPL-0076 and IMPL-0077 can be fixed in this story or in ST-0447, which edits the same script. Then the implementation agent runs the gate-check step.
