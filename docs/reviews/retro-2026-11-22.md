## 🛑 Stop Doing

- **Reporting an agent as done while it holds an open shell**. A finished report says nothing about background commands. Evidence: four developer agents waiting on seven shells after their work had merged.
- **Testing a fix only against its own finding**. The next defect hides in the neighbouring case. Evidence: the BUG-0133 fix dropped every function under any `overload` (BUG-0135); the first IMPL-0091 fix covered only the direct start, not the merge path.
- **Writing review questions into `todo.md` from a run worktree**. It collides with the stakeholder's own changes on `dev`. Evidence: T-0417 in ST-0444 and T-0418 in the security review.

## Improvement potential from the acceptance-first proposal

The proposal's population start, `acceptance-check` with `behave`, and `code-size` are larger features. Three parts are low-hanging fruit, because this run already did them by hand or because they reuse what exists:

1. **Binding traces and the feature file in every brief (proposal section 1).** It is a change to the brief templates and one `backlog-lint` check. Every brief of this run named the feature file and its Rules by hand, and the developers used them.
2. **The failing scenario in the fix brief (proposal section 3, last sentence).** The fix briefs of this run handed over findings, not scenarios. Handing over the scenario the defect breaks would have pointed the BUG-0133 fixer at the rule, not the case, and likely prevented BUG-0135.
3. **Step definitions once per feature, before the first story (proposal section 2).** This run's text checks and stub tests grew story by story in one shared file. Writing the feature's acceptance tests once, before wave 1, both front-loads the real end-to-end path and removes the shared file that serialised every wave.

The population start would have helped most where one developer's reading went wrong and its own tests agreed: BUG-0134 passed its story's tests because the tests used the same reading of coverage as the code. That is the proposal's main case, but it is not low-hanging.
