# Session Retrospective — 2026-11-20

**Session scope**: The orchestrated run on `feature/run-lifecycle` built 24 stories (ST-0408 to ST-0431) in ten waves, and the release v1.11.0 shipped them.
**Duration**: About two days, from 2026-11-18 19:31 to 2026-11-20.
**Mode**: Orchestrated, with stakeholder decisions at each stop.

## ✅ Went Well

- **The per-story review caught defects that lose work.** A fresh reviewer with scratch-repository probes found them before the merge. Evidence: IMPL-0031 (`git reset --hard` deleted uncommitted changes outside the story), IMPL-0040 to IMPL-0042 (`dispatch close` deleted unstashed files on three paths), IMPL-0045 and IMPL-0046 (`close --orphans` removed a live run's worktrees), and IMPL-0050 (the feature merge passed with an unstarted story).
- **A smoke run of the new scripts found what 23 story reviews could not.** Each review saw one diff, and the run used the old installed scripts throughout. One agent drove an orchestrated run end to end in a scratch repository. Evidence: three defects, among them the major one that `re-dispatch` set a `pending` story `prepared` and let `premerge-check dev` pass with a story in flight. ST-0431 fixed them.
- **The spec review at each wave close caught rules that contradicted each other.** Evidence: SPEC-0109 and SPEC-0110 (refused merge and rerun after a refused amend), SPEC-0112 to SPEC-0114 (a domain agent rewrote BR-113 to describe incomplete code), and SPEC-0120 (one contract row let a `none-required` survivor pass).
- **Checking the spec before asking the stakeholder saved questions.** Evidence: `return-story` of a finding (ST-0422 already owned it), `escalate` for a finding (BR-114, BR-115), and the wave-record rule (the ST-0421 Domain Rule) needed no decision.
- **Full merge logs in the scratchpad made a failed merge quick to read.** Evidence: the ST-0431 merge failed with 10 errors, and the log showed `No space left on device` at once, not a code defect.
- **Safety rules in the briefs kept the live run intact.** Every brief for `close` and `--orphans` forbade runs against the real repository and required probes that check their location. Evidence: no story of the run damaged the live ledger or a live worktree.

## 🛑 Stop Doing

- **Stop polling with `pgrep -f` on a word in the loop's own command line.** The loop matches itself and never ends. Evidence: four hanging loops from the developers of ST-0420, ST-0425, ST-0426 and ST-0430.
- **Stop adding a minor finding to a fix iteration when it changes another path than the major finding.** Each such addition gave the reviewer a new surface and produced a new major. Evidence: IMPL-0052 went into the ST-0424 iteration and caused IMPL-0054. The same pattern caused IMPL-0053 and IMPL-0061.
- **Stop committing on the feature branch while an agent works on a story branch cut before it.** The agent's next commit fails `verify-base`. Evidence: the ST-0410 fix iteration.

## ▶️ Continue Doing

- **Continue the narrow re-review of the fix commit only.** It confirmed or rejected each fix in one short pass. Evidence: seven stories needed fix iterations, and each re-review checked only the fix range.
- **Continue presenting review findings with a recommendation before any fix.** The stakeholder answered in one word each time. Evidence: decisions A on the refused amend, A on ignored files, A on the default tier, and option (a) for the empty wave.
- **Continue running drift owners one after another at the wave close.** No agent overwrote another's work in the shared worktree. Evidence: ten wave closes without a conflict after wave 1.
- **Continue keeping the full merge log in the scratchpad.** Evidence: the disk-full cause of the ST-0431 merge showed in the first read.
- **Continue requiring probe scripts that check their own location.** Evidence: after the one slip in the ST-0424 review, every probe in the run stayed in the scratchpad.

## 🆕 Start Doing

- **Start running a scripted smoke test before a feature merges into `dev`.** It replaces the four feature reports, by the stakeholder's decision of 2026-11-19. Its design and owner are open. Emerged from: the manual smoke run that found three defects after all story reviews passed.
- **Start listing in `touches` the test files a change makes wrong, and the finding files a reviewer may resolve.** The planning agent greps the tests for the touched script and subcommand names. Emerged from: about 12 scope commits.
- **Start running only the affected tests in the commit hook, and keep the full suite in `merge-story`.** Emerged from: four to six full runs per story.
- **Start bounding the usage capture.** It records a delta instead of a full transcript copy, keeps a key per subagent, and caps or rotates its folder. Emerged from: the full disk and the records that could not be summed.
- **Start blocking every way to start pytest by hand, not only `uv run pytest`.** Emerged from: two workarounds by developers.
- **Start giving `dispatch` a way to add a story to a running ledger.** `add` exists for findings now. Emerged from: the hand edit for ST-0431.
- **Start naming in every reviewer brief which rows only the stakeholder confirms.** Emerged from: the confirmed `docs/testing.yaml` row.
