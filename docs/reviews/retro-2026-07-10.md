## 🆕 Start Doing

- **Introduce "phase branches"** — one branch per phase/dispatch round, connected to the previous phase by a recorded `--base`/`--head` SHA pair, so a dispatcher run is isolated and reviewable as a discrete unit, and a downstream QA/reconciliation pass targets an exact, reproducible range instead of "whatever HEAD happens to be" when it runs. Emerged from: the worktree-isolation race this session hit — a clear phase-branch contract (with an expected starting SHA declared up front) would likely have made the dispatcher's improvised baseline commit unnecessary, and gives a clean, named rollback point if a dispatch goes wrong.
- **Give retrospective action items a path to become a dispatched backlog story**, not just a prose destination (`docs/spec/todos.md`, issue tracker, agent/skill update, `docs/CONTEXT.md`). Emerged from: this session's explicit ask that confirmed action items be handed to `implementation-agent` directly — the current `retrospective` skill and `coaching-agent` definition have no such destination today.
- **When a multi-context/monorepo split is decided, enumerate every artifact class it touches (docs, ADRs, backlog, `CONTEXT.md`, README) in the same pass**, rather than discovering each one as a separate follow-up round. Emerged from: the Caused-Friction item above.
