# Code review of ST-0437, refuse a measuring-command report in the wrong shape

## Verdict

ST-0437 passes the code review. No finding blocks the story. The review filed one `minor` defect as the register file IMPL-0078 and records three notes.

`crap-score` now checks the shape of every report before it filters or judges a row. It then runs the two duplicate checks on the kept rows, and it counts a deletion below the last function for that function (DEC-51). A wrong shape and a duplicate each exit 2, name the measure and the field or the function, and write no report. IMPL-0078 concerns one row that the schema accepts and the shape check refuses.

Next, the developer agent commits this report and the register file on `story/ST-0437`. Then the implementation agent runs the gate-check step.
