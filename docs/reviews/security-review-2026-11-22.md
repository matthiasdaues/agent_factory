# Security review of feature/crap-gate-setup

## Result

The review files no blocking `SEC` finding. It files one register file of severity `minor`, [SEC-0008](../findings/register/security/SEC-0008.json), and one question for the stakeholder, [T-0418](../spec/work/todo.md). Two notes complete the table.

SEC-0008: `guard-human-fields` lets eight ordinary shell calls write the exceptions register, such as `git checkout dev -- docs/findings/exceptions.md` and `truncate -s0 docs/findings/exceptions.md`. T-0418: a story branch can raise the threshold or exclude its own file in `docs/testing.yaml`, and the merge reads that file at the story head. The same story cannot accept its function through the register. The stakeholder decides whether the merge must refuse such a change.

Next, the implementation agent adds SEC-0008 as a unit of work or leaves it in the register, and the stakeholder answers T-0418. Neither blocks the merge into `dev`.

## Scope

The review covers `git diff 9ea68284..100ea97d` of `feature/crap-gate-setup`. It read the code that runs project-owned commands, the lock files, the register guard, and the plumbing of the proof:

- `crap-score`: `run_command`, `measure_lock`, `caller_environment`, `read_register`, `write_report`
- `premerge-check`: `run_ready_commands`, `_run_in_own_group`, `rerun_gate`, `gate_command`
- `dispatch` and `dispatch_lib.py`: `_ready_refusal`, `ready_commands`, `run_in_own_group`, `cmd_resume_gates`, `GUARDED_EDGES`
- `gate-setup-proof` in full, and the template `crap-measure-python` in full
- `guard-human-fields`: the kind `exceptions` in `guarded`, `check_call`, `check_patch`, `check_shell` and `_simple_targets`

The trust boundaries are those of the Factory. A person owns `docs/testing.yaml` on `dev` and the exceptions register on `dev`. An agent works on a story branch with a shell, and the hooks and the merge checks stand between that branch and `dev`. An attack that needs the capability it gains is not a finding, as [finding-classification.md § Class: security](../../packages/factory/rulebooks/conventions/finding-classification.md#class-security) says.

## How the review checked the guard

The review sent each call as a Claude Code `Bash` payload to `guard-human-fields` from the worktree and read the exit code. Exit `2` came back for `echo x >> docs/findings/exceptions.md`, `cp /tmp/x ./docs/findings/exceptions.md`, `cp -t docs/findings /tmp/exceptions.md`, `tee -a`, `sed -i`, `rm`, `unlink`, and `cd docs/findings && echo x > exceptions.md`. Exit `0` came back for the eight calls of SEC-0008. A `Write` call through a symbolic link to the register gave exit `2` in a scratch repository.
