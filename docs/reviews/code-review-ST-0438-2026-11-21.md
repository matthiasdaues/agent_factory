# Code review of ST-0438, run a measure that needs a running service within one time limit

## Verdict

ST-0438 passes the code review after the re-review of `40891e85`. No finding blocks the story. The first pass filed the `major` defect IMPL-0072 and the `minor` findings IMPL-0073 and IMPL-0074, and the fix commit resolves all three. The re-review filed one `minor` defect, IMPL-0075, as a register file, and it does not block the story. The report records four notes.

`crap-score` now runs the `ready` command before the measuring command, under one time limit for the whole run, and holds an `flock` per measure with a `ready` command. On `SIGTERM`, `SIGINT` and `SIGHUP`, `crap-score` stops the process group of the running command before it releases the lock, so a stopped run no longer overlaps the next run. IMPL-0075 concerns a test stub that logs its start before it sets its trap, so one new case of CG-04-IT-16 fails now and then under load.

Next, the developer agent commits this report and `docs/findings/register/code/IMPL-0075.json` on `story/ST-0438`. Then the implementation agent runs the gate-check step.
