# Session Retrospective — 2026-08-29

**Session scope**: Full implementation campaign for "test-gate-presence-over-test-execution" — 12 stories across 5 waves, reconciliation, QA, defect fixes, and merge to dev.
**Duration**: ~6 hours (two context windows — session was continued after compaction)
**Mode**: mixed (wave-at-a-time dispatch with autonomous subagents, interactive go/no-go between waves)

## Went Well

- **Wave-at-a-time dispatch kept the user in control without slowing delivery** — the user gave "go" at each wave boundary, allowing parallel subagent execution within waves while maintaining oversight. All 5 waves completed without requiring rollbacks. Evidence: ST-0147 through ST-0158 all merged to the feature branch.
- **Reconciliation agent caught three real code defects** — RECON-0020 (phase script missing charter resolution), RECON-0021 (backlog-lint three-gate default), RECON-0022 (test assertions inverted). All three were genuine functional bugs that would have shipped without the reconciliation pass. Evidence: `docs/findings/RECON-0020.md`, `RECON-0021.md`, `RECON-0022.md`.
- **QA agent found defects the reconciliation missed** — FAGAN-F03 (PyYAML dependency violating stdlib-only contract) and FAGAN-F04 (`script.split()` vs `shlex.split()`) were real correctness issues in the charter resolution code. Evidence: the phase script would crash without PyYAML installed, and quoted test commands would be mis-parsed.
- **The user's "who calls mutation-analysis?" question exposed a real gap** — the kit-manager had no mechanism to surface mutation-analysis as an open decision when it was absent from the testing charter. This was a design gap, not a code bug, and was resolved immediately by adding step 6 to kit-manager's test layer bindings. Evidence: `factory/agents/kit-manager.md` amended at `fd91527`.
- **Two-pass commit pattern handled pre-commit hook rewrites reliably** — ruff format modifications during commits were caught and re-staged consistently, avoiding failed commits. Evidence: multiple commits in the session used the add-u/recommit pattern without incident.
- **Rebase before merge was clean** — 41 commits rebased onto dev with only one conflict (INDEX.yaml, auto-generated), resolved in seconds. Evidence: merge commit `069c6d6` on dev.

## Stop Doing

- **Relying on subagent prompts to override hardcoded agent behavior.** The QA agent ignored explicit SHA-based diff instructions in two consecutive prompts and defaulted to `origin/HEAD`. Prompts cannot override behavior baked into an agent's workflow when it resolves its own scope. Evidence: two failed QA launches with identical `origin/HEAD` errors despite detailed override instructions.

## Continue Doing

- **Running reconciliation before QA** — reconciliation found 3 code defects that would have muddied the QA review. Fixing them first gave QA a clean baseline and kept QA findings focused on the remaining (different) issues. Evidence: RECON-0020/0021/0022 fixed before QA launched; QA found FAGAN-F01..F05 and BUG-B01/B02, all distinct from the RECON findings.
- **Verifying QA agent claims against actual file state** — the QA agent incorrectly claimed the bash guardrail had been updated with charter allowlisting (it was the canonical hook at `factory/config/hooks/`, not the deployed `.claude/hooks/` copy). Checking the actual files caught the misattribution and corrected the severity assessment. Evidence: FAGAN-F01 demoted from major to minor after verification.
- **Wave-at-a-time with go/no-go** — gives the user real decision points without slowing autonomous execution within each wave. The 5-wave plan respected dependency ordering and file-overlap constraints correctly.
- **Fixing the `.pre-commit-config.yaml` comment to say "Matches" instead of "Resolves"** — small precision improvements in comments prevent future readers from expecting dynamic behavior that does not exist. Evidence: FAGAN-F05 fix.

## Start Doing

- **Fix `origin/HEAD` symref as part of worktree setup** — the dangling `origin/HEAD → origin/master` (when only `origin/main` exists) caused 3 QA agent failures. `init-factory` or worktree creation scripts should verify and fix `origin/HEAD` if it points to a nonexistent ref. Emerged from: 25 minutes lost to QA agent failures.
- **Add `--max-files` parameter to the premerge-check invocation in the dispatch workflow for multi-story features** — the default limit of 20 files will always block feature branches that span 12 stories and 74 files. The dispatcher should calculate an appropriate limit from the story count. Emerged from: premerge-check BLOCK on file-count-blowout.
- **Extend VR-027 to handle deletion stories** — backlog-lint should recognize that a `status: done` story whose outputs are all deleted files is valid, not a violation. Currently requires the workaround of leaving status as `pending` until post-merge. Emerged from: VR-027 blocking every deletion story in Wave 1.
- **Add charter resolution tests to the phase script from the start** — the charter resolution code shipped through reconciliation without tests, and BUG-B01 caught it only in QA. The developer-agent's TDD loop should have produced these tests during ST-0151 implementation. Emerged from: BUG-B01 finding zero test coverage for a critical code path.
