# Code review of ST-0435, measure Python code with the Factory template

## Verdict

ST-0435 does not pass the code review. The review filed three blocking findings of severity `major`: IMPL-0065, IMPL-0066 and IMPL-0067. Each one is a case where the template gives no correct rows for code that it can measure, and the scratch runs below show each case.

The demo of the story works. The template writes six-field rows to `GATE_OUTPUT`, names `Parser.parse`, measures `scripts/import-orders`, exits `1` after a failed test run and for an unreached script, and writes one `parse_error` row with exit `0`. Every owned row has a test with its Test ID: CG-03-IT-01 to CG-03-IT-05, CG-03-LN-01 and CG-03-LN-02.

Next, the developer agent fixes the three findings on `story/ST-0435` and adds one test for each. Then the story comes back for a second review.
