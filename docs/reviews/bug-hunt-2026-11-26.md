## Notes

- N-1: A file with a byte-order mark fails with "the page has no frontmatter block". The message is true but hides the cause. A hint would help editors that add the mark.
- N-2: A CRLF `index.md` gets generated text with LF endings between the markers and CRLF outside. The lint passes, and the repository formatter normalizes the file on the next commit.
- N-3: A title with one unbalanced backtick, such as `Back`tick`, gets a backslash before its opening bracket, so the link breaks (`\[Back`tick`). A balanced code span works. The case is unlikely in a title.
- N-4: This note lies outside the feature. A first `init-factory` that stopped at the missing project name left `.agent-factory/factory/` in place, and a second run skipped the copy and wrote no `install.json`, so `update-factory` then said the project was not installed. The scripts of this feature do not touch that path.
