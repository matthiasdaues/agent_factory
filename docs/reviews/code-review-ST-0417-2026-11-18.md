## Correctness

The entry keeps the order that the BUG-0111 tests need. First it finds the Factory, then it checks for the rules file, and only then it calls the script. A clone without the Factory passes silently, and a project without the rules file passes without `uv`. The contract test `test_st_0417_hook_checks_the_rules_file_before_the_script` checks that order.

The `files` pattern `\.py$` matches every `.py` path and no `.pyc` or `.py.md` path. The source root is the repository root, the default `.` of `dependency-check`. So "under the source root" holds for every `.py` file, and the edge case "`.py` outside the source root" of the QA strategy has no instance. The spec-feedback report records this gap for the test-strategy agent.

The metadata entry uses `availability: requires-path:docs/spec/dependency-rules.dsl`, which `hook-subset` already reads. RL-10-IT-04 runs `hook-subset generate` with and without the file and sees the hook leave and return.
