## Verdict

ST-0436 does not pass the code review. The review filed one `major` defect, IMPL-0069, which blocks the story. It also records two notes in this report.

`crap-score` reads its settings, runs the measures in order, keeps the rows by `files` and `exclude`, and computes the score in `Decimal` with half-up rounding.
