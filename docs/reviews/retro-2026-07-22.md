**Mode**: Mixed — interactive decisions and confirmations followed by autonomous implementation, reconciliation, QA, and merge work.

## ✅ Went Well

- **The design preserved the feature's actual value across CLI differences** — the user made total token count non-negotiable even when Copilot child activity had to be subsumed through its parent process. The implementation converged on a CLI-agnostic normalized record instead of weakening the requirement for a difficult adapter.
- **Priority ordering kept uncertainty bounded** — Copilot was completed before Codex and Pi, matching the requested order. Each adapter could reuse the shared capture mechanism while retaining CLI-specific extraction and lifecycle behavior.
- **Layered review found material lifecycle and security defects before merge** — RECON, SEC, and FAGAN passes produced fixes through `FAGAN-0007`, including the accepted Pi supervisor-handle release. The final feature tip `2896254` passed sign-off before entering `dev`.
- **The merge was mechanically gated and verified at the actual merge commit** — `premerge-check dev feat/token-usage-tracking` passed for all 71 changed files, and the full post-merge suite reported `436 passed` with warnings treated as errors before any branch was deleted.
- **User-owned work remained isolated** — the token feature was merged through a dedicated `dev` worktree while `config/model.conf` and the Codex proposal on `chore/retro-improvements` remained untouched.
- **Pause/resume continuity worked** — the session resumed from `RECON-0008`, later handoffs retained exact SHAs and open findings, and the final integration proceeded without repeating completed implementation.

## 🛑 Stop Doing

- **Stop retaining absorbed review worktrees until final feature merge.** Once a fix branch is merged into the integration branch and its evidence is recorded, verify it is clean and remove its worktree. Evidence: 31 obsolete token-usage worktrees survived until final cleanup.
- **Stop adding regression tests without recording which contract boundary they uniquely protect.** A regression test is valuable, but unlabelled overlap makes the suite's size hard to justify or safely reduce. Evidence: the user challenged the test proliferation after review fixes expanded the capture suite.
- **Stop attempting known `.git` metadata mutations in the restricted sandbox first.** Resolve and validate exact targets read-only, then request the required permission once. Evidence: the first worktree-removal batch failed on read-only `.git/worktrees` metadata.
- **Stop treating an append-only handoff as a final current-state document.** Preserve history in Git or a dated log, but rewrite the active summary when milestones supersede earlier instructions. Evidence: `HANDOFF.md` says the top section supersedes several stale sections below.

## ▶️ Continue Doing

- **Continue treating total token conservation as an acceptance invariant** — it prevented adapter convenience from silently weakening the feature. Evidence: Copilot subsumption was accepted only because total usage remained captured.
- **Continue using a shared normalized core with thin CLI adapters** — it delivered one mechanism for Claude, Copilot, Codex, and Pi while isolating their extraction differences.
- **Continue gating merges with exact-scope `premerge-check` followed immediately by the merge** — the 71-file gate passed and preserved the intended branch topology.
- **Continue running the full suite at the merge commit before cleanup** — `436 passed` proved the merged state, not merely the feature tip.
- **Continue preserving unrelated dirty-tree state through dedicated worktrees** — Claude's retrospective work and your config/proposal changes were not disturbed.
- **Continue recording exact restart points in handoffs** — resuming at `RECON-0008` and tracking exact feature tips avoided duplicated work after pauses and rate-limit interruptions.

## 🆕 Start Doing

- **Start maintaining a capture-test coverage map** — document each contract boundary and the smallest test layer that owns it: parser/unit, installed-hook integration, CLI adapter end-to-end, or lifecycle end-to-end. New regression tests must name the boundary and should replace overlapping cases where possible. Emerged from: the test-count question and the 71-file final diff.
- **Start phase-close hygiene after every merged finding or story** — after verification, remove the clean source worktree and delete the merged branch unless it is still needed as an active review base. Emerged from: the final 31-worktree cleanup.
- **Start grouping confirmation gates into bounded autonomous batches** — present the scope, invariants, stopping conditions, and destructive actions once; then execute reversible implementation and verification steps without asking again unless those conditions change. Emerged from: the long sequence of one-word confirmations.
- **Start separating current state from historical narrative in handoffs** — keep a compact authoritative state section and move superseded material to a dated history section or replace it entirely. Emerged from: the supersession warning in `HANDOFF.md`.
- **Start making local-versus-remote branch state explicit in merge handoffs** — record `git rev-parse dev`, its upstream, and ahead/behind counts instead of relying on decorated log labels. Emerged from: the local `dev`/`agent_factory/dev` ambiguity during observation.
