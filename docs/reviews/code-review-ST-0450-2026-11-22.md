# Code review of ST-0450, judge every story by the gate settings of the integration branch

## Verdict

ST-0450 does not pass the code review. Two findings block. With [IMPL-0094](../findings/IMPL-0094.md), a story can set `integration_branch: "story/ST-1~1"`, and `crap-score` then judges it by the threshold of the story's own parent commit with exit `0`. A scratch repository reproduces this. With [IMPL-0096](../findings/IMPL-0096.md), the story commit changes `docs/spec/work/todo.md` outside its `touches`, and the scope check of `premerge-check` refuses the merge. The review also files one register file of severity `minor`, records two notes, and asks the stakeholder one question.

Everything else that the focus of this review named holds. The reader is one interface, and the fixed read of `dev` is gone from `crap-score`. A tag or a remote ref named like the branch does not replace an existing branch, `--settings-from-folder` reaches no merge path, and the join by measure name refuses a dropped or renamed measure. The six scoped test files pass: 250 tests.

Next, the developer agent fixes IMPL-0094 and IMPL-0096 on `story/ST-0450` and commits this report, the two finding files and the register file. Then the code review runs again.

## Question for the stakeholder

The story agent shares the refs of the repository with every worktree, so it can create a local branch. Take a story `story/ST-0350` whose `touches` names `docs/factory-settings.yaml`. Its agent commits a raised threshold, creates the branch `loose` at that commit, and sets `integration_branch: loose` in the next commit. Even after the fix of IMPL-0094, `crap-score` judges the story by threshold 10 of `loose` and exits `0`. The tip of `loose` is not `HEAD`, so DEC-76 does not apply.

- **Keep DEC-76 as it stands.** The story passes with threshold 10. Only the planner's `touches` and the code review keep the key in check.
- **Also refuse a named branch whose tip is a commit of the story.** `crap-score` exits `2` when the tip is an ancestor of `HEAD` and not an ancestor of `--base`. The story with `loose` exits `2`. A branch `loose` cut from `dev` with its own new commit still passes.

The review recommends the second option. It closes every commit that the story itself made, and it costs one `git merge-base --is-ancestor` call. The answer changes DEC-76, the § Trusted gate source contract, and the rows of CG-14-IT-07.
