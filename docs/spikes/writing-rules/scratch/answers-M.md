## Where I read twice, and where the text was hard to act on

Line 306 says the branch root is the feature branch tip "when `dispatch init` runs". That clashes with later waves that start from a moved head (276, 48), so I read it twice. Line 62 still uses the path `invocation`, although line 56 retires "invocation branch". The path is a file name, and file names keep their old terms, so it probably passes, but it took a second read. The subcommand table (line 102) puts the human's go on orchestrated `re-dispatch`, while line 83 says orchestrated runs never ask. Many answers depend on 15 open questions. A planner cannot act on `close` ownership, escalation conditions, the `quality-gates` field or the stash rule until someone decides them.
