# Scratch material of the writing-rules spike

These files were in the session scratchpad. The scores in the spike folder rest on them.

- `blind-key.json`: maps each passage ID in `08-blind-passages.md` to its objection or control ID.
- `score.py`: scores a judge table against the key. Run it as `python3 score.py blind-key.json <judge-table>`.
- `versions/`: the five proposal versions as the readers saw them, without frontmatter, Primer, and Appendix. K is the working copy, M is the round-2 rules, T is the current voice file, R is the original pack, and S is the plain pack.
- `answers-K.md` to `answers-T.md`: the readers' answers to `11-reader-questions.md`.
