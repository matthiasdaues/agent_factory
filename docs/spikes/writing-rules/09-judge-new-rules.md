# Judgement of the blind passages against the round-2 rules

Rules 1 to 11 from `07-rules-round2.md` were applied to each passage in `08-blind-passages.md`. Rule 12 was not applied.

The same bar holds for every passage:

- Rule 1 fires on an "it" with no antecedent, on a counted set that the passage does not list ("all seven"), on a label that the passage does not explain ("Q3", "I-1"), and on "above" or a line number. A definite "the proposal" or "the story" counts as context from the surrounding text.
- Rule 4 fires when a question has no recommendation, when the recommendation has no reason, or when an option is named but not described. A yes/no proposal does not need an outcome for "no".
- Rule 6 fires on an unsourced number or estimate, a wrong unit, or an inference stated as fact. A plain statement about tool behaviour does not trigger it.
- Rule 9 fires when the grammatical subject is an idea, an answer, an activity, a gerund, or a backlog item that acts. It also fires on slogans.
- Rule 11 counts the words in each prose sentence, including quoted text, and checks every sentence for a verb. List labels and headings are exempt from the verb check.
