# Contributing

This chapter explains how to write and check a handbook page.

## How-to guides

- [Add a chapter stub and fill it later](stub-rule.md): Write a stub page for a chapter that has no content yet, and turn it into a full page.
- [Quote a rule in a page](quote-a-rule.md): Copy a rule from a rulebook into a handbook page as a rule summary with a source line.
- [Update the page lists with handbook-index](handbook-index.md): Run handbook-index after you add, change, or remove a page.
- [Check the pages with handbook-lint](handbook-lint.md): Run handbook-lint to find page errors before the commit hook does.
