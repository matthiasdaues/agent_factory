# Getting started

You want the Factory to do something it does not do today. Start by [deciding where your change belongs](where-a-change-belongs.md). A project convention, a team extension, and an upstream change have different places to live.

If the change is for your team, [add a project playbook](add-a-project-playbook.md) and try it on examples with known results. If the change belongs in the shared Factory, [bring it upstream](bring-a-change-upstream.md). The clone-and-test tutorial is the setup exercise for that route.
