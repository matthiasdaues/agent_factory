### Deployment model

- Agent Zero runs inside Docker. The README gives a minimal direct command: `docker run -p 80:80 -v a0_usr:/a0/usr agent0ai/agent-zero`.
- Three install paths are documented: the desktop "A0 Launcher" GUI application, the "A0 Install" script (`curl -fsSL https://bash.agent-zero.ai | bash` on macOS/Linux, or a PowerShell equivalent on Windows), and direct `docker run`.
- The README states Agent Zero "runs wherever Docker runs, from a $6 VPS or Raspberry Pi to a local workstation or GPU server."
- A separate "A0 CLI Connector" bridges a running (Dockerized) Agent Zero instance to the host machine's filesystem and shell, installed with `curl -LsSf https://cli.agent-zero.ai/install.sh | sh`. The README states this "is not a separate CLI agent" — it connects to an existing instance rather than running independently.

### Multi-agent cooperation (subordinate agents)

- Verbatim: "Every agent can create subordinate agents to break down work. The superior gives tasks and receives reports; subagents keep their own contexts focused and return their findings when done." This describes a hierarchical, superior/subordinate delegation model, not a flat multi-agent system.

### Extensibility model

- Verbatim: "Almost nothing is hidden. Prompts live in `prompts/`, tools live in `tools/` or plugins, and built-in behavior can be inspected, changed, replaced, or extended."
- The README lists supported extension mechanisms: plugins, MCP (Model Context Protocol), A2A (agent-to-agent), custom tools, custom prompts, project-scoped configuration, and environment-based deployment settings.
- "Plugin Hub" is described as browsing "a growing catalog of community plugins - currently more than 100," spanning development frameworks (e.g., BMAD Method, Agent Skills), "memory systems - alternative memory backends, intelligent consolidation strategies, vector recall plugins," tools/integrations, UI extensions, and workflow plugins. This confirms memory itself is plugin-extensible, corroborated at the code level in SR-0003.

### LLM provider connectivity

- The README states Agent Zero "connects to your OpenAI Codex plan through the new OAuth flow" as a first step toward "account-backed LLM plans," and separately references bring-your-own-API-key connectivity to multiple providers (not enumerated exhaustively in the README body itself beyond the Codex OAuth example and general provider-agnostic framing in the "Documentation" table pointing to MCP and API-integration guides).

## Alternative explanations and interpretive notes

- The current README describes a substantially more elaborate product (Linux desktop, Canvas, Launcher, Plugin Hub) than early descriptions of Agent Zero as a minimal prompt-driven agent loop. This record does not assume feature parity between the original 2024 release and the current (2026-09) state; it describes only the current README's claims. SR-0002 and SR-0003 verify structural claims (agent loop, memory) directly against source code rather than the README, to avoid relying on marketing prose for architectural fact.
- The organizational move from `frdel/agent-zero` to `agent0ai/agent-zero`, combined with a company-held copyright ("Agent Zero, s.r.o."), suggests the project transitioned from an individual maintainer to an organizational/commercial structure at some point between the 2024-06-13 first commit and the current state. The README and repository metadata do not state the date of this transition; this gap is unresolved.
