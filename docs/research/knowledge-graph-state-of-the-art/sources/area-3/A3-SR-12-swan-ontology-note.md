## Evidence

- Abstract (paraphrase): SWAN is an ontology for modeling scientific discourse for biomedical researchers, mainly in neurodegenerative disease, to make scientific context machine-interpretable.
- Section 4: a provenance, authoring and versioning module (PAV) "provides all the relationships that we need for defining provenance, authoring and versioning".
- Section 3.2: the authors state that SWAN cannot be the authoritative source for all biomedical domain ontologies.
- Section 8 (paraphrase): mappings from SWAN to other argumentation models, such as IBIS, aTags, SALT and SchoolOnto, are proposed but not implemented.
