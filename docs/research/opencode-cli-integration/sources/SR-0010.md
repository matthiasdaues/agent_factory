# SR-0010 — OpenCode Official CLI Documentation

## Provenance

- **URL**: https://opencode.ai/docs/cli/
- **Accessed**: 2026-09-18
- **Type**: official documentation
- **Freshness**: current (2026)

## Evidence

### Command Structure

`opencode [command] [subcommand] [flags]`. Defaults to TUI when run without arguments.

### Agent Management CLI

- `opencode agent create` — interactive agent creation (choose location, describe, auto-generate prompt, select tools, creates markdown).
- `opencode agent list` — list available agents.

### Session Operations

- `opencode session list` — with `--max-count`, format options (table/JSON).
- `opencode session delete [sessionID]`.
- `opencode run [message]` — non-interactive execution.
- `--continue` or `--session [ID]` — continue existing session.
- `--fork` — branch from existing session.
- `--share` — enable session sharing.
- `opencode export [sessionID]` and `opencode import [file|URL]`.

### Server Modes

- `opencode serve` — headless API.
- `opencode web` — with web interface.
- `opencode attach [url]` — connect to remote instance.

### Key Flags

- `--model provider/model` — model selection.
- `--agent [name]` — agent assignment.
- `--auto` — auto-approve non-denied permissions.
- `--dir` — working directory.
- `--title` — session name.
- `--format [default|json]` — output format.
- `--variant` — model reasoning effort.
- `--system` — system prompt override.

### Experimental Environment Variables

`OPENCODE_EXPERIMENTAL*` — features like workspace support, background subagents, native LLM paths.

## Limitations

- Does not document the experimental workspace support in detail.
- Does not document the `opencode serve` API endpoints.
- Background subagents are experimental, not documented as stable.
