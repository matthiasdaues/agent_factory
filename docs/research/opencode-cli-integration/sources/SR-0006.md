# SR-0006 — OpenCode Official Skills Documentation

## Provenance

- **URL**: https://opencode.ai/docs/skills/
- **Accessed**: 2026-09-18
- **Type**: official documentation
- **Freshness**: current (2026)

## Evidence

### SKILL.md Format

Skills are markdown files with YAML frontmatter. Required fields: `name`, `description`. Optional: `license`, `compatibility`, `metadata` (string-to-string map). Unknown frontmatter fields are ignored.

### Name Validation

Regex: `^[a-z0-9]+(-[a-z0-9]+)*$`. 1–64 characters, lowercase alphanumeric with single hyphens, must match containing directory name.

### Discovery Paths (six locations)

Project-local:

- `.opencode/skills/<name>/SKILL.md`
- `.claude/skills/<name>/SKILL.md`
- `.agents/skills/<name>/SKILL.md`

Global:

- `~/.config/opencode/skills/*/SKILL.md`
- `~/.claude/skills/*/SKILL.md`
- `~/.agents/skills/*/SKILL.md`

For project-local paths, OpenCode walks up from current working directory until it reaches the git worktree root.

### Skill Invocation

Agents access skills via the native `skill` tool. The agent calls `skill({ name: "skill-name" })`. Available skills appear in the tool description with their name and description.

### Permissions

Pattern-based in `opencode.json`: `allow`, `deny`, `ask`. Supports wildcards like `internal-*`.

### Agent-Specific Skill Overrides

Custom agents can override skill permissions in frontmatter. Built-in agents configure overrides in `opencode.json` under `agent.<name>.permission`.

Skills can be disabled per-agent by setting `tools.skill: false`.

### Description Constraint

1–1024 characters.

## Limitations

- Does not document the skill directory structure beyond SKILL.md (e.g., `scripts/`, `references/`, `assets/` subdirectories).
- Does not document whether skills can declare dependencies or inputs/outputs.
- The `compatibility` frontmatter field is not defined — unclear what values it accepts.
