# SR-0005 — OpenCode Official Configuration Reference

## Provenance

- **URL**: https://opencode.ai/docs/config/
- **Accessed**: 2026-09-18
- **Type**: official documentation
- **Freshness**: current (2026)

## Evidence

### Config File Format

OpenCode supports JSON and JSONC (JSON with Comments) formats. Schema validation at `https://opencode.ai/config.json`.

### Config File Locations (merge order, later overrides earlier)

1. Remote config (`.well-known/opencode` endpoint)
2. Global config (`~/.config/opencode/opencode.json`)
3. Custom path (`OPENCODE_CONFIG` env var)
4. Project config (`opencode.json` in project root)
5. `.opencode` directories (agents, commands, plugins)
6. Inline config (`OPENCODE_CONFIG_CONTENT` env var)
7. Managed files (`/etc/opencode/` on Linux)
8. macOS managed preferences (`.mobileconfig` via MDM)

### Top-Level Configuration Keys

Key fields: `model`, `small_model`, `provider`, `shell`, `tools`, `agent`, `default_agent`, `subagent_depth` (default: 1), `command`, `permission`, `share`, `server`, `instructions` (array of paths/globs), `mcp`, `lsp`, `formatter`, `snapshot` (git-based change tracking), `autoupdate`, `compaction`, `watcher`, `plugin`, `disabled_providers`, `enabled_providers`, `experimental`.

### Environment Variables

`OPENCODE_CONFIG`, `OPENCODE_CONFIG_DIR`, `OPENCODE_CONFIG_CONTENT`, `OPENCODE_TUI_CONFIG`, `{env:VARIABLE_NAME}` (substitute in config), `{file:path/to/file}` (include file contents).

### Plugin System

Plugins load from `.opencode/plugins/` or npm. The `plugin` key is an array.

### Snapshot System

When `snapshot: true` (default), OpenCode uses git for change tracking.

## Limitations

- Does not document the plugin API or plugin authoring format.
- Does not document experimental features in detail.
- The `subagent_depth` key is documented but its interaction with worktree isolation is not covered.
