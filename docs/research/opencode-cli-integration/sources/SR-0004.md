## Evidence

OpenCode is an open-source, MIT-licensed, terminal-native AI coding agent. Key configuration details:

- **Config file**: `opencode.json` (JSONC supported) in project root, `~/.config/opencode/opencode.json` globally.
- **Data directory**: `.opencode/` by default.
- **Built-in agents**: Build, Plan (primary); General, Explore, Scout (subagent); Compaction, Title, Summary (hidden/system).
- **Config structure** includes `providers`, `agent`, `shell`, `mcp`, `lsp`, `permission`, `instructions`, `tools`, `plugin`.
- **Custom commands** stored as markdown in `.opencode/commands/` (project) or `~/.config/opencode/commands/` (global).
- **Tools**: `read`, `write`, `edit`, `grep`, `glob`, `list`, `bash`, `fetch`, `task` (subagent), `skill`, `lsp`, `websearch`, `webfetch`.
- **MCP support**: local (stdio) and remote (HTTP/SSE) transport types.
- **SQLite** for session persistence.
- **Auto-compact** summarizes conversations approaching context limits.
- **Connects to 75+ AI providers.**
