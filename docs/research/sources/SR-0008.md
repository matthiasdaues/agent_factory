## Evidence

### Configuration Format

MCP servers defined in `opencode.json` (JSONC) under the `mcp` key with unique names:

```json
{
  "mcp": {
    "server-name": {
      "type": "local" | "remote",
      "enabled": true
    }
  }
}
```

### Transport Types

**Local (stdio):**

```json
{
  "type": "local",
  "command": ["npx", "-y", "my-mcp-command"],
  "environment": { "VAR": "value" },
  "timeout": 5000
}
```

**Remote (HTTP/SSE):**

```json
{
  "type": "remote",
  "url": "https://mcp-server.com",
  "headers": { "Authorization": "Bearer KEY" },
  "oauth": {}
}
```

### OAuth Support

Automatic OAuth handling for remote servers. Detects 401 responses, supports Dynamic Client Registration (RFC 7591). Tokens stored in `~/.local/share/opencode/mcp-auth.json`.

CLI commands: `opencode mcp auth <name>`, `opencode mcp list`, `opencode mcp logout <name>`.

### Per-Agent MCP Tool Enablement

MCP tools can be disabled globally and enabled per-agent using glob patterns:

```json
{
  "tools": {
    "my-mcp*": false
  },
  "agent": {
    "my-agent": {
      "tools": {
        "my-mcp*": true
      }
    }
  }
}
```

### Tool Exposure

MCP tools become available as built-in tools to the LLM alongside OpenCode's native tools.

## Limitations
