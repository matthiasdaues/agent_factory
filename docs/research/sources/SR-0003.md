# SR-0003 — OpenCode Official Rules Documentation

## Provenance

- **URL**: https://opencode.ai/docs/rules/
- **Accessed**: 2026-09-18
- **Type**: official documentation
- **Freshness**: current (2026)

## Evidence

### AGENTS.md — Project Instructions

OpenCode uses `AGENTS.md` files for project-level custom instructions, similar to Claude Code's `CLAUDE.md`. The `/init` command scans a repository and generates or updates an `AGENTS.md`.

### Discovery and Precedence

1. **Local project files** — traversing up from current directory (`AGENTS.md`, then `CLAUDE.md`).
2. **Global user file** — `~/.config/opencode/AGENTS.md`.
3. **Claude Code fallback** — `~/.claude/CLAUDE.md` (unless disabled).

First matching file wins within each category. Project-level `AGENTS.md` takes precedence over `CLAUDE.md` in the same directory.

### Multiple Instruction Sources

Sources combine (cumulative, not replacing):

- Local `AGENTS.md` or `CLAUDE.md`.
- Global config file.
- Custom instruction paths in `opencode.json` via `"instructions"` field.

The `instructions` field supports globs: `"packages/*/AGENTS.md"` for monorepos.

Remote instructions are fetched with a 5-second timeout.

### Claude Code Compatibility

Environment variables to disable:

- `OPENCODE_DISABLE_CLAUDE_CODE=1` — disable all `.claude` support.
- `OPENCODE_DISABLE_CLAUDE_CODE_PROMPT=1` — disable only `~/.claude/CLAUDE.md`.
- `OPENCODE_DISABLE_CLAUDE_CODE_SKILLS=1` — disable only `.claude/skills`.

When compatibility is enabled (default), OpenCode reads:

- `.claude/CLAUDE.md` (project instructions).
- `.claude/skills/*/SKILL.md` (skill definitions).
- `~/.claude/CLAUDE.md` (global instructions).
- `~/.claude/skills/*/SKILL.md` (global skills).

### Prompt Assembly Order

1. Provider header (identity, knowledge cutoff).
2. Provider-specific prompt (model-tailored).
3. Environment information (working dir, git status, platform, date).
4. Custom instructions (AGENTS.md / CLAUDE.md).
5. Agent-specific prompt (from `.opencode/agents/`).
6. User override (`--system` flag).

## Limitations

- If both `AGENTS.md` and `CLAUDE.md` exist in the same directory, only `AGENTS.md` is used. This means a project with both Claude Code and OpenCode users would need to maintain `AGENTS.md` as the canonical file.
- Does not document how `settings.json` hooks from `.claude/settings.json` are handled (they are not — see SR-0007).
