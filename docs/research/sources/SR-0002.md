- **Freshness**: current (2026)

## Evidence

### Agent Types

Two categories: **Primary** (user-facing, switchable via Tab) and **Subagent** (invoked by primary agents or via `@` mentions).

### Built-in Agents

- **Build**: primary, all tools enabled.
- **Plan**: primary, file edits and bash set to `ask`.
- **General**: subagent, full tool access, multi-step parallel tasks.
- **Explore**: subagent, read-only, codebase exploration.
- **Scout**: subagent, read-only, external docs and dependency research.
- **Compaction, Title, Summary**: hidden system agents.

### Agent Definition — JSON Format

In `opencode.json` under the `agent` key:

```json
{
  "agent": {
    "custom-agent": {
      "mode": "subagent",
      "model": "anthropic/claude-sonnet-4-20250514",
      "prompt": "{file:./prompts/custom.txt}",
      "permission": {
        "edit": "deny",
        "bash": "allow"
      }
    }
  }
}
```

### Agent Definition — Markdown Format

Place files in `~/.config/opencode/agents/` (global) or `.opencode/agents/` (project):

```markdown
---
description: Agent purpose
mode: subagent
model: anthropic/claude-sonnet-4-20250514
temperature: 0.1
permission:
  edit: deny
  bash: deny
---
System prompt content here...
```

### Configuration Options

| Option        | Purpose                         |
| ------------- | ------------------------------- |
| `description` | Required brief description      |
| `mode`        | `primary`, `subagent`, or `all` |
| `model`       | Override global model selection |
| `temperature` | 0.0–1.0                         |
| `steps`       | Maximum agentic iterations      |
| `prompt`      | Custom system prompt file path  |
| `disable`     | Set `true` to disable           |
| `color`       | Hex or theme color              |
| `top_p`       | 0.0–1.0                         |

### Permissions Per Agent

Permission keys: `read`, `edit`, `glob`, `grep`, `list`, `bash`, `task`, `external_directory`, `webfetch`, `websearch`, `lsp`, `skill`.

Each accepts `"allow"`, `"ask"`, or `"deny"`.

Fine-grained bash control with glob patterns:

```json
"permission": {
  "bash": {
    "*": "ask",
    "git status": "allow",
    "git push": "deny"
  }
}
```

### Subagent Invocation

- `@general search for X` — manual invocation via `@` mention.
- `session_child_first` (Leader+Down) to enter child session.
- Navigate children with Right/Left, parent with Up.

### Agent Creation CLI

`opencode agent create` — interactive process: choose location (global/project), describe purpose, auto-generates system prompt, select tools, creates markdown file.

## Limitations

- Does not document whether agents can spawn worktree-isolated sessions natively.
- Does not document agent-to-agent handoff protocols.
- `subagent_depth` default is 1, limiting recursion, but configurable.
