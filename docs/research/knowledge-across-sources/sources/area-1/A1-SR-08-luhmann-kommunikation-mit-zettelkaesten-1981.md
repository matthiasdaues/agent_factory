## Evidence

- Fixed place: the translation says Luhmann chose not to "order notes by topics and subtopics, and instead choose an order with fixed placement."
- "It is enough to assign a number to each note, place it so that it’s easy to see (top left for us), and never change it, and thus never change the note’s place."
- (1) Branching: "A note with the number 57/12 can be continued with 57/13, but it could also be complemented from a word or a thought with 57/12a".
- (2) Links by number: "Because all notes have a fixed number, you can create as many references on each note as you want."
- "References allow solving the “multiple storage problem” without significant investment of labor or paper."
- (3) Register: "Considering that there is no topical order, you have to put a search mechanism in place because you cannot rely on your numerical memory."
- Sources: "Bibliographical notes that you extract from literature should be captured inside the Zettelkasten. Books, articles, etc. that you actually have read should each get individual notes that belong in a separate section and that contain the bibliographical information. This allows you in the longer run to distinguish what source you have actually read and what source you have just collected for later use."
- Translator note: "Manfred Kühn created the first translation."

What the source shows: links in the Zettelkasten are references to a fixed note number written on the note that refers. A keyword register gives entry points. Sources sit in a separate bibliographic section, and notes refer to them.

What it does not show: any reverse reference written on the target note. It shows no provenance of a single note beyond the bibliographic reference the author chose to write.
