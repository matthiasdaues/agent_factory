## Evidence

- Hosting note: "This document was an attempt to persuade CERN management that a global hypertext system was in CERN's interests."
- Enquire: "Called Enquire, it allowed one to store snippets of information, and to link related pieces together in any way."
- Enquire figure caption: "Note that each link has a type". The example type is includes, set in quotation marks in the source. The caption goes on: "and may also have comment associated with it."
- Web of notes: "This is why a". The next word, web, is set in quotation marks in the source. The sentence goes on: "of notes with links (like references) between them is far more useful than a fixed hierarchical system."
- "We can call the circles nodes, and the arrows links."
- Requirement: "A new system must allow existing systems to be linked together without requiring any central control or coordination."
- Requirement: "One must be able to add one's own private links to and from public information. One must also be able to annotate links, as well as nodes, privately."
- Live links: "Hypertext allows documents to be linked into". The next word, live, is set in quotation marks in the source. The sentence goes on: "data so that every time the link is followed, the information is retrieved."

What the source shows: the design goal of linking without central control, typed links in Enquire, and an explicit requirement for private links and annotations on public information.

What it does not show: whether links are one-way or two-way in the planned system. A1-SR-07 covers that design question.
