# Term Candidates

Each row is a term that waits for the stakeholder's confirmation. The domain-modeling agent moves a confirmed row into `docs/spec/glossary.md` and removes it here (BR-065).

| Term                  | Domain area             | Source                                                                                                                                                                                                           | Proposed definition                                                                                                                                                                                                                                                                                                              | Status   | Note |

| Output Declaration    | Core artifact ownership | `packages/factory/agents/*.md` frontmatter `outputs.declarations`; [core-artifact-ownership.feature](../features/core-artifact-ownership.feature)                                                                | One entry under `outputs.declarations` in an agent definition. It names a path pattern the agent writes, whether the output is required, its validator, and on a core or seam artifact its reviewers in `reviewed_by:`.                                                                                                          | proposed |      |
| Report Row            | Core artifact ownership | `packages/factory/scripts/dispatch_lib.py` `REPORT_COLUMNS`, `ROW_STATUSES`                                                                                                                                      | One row of a spec-feedback report or a reconciliation report, with the columns Artifact, Drift, Evidence, Owner, and Status. Its status is `open`, `fixed`, `confirmed`, or `rejected` (BR-061).                                                                                                                                 | proposed |      |
| Reconciliation Report | Core artifact ownership | `packages/factory/agents/reconciliation-agent.md`; Rule "Reconciliation agent reports drift to each artifact's owner"                                                                                            | The file `docs/reviews/reconciliation-<date>.md`.
