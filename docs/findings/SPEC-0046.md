# The term candidate "Indexed Artifact" of the domain area counter-ids waits for the stakeholder

**What is wrong:** `docs/spec/work/term-candidates.md` holds the term **Indexed Artifact** in the domain area `counter-ids` with the status `proposed`. The term is not in the glossary until the stakeholder confirms it (BR-065). The proposed definition covers only an artifact "whose name carries an ID that `next-id` claimed". So ST-0327, which keeps its name (DEC-03), would not be an indexed artifact, although the branching rule of CID-08 covers it too. Propose a definition that names the ID form and the prefix list instead, for example "a story, finding, todo entry, or ADR whose name carries an ID of a prefix in the list of `next-id`".

**Fix:** Present the term and its proposed definition to the stakeholder at the next pause point. On confirmation, move the row into `docs/spec/glossary.md` and remove it from `term-candidates.md`. On rejection, keep the stakeholder's note in the row.
