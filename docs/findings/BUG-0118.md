# `housekeeping-about` counts five fitting steps after the sixth was added

**What is wrong:** ST-0377 of counter-ids-fitting adds the sixth fitting key,
`counter_seeded`. `housekeeping-about` still lists five keys (line 35) and
prints the fitting progress as `X/5` (line 67). A project with all six keys
`true` shows `5/5` and misses the seed step, and a project that has not seeded
shows "done" too early. Raised by the drift row of ST-0377 on
`feature/counter-ids-fitting`.

**Fix:** list `counter_seeded` with its step name, and print the count against
the number of keys in that list, not a fixed 5. Add a test with six keys.
