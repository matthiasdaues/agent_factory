# The worktree rule loses its automated-run qualifier

**What is wrong:** A maintainer running dispatch by hand can read the callout as an instruction to create a linked worktree for each story. The summary drops the automated-only qualifier from `rules.md` § Branching. The run-by-hand section of `branches-and-dispatch/dispatch-runs.md` correctly describes a story checkout in the primary worktree.

**Why this severity:** The callout changes the scope of a binding rule. The handbook must report the rule as it applies today. The handbook text is new on the story branch.

**Fix:** Restore the automated-only qualifier and link to the run-by-hand section for the primary checkout workflow.
