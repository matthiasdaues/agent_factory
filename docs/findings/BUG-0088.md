# The feature-addition playbook has no route for exit 2 of `module-graph-check`

**What is wrong:** Step 1.4 of `feature-addition.md` runs
`module-graph-check` and reads its result. Since the fix for BUG-0055 the
script exits 2 when it cannot read the DSL or the interface contracts. The
playbook says nothing about exit 2, so a run that hits it stops with no
route forward. The review of story ST-0297 found this.

**Fix:** Add one line to Step 1.4: on exit 2, keep
`impact.architecture_change` as declared and ask the human.
