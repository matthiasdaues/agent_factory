# The claim and seed error tables name a refusal by the remote in two different ways

**What is wrong:** The claim error table has the rows "fetch refused by the remote" and "push refused for another reason". The seed error table has one row, "access refused by the remote". A seed that a `pre-receive` hook refuses is a refused push, not a refused access, so a reader cannot tell which seed row covers it. All three rows name the same message, the remote and git's error message, so only the wording differs.

**Fix:** Use one name per case in both tables. For example, rename the seed row to "push refused by the remote", if a seed only pushes. Add a "fetch refused by the remote" row only if a seed also reads the remote.
