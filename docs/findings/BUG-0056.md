# `schema-validate` crashes on union types

**What is wrong:** `"type": ["string", "null"]` raises a `TypeError` and exits 1, the code for findings. `"type": "null"` accepts a string. `minimum` is ignored. `contracts/usage-record/v1.schema.json` uses both union types and `minimum`. Source: [bug-hunt report § L-11](../reviews/bug-hunt-2026-10-15.md#l-11--schema-validate-crashes-on-union-types).

**Fix:** Support union types, `null`, and `minimum`, or use a JSON Schema library.
