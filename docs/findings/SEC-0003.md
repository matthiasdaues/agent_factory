# Automatic capture executes an unpinned tokenizer dependency

**What is wrong:** every installed lifecycle hook runs the PEP 723
`usage-capture` script, whose dependency is declared only as `tiktoken` with no
version or integrity constraint. A future compromised or incompatible package
release can be resolved and executed automatically with the developer's
privileges during routine CLI use. The hook frequency and automatic execution
make this a realistic supply-chain path. This is OWASP A06: Vulnerable and
Outdated Components, Medium severity.

**Fix:** Pin a reviewed tokenizer version and protect resolution with a lock or
verified artifact hash, or vendor the required tokenizer implementation. Fetch
or verify it at an explicit trusted installation boundary and make lifecycle
capture run offline from that verified installation. Add a test that the
runtime dependency declaration cannot float to an arbitrary release.
