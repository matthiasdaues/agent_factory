# The migration drops working source commands and a related documentation link

**What is wrong:** Contributors following the map lose the source-checkout launch commands. The install row routes `cd packages/usage` to a page with the installed directory only, and the browser rows omit the `packages/usage` direct commands and bootstrap variants. The wrapper row routes to the query page without locating `usage-explore` on the browser page. The related documentation row leads to an architecture page with no link to the replacement UI guide. The map introduction also describes the retained README as deleted.

**Why this severity:** The brief requires the map to account for working source commands, paths, and facts. The installed paths change, but the development paths still exist. The affected documentation is on the story branch.

**Fix:** Keep the development variants on an appropriate contributor page and record the split in the relevant rows. Record where the wrapper launch moved, restore the exploration link on the architecture page, and describe the README as retained.
