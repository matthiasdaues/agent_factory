# The ignore summary promises to hide paths that a later rule can expose

**What is wrong:** A maintainer can see an untracked `AGENTS.md` symlink that the handbook says Git hides. The new summary says each installer rule hides every matching untracked path. In a scratch repository, the installer wrote `/AGENTS.md`, and Git ignored the link. After a later `!/AGENTS.md` rule, `git ls-files --others --exclude-standard AGENTS.md` listed it.

**Why this severity:** The install inventory gives the wrong Git visibility when a project has a later exception. The new summary exists on the story branch.

**Fix:** State that the rules match untracked paths regardless of when the paths appeared. Explain that Git applies later matching exceptions.
