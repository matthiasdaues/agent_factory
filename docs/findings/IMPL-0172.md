# The install inventory wrongly says Git ignores the test declaration

**What is wrong:** A project maintainer can mistake `docs/testing.yaml` for ignored local state. The new inventory says the installer adds it to the ignore block. `write_gitignore_block` adds no entry for the file, which `detect_test_regime` can create with a detected or user-selected command.

**Why this severity:** The moved inventory gives the wrong source-control status for the project test declaration. The change exists only on the story branch.

**Fix:** Mark the test declaration as eligible for version control. Explain which paths the installer ignores and which files the project can track.
