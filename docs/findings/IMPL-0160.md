# The direct explorer command looks for the database in the wrong directory

**What is wrong:** A user who follows the direct commands from the project root gets `file not found: usage.duckdb`. The launch command uses `uv run --directory`, which changes the working directory to the installed package. The query writes the database to the project root. The module also watches the spool only when it receives `--watch`, so the direct launch does not provide the refresh described below it.

**Why this severity:** The story moves the direct launch into the handbook and requires the installed commands to work as documented. The affected documentation is on the story branch.

**Fix:** Pass the module an absolute database path from the project root. Explain where the wrapper enables watch mode and show the absolute spool path with `--watch` for the direct equivalent.
