# Stale-list diagnostics can disappear after an unrelated refusal

**What is wrong:** BR-147 requires every failure. BR-146 delegates stale-list detection to the generator, which may refuse when a page in the other handbook has invalid metadata. [`docs/spec/validation-rules.md:662`](../spec/validation-rules.md)

**Why this severity:** A test author must decide whether a stale list in a valid chapter still needs a diagnostic. FH-04-15 checks continued folder validation only. No code or completed story outside this run encodes the affected test requirement.

**Fix:** Define which lists can still be checked after a refusal. Check a stale list in one handbook alongside a malformed page in the other.
