# `remove-factory` leaves the freshness hook wired

**What is wrong:** After removal, `.claude/settings.json` still runs `check-factory-freshness.sh` before every Bash call, but the script is gone. Source: [bug-hunt report § I-5](../reviews/bug-hunt-2026-10-15.md#i-5--remove-factory-leaves-the-freshness-hook-wired).

**Fix:** Add the freshness command to the strip list and remove the empty `.claude/hooks/` directory.

**Resolution:** Fixed in commits `01c91b425d16046ff495013b1e5c14b02f2e67dc`, `3243b2701e227647bc742bcb14e470bad2214ede`, `4d9c19b966aabbab97ae90879a8af4eeaa12c09f`, `d59b3d89524508d8ddb5787a4aed60f7bdb4f22b`, `b73d890c1eb12872a2a56bf865e498862564fa99`, merged into `dev` as `3921e522cc31f7fd454d9c908c9e8e42ceb201fe`. The full suite passed after the merge. `.claude/hooks` is recorded in `remove_paths` when the install creates it, and removal deletes it only when empty, so a user's own hook survives.
