# `spec-lint` reads a todo file name the convention forbids

**What is wrong:** `spec-lint` (around line 503) reads `docs/spec/todos.md`. `todo-format.md` line 18 requires `docs/spec/todo.md`, a single file. Agents write `todo.md`, so the todo check has never inspected an entry.

**Fix:** Read `docs/spec/todo.md`. The stakeholder folded this into story ST-0307.
