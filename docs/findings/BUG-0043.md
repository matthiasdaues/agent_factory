# The documented update and reconcile commands do not exist

**What is wrong:** The session menu's "Update Factory" option tells the agent
to run `init-factory --update <project-root> --force`. The four orientation
files tell it to run `init-factory --update .` when fitting progress looks
stale. `migrate-layout` prints `init-factory --update TARGET --force` as the
next step. `init-factory --update` accepts only `usage`, and `init-factory`
has no `--force` flag, so each command exits 2 with "invalid choice". Source:
[bug-hunt report § X-3](../reviews/bug-hunt-2026-10-15.md#x-3--the-documented-update-command-does-not-exist).

**Fix:** Point the menu at `update-factory --target <project-root>`. Stop and
ask before rerunning with `--force` when it reports user changes. Point the
orientation files and `migrate-layout` at a plain `init-factory --target`
rerun, which re-derives the fitting keys and rewires the links. This depends
on [BUG-0044](BUG-0044.md), because a plain rerun must not add tools.
