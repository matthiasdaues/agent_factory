# The `validate` skill has a broken command and changes files

**What is wrong:** The gate 4 command is cut off after `':!.agent-factory/**'`. mdformat dropped the text after an unescaped `|` inside a table cell. Gates 1 to 3 run `mdformat --number .`, `ruff check --fix`, and `ruff format`, which change files. The skill says validate does not rewrite project files. Source: [bug-hunt report § L-7](../reviews/bug-hunt-2026-10-15.md#l-7--the-validate-skill-has-a-broken-command-and-changes-files).

**Fix:** Escape the `|` in the table, and use the `--check` forms.

**Resolution:** Fixed in commit `01727d671692176b1a9a562c3ebf72cba3fc232a`, merged into `dev` as `3921e522cc31f7fd454d9c908c9e8e42ceb201fe`. The full suite passed after the merge.
