# The CLI how-to overstates what setup installs for OpenCode

**What is wrong:** An OpenCode user can expect `--add` to install usage capture and freshness hooks. The how-to promises those features for any CLI. The installer treats OpenCode as guard-only and places its plugin under `.opencode/plugins/`. The chapter has no OpenCode page to explain the supported version, trust model, and host-authority limit named in the OpenCode documentation scenario.

**Why this severity:** The current behavior differs from the how-to. The CLI chapter is also the documented home for the existing OpenCode scenario. The handbook text is new on the story branch.

**Fix:** Qualify the `--add` description and link to an OpenCode concept page with the guard-only integration details required by the scenario.
