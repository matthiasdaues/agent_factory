# The ignore summary misses existing files that Git can ignore

**What is wrong:** A maintainer can miss an untracked `AGENTS.md` symlink after installing for Codex. The handbook summary limits the rules that match existing files to the Copilot folder rules and four Codex path rules. In `init-factory`, `_link_orientation` also sets the root ignore flag for an existing project symlink. The installer keeps the symlink and adds `/AGENTS.md` to the ignore block. The block always includes `/session-scratchpad.md` too. In a scratch repository, `git check-ignore -v` matched the installer rules for both existing paths.

**Why this severity:** The inventory gives maintainers the wrong Git visibility for existing project files. The sentence under review is on the story branch.

**Fix:** Revise the summary to say that ignore rules also apply to existing untracked paths when they match. Document the existing root symlink case in the `/AGENTS.md` bullet.
