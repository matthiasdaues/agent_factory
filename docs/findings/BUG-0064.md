# Claude Code token counts are inflated

**What is wrong:** Claude Code writes one transcript line per content block, and each line repeats the message's usage. The normalizer adds every line. On a real transcript, output tokens came to 7,611 instead of 3,982, and cache reads to 574,421 instead of 372,773. Source: [bug-hunt report § U-5](../reviews/bug-hunt-2026-10-15.md#u-5--claude-code-token-counts-are-inflated).

**Fix:** Count usage once per message ID.
