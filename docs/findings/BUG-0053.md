# Block-style `concerns:` escapes two gates

**What is wrong:** Invalid concern names written as a nested block mapping pass both gates. The same names in flow style are caught. Source: [bug-hunt report § L-4](../reviews/bug-hunt-2026-10-15.md#l-4--block-style-concerns-escapes-two-gates).

**Fix:** Parse nested block mappings, or report frontmatter lines the parser cannot read.

**Resolution:** Fixed in commits `cfc0332a607c96aaf2ae03649cdc1bad17896967`, `410dcca63c47206cc130af3c147d0dfc401fa337`, merged into `dev` as `3921e522cc31f7fd454d9c908c9e8e42ceb201fe`. The full suite passed after the merge.
