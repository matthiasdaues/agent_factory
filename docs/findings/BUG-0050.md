# `conjecture-lint` matches markers inside other words

**What is wrong:** "The Arduino platform supports the Singapore protocol" is flagged, because "arduino " contains "no ". Source: [bug-hunt report § L-14](../reviews/bug-hunt-2026-10-15.md#l-14--conjecture-lint-matches-markers-inside-other-words).

**Fix:** Match whole words only.

**Resolution:** Fixed in commits `292b913a1714f00ec71d88945c07103c98d64a82`, `9e8b8a38436843d0a81c8d83d009735410fce780`, `3f0c0895cd2d24646054e7047243b93fa1f4640e`, merged into `dev` as `3921e522cc31f7fd454d9c908c9e8e42ceb201fe`. The full suite passed after the merge. "must-not" counts as an explicit marker. Known gap: the leading-negation pattern still ends in `\b`, so a claim opening with "No-op" skips the bundle check.
