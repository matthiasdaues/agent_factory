# Agents in linked worktrees find no factory tooling

**What is wrong:** `.gitignore` excludes `/.agent-factory/`, `/.current-work/`, `/.github/INDEX.yaml`, and `/.github/{agents,hooks,playbooks,rulebooks,scripts,skills}`. A linked worktree therefore holds no factory tooling and no INDEX.yaml. In an onboarding run both dispatched agents halted on this, as the rules require, and each halt cost a dispatch cycle.

**Fix:** Require absolute paths into the primary checkout in the brief-file section of the dispatch contract, or make the factory discoverable from linked worktrees.

**Resolution:** Merged into `dev` with the brief-storage run; fixed in commit `7fc3ae57`, and the full suite passed. The Brief File section of `dispatch-contract.md` requires a brief to name factory inputs by absolute path under `<main checkout>/.agent-factory/factory/`, and to keep briefs and scratch files under `.current-work/<branch>/` in the main checkout. Making the factory discoverable from a linked worktree by other means was not done.
