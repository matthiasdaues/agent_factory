# `index-lint` rejects the one-line `any_of` form with a misleading message

**What is wrong:** `- any_of: [{type: a, path_pattern: x}]` is valid YAML, and the engine accepts it. `index-lint` reads it as a string and reports "must be a non-empty list of alternatives". Source: [brownfield onboarding run](../reviews/brownfield-onboarding-run-2026-10-16.md), review of ST-0313.

**Fix:** Parse the flow form, or name the block form in the error.
