# `reverse-map` has no unattended mode

**What is wrong:** The skill expects a stakeholder who confirms its findings in batches. It documents no unattended mode, so a subagent can run it only by improvising.

**Fix:** Document an unattended mode that marks its output `draft pending confirmation`, the convention the scope map already uses.

**Resolution:** Fixed in commits `920b5f0d29f670c3a5471ff735f656d2f1aeb51e`, `7bfde68c34e132cc5012e14d1fbbc4232ca8f2a8`, `7ae4b5f2e866c71d0be3e5d3d0be2312c22b755f`, merged into `dev` as `55ece0a7d9984e7e4f77e5fc69723d0083a73e66`. The full suite passed after the merge. `reverse-map` has an unattended mode that writes `status: draft`; the Stage 1 exit fails on `SCOPE001` and on a `spec-lint` crash. Known gap: the exit command uses `<<<` and the playbook does not say it needs bash.
