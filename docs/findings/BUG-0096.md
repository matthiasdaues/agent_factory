# `reverse-map` has no unattended mode

**What is wrong:** The skill expects a stakeholder who confirms its findings in batches. It documents no unattended mode, so a subagent can run it only by improvising.

**Fix:** Document an unattended mode that marks its output `draft pending confirmation`, the convention the scope map already uses.
