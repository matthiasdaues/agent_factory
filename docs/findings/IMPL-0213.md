# The fallback instructions also enable dispatch for tiers deliberately left out

**What is wrong:** A reader who omits a tier to block dispatch can enable that tier while setting up a default for another tier. The model matrix reference tells readers to omit tiers they never want to reach. Its new paragraph presents `auto` as a step for one tier without saying that the setting covers the entire matrix.

In a scratch matrix, omitting `copilot.strong` under `halt` made `resolve-model` exit 2. To enable the default for `claude.standard`, the review removed that row and set `on_missing = auto`. Resolving either tier then returned empty output and exit 0. The same policy in `trigger` omits the model argument for both requests.

**Why this severity:** The reference gives a procedure that defeats the reader's stated goal of blocking an omitted tier. The instructions are on the story branch.

**Fix:** State in the tutorial and reference that `auto` applies to every missing CLI and tier pair. Qualify the advice about blocking dispatch by omitting a row with `on_missing = halt`.
