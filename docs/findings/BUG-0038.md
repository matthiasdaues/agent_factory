# The ledger's branch_head is never updated

**What is wrong:** Only `init` sets `branch_head`. `merge-story` and
`close-wave` do not update it, so `prepare-wave` cuts the next wave's stories
from the original root instead of the merged head. The dispatch contract says
`branch_head` is updated after each merge and wave closeout. Source:
[bug-hunt report § D-3](../reviews/bug-hunt-2026-10-15.md#d-3--the-ledgers-branch_head-is-never-updated).

**Fix:** Set `branch_head` to the merge commit in `merge-story` and to the
closing head in `close-wave`. Add a test that reads the ledger after a merge.
