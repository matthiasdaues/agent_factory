# Usage transcripts are readable by other local users

**What is wrong:** capture persists exact prompts, reasoning, and tool results
as plaintext using process-default directory permissions, while session JSONL
files are explicitly created with mode `0644`. On a multi-user host with a
permissive umask, another local account can read secrets present in transcripts,
including credentials returned by tools or pasted into prompts. The local and
git-ignored location prevents repository disclosure but does not enforce local
confidentiality. This is OWASP A02: Cryptographic Failures / Sensitive Data
Exposure, Medium severity.

**Fix:** Create usage and transcript directories with mode `0700` and files
with mode `0600`, using atomic no-follow operations and correcting permissions
on existing Factory-owned paths where safe. Document that full normalized text
is retained, including a retention policy and an opt-out or redaction mechanism.
Add permission regressions independent of the caller's umask.

**Resolution:** Every Factory-owned usage, control, scratch, record,
reservation, and transcript directory/file now uses exact owner-only modes:
`0700` directories and `0600` files. Creation is followed by no-follow
permission repair, so both permissive and restrictive umasks produce the same
result. Existing owner-owned paths are repaired; symlinks, foreign-owned
entries, and unsafe hard links are rejected or skipped rather than followed.
Pi applies the same modes to its transient registration metadata and staged
stream, and removal protects its owner/state artifacts.

Transcript retention resolves in this order: direct CLI option, environment,
secure project config, then `full` on POSIX. `omit` still normalizes the entire
run and persists all normalized/provider totals and context, but leaves the
exclusive evidence reservation empty with `span: content-omitted`. Invalid
configuration and platforms without enforceable owner-only mode semantics fail
closed to omission rather than disabling accounting. `init-factory` creates or
preserves the secure project setting via `--usage-transcript-retention`.

Records and full or omitted evidence remain until explicit per-session deletion
or `remove-factory`; there is no automatic TTL. Pi scratch text is deleted after
processing, with owner-only crash remnants removed manually or by uninstall.
Regex redaction is deliberately not offered because it can miss secrets;
accounting itself cannot be disabled.
