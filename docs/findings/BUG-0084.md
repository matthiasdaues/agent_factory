# A partial failure in `prepare-wave` blocks the story for good

**What is wrong:** When `worktree add` or `verify-base` fails, the branch made with `git branch` remains. Every retry fails with "A branch named 'story/ST-0001' already exists". This also breaks the rule that a branch and its worktree are created together. Source: [bug-hunt report § D-6](../reviews/bug-hunt-2026-10-15.md#d-6--a-partial-failure-in-prepare-wave-blocks-the-story-for-good).

**Fix:** Use `git worktree add -b`, and roll back or reuse on retry.
