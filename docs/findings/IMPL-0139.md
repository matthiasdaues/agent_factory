# The manual dispatch how-to gives conflicting instructions about who pushes

**What is wrong:** The operator gets two directions about who pushes after
a story merge. Step 7 asks the operator to push, but the new paragraph says
the implementation agent runs every command. The dispatch rule assigns
ordinary pushes in a run by hand to the human.

**Why this severity:** ST-0453 requires the handbook to describe the current
workflow. The conflict obscures who acts at the handoff. The claim that
the agent runs every command is new on the story branch.

**Fix:** Limit the agent’s role to the listed dispatch commands and name the
human as the person who pushes. If the page repeats the push rule, cite
[Dispatch](../../packages/factory/rulebooks/rules.md#dispatch) in a rule summary.
Describe the two approval stops as part of the successful story path. Link
to [Stops by hand](../../packages/factory/agents/implementation-agent.md#stops-by-hand)
for the other stops.
