# `scope-lint` syntax differs per file type and fails in worktrees

**What is wrong:** A `.md` file declares its scope in YAML frontmatter, a `.feature` file in a first-line `# scope:` comment, and a `.dsl` file in a `// scope:` comment. Valid workstream IDs come from `.agent-factory/workstreams`, which is ignored by git and so missing in any linked worktree. There, `global` is the only usable value.

**Fix:** Use one declaration syntax where the file format allows it. Read the workstream IDs from a location that linked worktrees can see.
