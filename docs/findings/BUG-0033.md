# Capture hooks look for the usage runtime in the old layout

**What is wrong:** The Claude, Codex, and Copilot capture hooks check `$PROJECT_DIR/factory/scripts/usage-capture-runtime`, and the Pi bootstrap expects `<root>/factory/scripts/usage-capture-runtime`. The directory `factory/` no longer exists; installs put scripts under `.agent-factory/factory/scripts/`. Each hook exits 0 without a message and records nothing. Source: [bug-hunt report § X-1](../reviews/bug-hunt-2026-10-15.md#x-1--capture-hooks-look-for-the-usage-runtime-in-the-old-layout).

**Fix:** Point `capture-usage.sh`, `capture-codex-usage.sh`, `capture-copilot-usage.sh`, and `pi-capture-bootstrap.mjs` at `.agent-factory/factory/scripts/usage-capture-runtime`. Add a test that runs a hook against an installed layout.

**Resolution:** Fixed in commit `9c65b3b57bd488c026f6e3871093895c7e7d8cd5`,
merged into `dev` as `e159bd4056a8f4eb306791773f20f24156a36e07`. A code
review ran capture end to end in a scratch project with the installed
layout, and a Claude Stop event and a Pi bootstrap call each wrote a record.
The full suite passed after the merge.
