# usage-capture-runtime finds the project root one level too low

**What is wrong:** The launcher sets `PROJECT_DIR` two levels above its own directory. From `.agent-factory/factory/scripts/`, that is `.agent-factory/`, so it looks for `.agent-factory/.agent-factory/usage/runtime` and exits 70 on every capture. Source: [bug-hunt report § U-1](../reviews/bug-hunt-2026-10-15.md#u-1--usage-capture-runtime-finds-the-project-root-one-level-too-low).

**Fix:** Go up three levels. Add a test that runs the launcher from an installed layout and expects it to find the runtime.
