# The proposal page drops the reacceptance requirement for material changes

**What is wrong:** A reader who changes an accepted proposal cannot tell from
the handbook page that the proposal needs reacceptance. The revised paragraph
replaces that requirement with a link to the template. The new callout covers
entry into the accepted state and leaves out what happens after a material change.

**Why this severity:** Acceptance criterion 12 requires the mapped page to
retain the guide's facts. The guide's Proposals section states that material
planning changes require reacceptance.

**Fix:** State in a rule summary that material changes after acceptance return
the proposal to `open` for reacceptance. Cite the
[proposal template](../../packages/factory/rulebooks/templates/proposal.md).
