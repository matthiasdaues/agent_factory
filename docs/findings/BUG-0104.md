# `dispatch --ledger` help text is wrong

**What is wrong:** The help says the default ledger is "derived from current branch" (`dispatch:2031`). `_default_ledger` takes the single ledger under `.current-work/`; with two ledgers it falls back to a path that does not exist, and `merge-story` fails.

**Why this severity:** `_default_ledger` now picks the ledger of the current branch and raises `LedgerChoiceError`, which names the ledgers it found. So the help text is correct, the missing-path failure is gone, and nothing remains to change.

**Fix:** Derive the ledger from the current branch as the help says, or correct the help and name the fallback in the error.
