# The Pi bootstrap leaks its pending marker and transcript copy

**What is wrong:** The bootstrap rejects the launcher path it is given. Because `ctx` is never set, the cleanup does nothing, and the marker and transcript copy stay behind without a message. Source: [bug-hunt report § U-3](../reviews/bug-hunt-2026-10-15.md#u-3--the-pi-bootstrap-leaks-its-pending-marker-and-transcript-copy).

**Fix:** Correct the path, and clean up whenever the marker passed validation.
