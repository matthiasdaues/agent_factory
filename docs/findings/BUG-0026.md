# Two stories declare an unsupported quality gate

**What is wrong:**
[`ST-0217`](../../backlog/ST-0217.md) and
[`ST-0221`](../../backlog/ST-0221.md) declare `mutation-analysis`, while the
canonical backlog schema accepts `mutation-testing`. `backlog-lint` therefore
reports two `BL-ENUM` errors and the repository cannot pass its deterministic
validation suite.

**Fix:** Replace `mutation-analysis` with `mutation-testing` in both story
frontmatter declarations and rerun `backlog-lint`.
