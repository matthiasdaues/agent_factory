# The Gates pass row of `premerge-check` passes a survivor that BR-066 now fails

**What is wrong:** Commit `383abb1d` adds a condition to BR-066. The mutation gate passes after a non-zero exit only when every survivor has one of the three actions of the `mutation-testing` skill. A survivor with any other action, such as `none-required`, counts as unresolved. `_entry_problem` in `packages/factory/scripts/mutation-testing` fails such a survivor. The same commit points the row `mutation-testing` of § Gate result files to that rule.

The row "Gates pass" of the Story merge table in `docs/spec/interface-contracts.md` § premerge-check did not change. It lists the conditions of a pass in full: the command ran within the time limit, the list `mutants` holds a survivor, no entry has `resolution_action: unresolved`, and each `finding` names a file at the head of the story branch. Under that list, a survivor with `resolution_action: none-required` passes.

Take ST-0350 with one survivor in `src/login.py:42` whose entry says `none-required`. BR-066, § Gate result files and the code refuse the merge. The Gates pass row lets it merge. A test writer who follows the row writes a test that expects a pass, and the test fails against correct code.

**Why this severity:** No story or code outside the run encodes the row (in_use: false). Two statements of `docs/spec/interface-contracts.md` contradict each other, and a reader who follows the row reaches a wrong result (fails_purpose). No pending story owns the row. ST-0430 changes words only, and ST-0423 is done.

**Fix:** Add "every survivor has one of the three actions of the `mutation-testing` skill" to the conditions of the row. Add the sentence "A survivor with any other action, such as `none-required`, counts as unresolved (BR-066)." The row may also say that `premerge-check` takes only `mutants` from the stored result, as § Gate result files says.

**Verified (2026-11-19, spec review repeat pass, fix check):** The fix holds. Commit `a53b4444` adds "every survivor has one of the three actions of the `mutation-testing` skill" to the conditions of the Gates pass row. It also adds the sentence "A survivor with any other action, such as `none-required`, counts as unresolved and fails the gate." The row, § Gate result files, BR-066 and `_entry_problem` in `packages/factory/scripts/mutation-testing` now fail the same survivor. The status is now `resolved`.
