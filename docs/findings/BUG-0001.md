# Survey fixture accepts source records outside its run

**What is wrong:** `_resolve_survey_findings` joins each report reference to the
run directory without resolving and containing the result. An absolute path or
`../` traversal can therefore select any JSON file outside the survey run; a
symlink below `source-records/` can escape in the same way. If that file has a
`source_family`, the supposedly unsupported reference passes. The end-to-end
proof therefore does not establish that every finding resolves to a source
record supplied by this survey.

**Fix:** Add regression coverage for traversal, absolute-path, and symlink
escapes. Resolve each candidate and reject it unless its canonical path remains
below the run's canonical `source-records/` directory. Keep missing references
as deterministic failures, then rerun the complete survey and falsification
research suites.

**Resolution:** The fixture resolver now canonicalizes the survey's
`source-records/` directory and every referenced path, rejects candidates
outside that boundary, and still rejects missing files. A parameterized
regression proves that relative traversal, absolute paths, and a symlink below
`source-records/` cannot escape to an otherwise parseable JSON record. The
complete survey and falsification research suite passes 170 tests.
