# Handbook descriptions use fragments in place of sentences

**What is wrong:** A reader scanning handbook entries finds labels where the page format calls for descriptions in complete sentences. Examples include `The packages, the install model, and the engine.` and `The frontmatter fields and the page types of both handbooks.` The same pattern appears in chapter indexes and the `sources.md` pages.

**Why this severity:** BR-140 requires one sentence in each supplied description. The QA strategy assigns this check to the reviewer. The affected descriptions are new on the story branch.

**Fix:** Rewrite the fragment descriptions as complete sentences. Regenerate the handbook lists so the displayed descriptions match.
