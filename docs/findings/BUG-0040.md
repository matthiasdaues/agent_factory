# Source-repository hooks fail in every worktree

**What is wrong:** The source-repository hooks `mdformat`, `link-check`,
`spec-lint`, `arch-lint`, `backlog-lint`, `concern-lint`, and
`statemachine-lint` run scripts from the untracked installed copy under
`.agent-factory/`. A worktree or a fresh clone has no such directory, so each
hook fails with "No such file" as soon as a matching file changes. Every
worktree commit that touches markdown is blocked, and the hooks check the
installed scripts instead of the source. Source:
[bug-hunt report § G-9](../reviews/bug-hunt-2026-10-15.md#g-9--seven-source-repository-hooks-fail-without-agent-factory).

**Fix:** Run the scripts from `packages/factory/scripts/`, as the
`index-lint` hook does. Add a test that no source-repository hook entry
calls `.agent-factory/factory/scripts/`. The `matrix-lint` hook belongs to
[BUG-0029](BUG-0029.md).
