# The manual dispatch how-to skips required ledger steps

**What is wrong:** A reader following the new numbered procedure cannot merge
the story. Steps 2 and 3 leave the entry in `prepared`. Step 5 calls
`dispatch merge-story`, which requires `dispatched`
(`packages/factory/scripts/dispatch:2647`). The procedure also ends at the
push, but the next story cannot start until the implementation agent closes
the current story's wave.

**Why this severity:** The how-to stops before its stated result. ST-0453
requires the handbook to describe the current workflow. The page is new on
the story branch.

**Fix:** Follow the [implementation agent's run-by-hand workflow](../../packages/factory/agents/implementation-agent.md#workflow--run-by-hand).
Include the ledger transitions, commit verification, gates, and wave close.
Mark which steps the implementation agent runs and where the reader gives
approval.
