# The handoff contract names bare `uv run pytest` as the test command

**What is wrong:** ST-0314's handoff contract named `uv run pytest`; the factory hook blocks bare `pytest`, and the briefs require `pre-commit run run-tests --all-files`. `init-factory` asks for the canonical test command only when it finds several, and a blank answer leaves the gap.

**Fix:** Take the test command from `docs/testing.yaml` and fall back to the pre-commit form.
