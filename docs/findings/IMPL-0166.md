# The output format table hides the CLI fallback for relation and Arrow

**What is wrong:** A reader can take the five entries under Output formats to mean that `usage-query --format relation` returns a relation and `--format arrow` returns an Arrow table. The CLI accepts these values but prints JSON, and it directs the user to the Python API when preflight ran.

**Why this severity:** The story requires an accurate reference for the current CLI and the programmatic output formats. The affected documentation is on the story branch.

**Fix:** State that the relation and Arrow objects come from the Python API. Describe the CLI's JSON fallback for those flags.
