# Tests check the installed scripts, so they fail in worktrees and miss source changes

**What is wrong:** `tests/conftest.py:16` sets
`SCRIPTS_DIR = INSTALLED_SCRIPTS_DIR`, and four test files in `tests/factory/`
build script paths from `.agent-factory/`. The directory `.agent-factory/`
holds the installed copy and is not tracked. This has two effects:

1. A new worktree has no `.agent-factory/`. On branch
   `feature/update-keeps-init-manifest`, the commit hook failed 51 tests in
   `test_characterization_checks.py`, `test_characterization_safety.py`,
   `test_context_lint.py`, `test_context_lint_legacy.py`,
   `test_format_detection.py`, and `test_testing_yaml_resolution.py`. Clean
   `dev` passed the same tests in the main checkout. The commit passed only
   after the main checkout's `.agent-factory/` was linked into the worktree.
   The branching rules require worktrees for automated work, so every
   automated commit hits this.
2. In the main checkout, these tests check the installed scripts. A change to
   a script under `packages/factory/scripts/` is not tested until the next
   install.

**Fix:** Point `SCRIPTS_DIR` and the four hard-coded paths at
`packages/factory/scripts/`. Then run the test hook in a new
worktree with no `.agent-factory/` and expect it to pass.

**Correction:** The first version of this finding counted 13 test files. Only
`tests/conftest.py` and four test files used the real installed copy. The
other matches build a fake install in a temporary directory. The first
version also proposed a fallback to the installed copy for consumer
projects. `tests/` exists only in the factory source repository, so no
fallback is needed.

**Resolution:** Commits `e87264fdfc217670fce9479170e0298b55db2d70` and
`99dad9762a2392c893ade6fb7b3c109f7a027a6e` point the tests at the source
scripts and remove the fallback to the installed copy from `load_script` and
`sys.path`. The test hook passed in a new worktree without `.agent-factory/`.
The fix was merged into `dev` as `15998d9e160d0a923c61265d2c72d9ec7fc3b032`,
and the full suite passed after the merge. The fix needed the root change
from [BUG-0030](BUG-0030.md), so both bugs were fixed on one branch.
