# A story branch cannot take in the moved invocation branch

**What is wrong:** `merge-story` runs `premerge-check <invocation branch> <story branch>`. Its stale-base check requires the story branch to contain
every commit of the invocation branch. After the first story of a parallel
wave merges, every other story of that wave fails the check. `dispatch` has
no step that brings a story branch up to date. A manual merge of the
invocation branch into the story branch needs a premerge marker, and
`premerge-check <story branch> <invocation branch>` blocks it, because the
invocation branch does not contain the story's own commits.

`verify-base <invocation branch>` fails the same way for every agent that
must commit on a story branch after the invocation branch moved, such as a
fix agent after a review.

**Reproduction:** In the bug-hunt fix run, one commit on
`feature/bug-hunt-fixes` (`879a0af1`) made every story stale.
`premerge-check story/ST-0303 feature/bug-hunt-fixes` printed:

```
BLOCK stale-base-signature: 'feature/bug-hunt-fixes' is missing 2 commit(s) present on 'story/ST-0303'
```

**Fix:** Add `dispatch refresh-story <id>`. It merges the invocation
branch tip into the story branch inside the story's worktree. On a conflict
it aborts the merge and marks the story blocked. `merge-story` calls the
same step before `premerge-check` when the story branch lacks the
invocation tip.

**Resolution:** Fixed in commits `b3feda1cf7a32f297628cd44ff5176f952370a93` and `633db168e35c2f9fdaf446a59579a50ddc057424`, merged into `dev` as `d22b613c90872c8f313669012ec51725e38b7cda`. `dispatch refresh-story <id>` merges the invocation tip into the story branch in its worktree. It refuses a dirty worktree, a worktree on another branch, a story outside the states prepared, dispatching, and dispatched, and a story whose `merge-story` was interrupted. On a conflict it aborts and blocks the story. `merge-story` refreshes first, except when it recovers an interrupted merge. `premerge-check` is unchanged. Known gap: a deleted worktree directory is reported as a detached HEAD. The full suite passed after the merge.
