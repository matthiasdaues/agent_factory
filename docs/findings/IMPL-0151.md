# The README route check accepts a stub as the tutorial

**What is wrong:** The FH-07 check can pass after the README’s only tutorial is replaced with a stub. It tests the destination’s `type` and accepts `status: stub`. In the scratch clone, replacing the tutorial body with a one-sentence stub and setting its status to `stub` left `test_st_0456_contributing_section_links_to_the_tutorial` green.

**Why this severity:** The owned check can report success while the journey it verifies is unavailable. The check is new on the story branch.

**Fix:** Require an implemented tutorial as the destination. Resolve the link path before checking that it lies under `docs/handbook/getting-started/`.
