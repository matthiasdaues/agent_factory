# The install inventory overstates which project files remain visible to Git

**What is wrong:** A maintainer following the inventory can overlook a project-owned Copilot hook that Git ignores. The inventory says only paths the installer creates are ignored under `.github/`. The Copilot installer adds `.github/hooks` to the ignore block when that directory already exists. In a test repository, `git check-ignore -v .github/hooks/project-owned.json` matched the generated rule for an untracked file present before the block was written.

**Why this severity:** The moved inventory gives the wrong Git status for files covered by installer directory rules. The change exists only on the story branch.

**Fix:** Describe the directory-level rules for Copilot hooks and agents. Distinguish files already tracked by Git from untracked files covered by those rules.
