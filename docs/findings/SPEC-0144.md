# The chapter sort has no rule for equal order and title

**What is wrong:** Two chapters may use the same index title and omit order. BR-145 gives them identical sort keys. Different directory traversal orders can then produce different results for the same handbook, and --check compares the resulting text. [docs/spec/validation-rules.md:657](../spec/validation-rules.md)

**Why this severity:** An implementer must choose a final ordering or a new validity rule, and a test author cannot derive the expected list. No code or completed story outside the run encodes this review target.

**Fix:** Keep the decided order and title keys. Specify a stable final key, such as the chapter path, and test two chapters with identical order and title.
