# `handoff-lint` exit codes break the contract

**What is wrong:** An empty handoff exits 8, the finding count. A missing file exits 1 instead of 2. Source: [bug-hunt report § L-12](../reviews/bug-hunt-2026-10-15.md#l-12--handoff-lint-exit-codes-break-the-contract).

**Fix:** Exit 1 for findings and 2 for usage errors.
