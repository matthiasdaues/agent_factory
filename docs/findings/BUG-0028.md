# Requirements remediation manifest excludes required findings and proposal output

**What is wrong:** The
[`feature-addition` update-specification step](../../packages/factory/playbooks/feature-addition.md)
does not admit `docs/findings/SPEC-*.md` as input or
`docs/proposals/**/*.md` as output. A Requirements Agent returning from a failed
specification review therefore cannot read the defects it must remedy or correct
an accepted proposal whose internal contract caused a finding.

**Fix:** Add `docs/findings/SPEC-*.md` to the update-specification inputs and
`docs/proposals/**/*.md` to its outputs. Extend the playbook contract test to
prove both paths remain available, regenerate the Factory index, and rerun the
relevant deterministic gates.
