# Consumer gates pass without running in worktrees

**What is wrong:** Every consumer hook starts with
`[ -d .agent-factory ] || exit 0`, so teammates without the factory can
commit. A linked worktree has no `.agent-factory/` either, because the
directory is untracked and lives only in the main checkout. In a worktree,
every Factory gate therefore reports "Passed" without running. Automated
work is committed in worktrees, so it skips all Factory gates. Source:
[bug-hunt report § G-10](../reviews/bug-hunt-2026-10-15.md#g-10--consumer-gates-pass-without-running-in-worktrees).

**Fix:** Look for `.agent-factory/` in the current checkout first, then in
the main checkout through `git rev-parse --git-common-dir`. Skip only when
neither has it. Add a test that runs a consumer hook entry from a linked
worktree and expects the gate script to run.
