# Greenfield and brownfield gates depend on the retired charter

**What is wrong:** The greenfield playbook expects a bare `capture-context`
call to write Epic 0 stories. Called without flags, that skill migrates
legacy YAML and writes no stories. Both playbooks then run
`charter-lint --planning-gate`, which exists nowhere, so the greenfield gate
can never pass. `rules.md` still requires Epic 0 from the charter and the
charter's house rules. The implementation agent schedules Epic 0 as wave 1,
and three skills name `update-charter` or `capture-charter`, which do not
exist. Source:
[bug-hunt report § R-1](../reviews/bug-hunt-2026-10-15.md#r-1--the-greenfield-and-brownfield-gates-depend-on-the-retired-charter).

**Fix:** The stakeholder decided on 2026-10-15 to drop Epic 0. Setup work
becomes a line item inside the first story that needs it, as
`create-backlog` already requires for all other infrastructure. Replace the
charter gates with `concern-lint` and stakeholder approval of
`docs/agent-context.md`. Remove the Epic 0 and charter rules, the wave-1
scheduling, and the references to skills that do not exist.
