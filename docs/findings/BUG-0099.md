# No template tells an author to declare a scope

**What is wrong:** No template or skill tells an author to write a scope declaration in a new spec, feature or DSL file, so new files fail `scope-lint` once it runs.

**Fix:** Add the declaration to the templates and name it in the skills that create these files.
