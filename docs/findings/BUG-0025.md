added the required `valid_risk_levels` argument to
[`check_story`](../../packages/factory/scripts/backlog-lint), but its direct
callers in
[`test_backlog_lint.py`](../../tests/factory/test_backlog_lint.py) still use the
old signature. The full test suite therefore fails 23 tests with `TypeError`,
blocking every hook-governed commit.

**Fix:** Update every direct unit-test call to pass the default risk-level set,
then run the focused backlog-lint tests and the full suite.
