# The Stage 1 exit command needs bash, and the playbook does not say so

**What is wrong:** The Step 2.6 command uses `<<<`. Under `/bin/sh` it fails for every project with `Syntax error: redirection unexpected`, a confirmed map included. It fails closed, but the cause is hidden. Source: [brownfield onboarding run](../reviews/brownfield-onboarding-run-2026-10-16.md), review of ST-0314.

**Fix:** Say "in bash", or use `printf '%s\n' "$out" | grep -q SCOPE001`.
