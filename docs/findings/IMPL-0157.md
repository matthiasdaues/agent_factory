# The entry-point checks accept a chapter index and missing commands

**What is wrong:** FH-06-LN-01 can report success when the tour opens the chapter index and the README contains no runnable commands. The tour test checks only a directory substring. The README test checks the three command names anywhere in the text. In a scratch copy, all 15 checks passed after the tour was pointed at `getting-started/index.md` and the README was reduced to command names in prose plus one handbook link.

**Why this severity:** The text checks do not enforce two behaviors owned by FH-06-01. Both regressions produce a passing result.

**Fix:** Check that the procedure resolves to an implemented tutorial page, such as `getting-started/first-session.md`. Check for each runnable invocation in the README command blocks.
