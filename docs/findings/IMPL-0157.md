# The entry-point checks accept invalid tutorial paths and command names

**What is wrong:** FH-06-LN-01 can pass when newcomers are sent to a
missing tutorial and the README shows commands that do not exist.
`tutorial_pages` stops matching at `.md`, so it accepts
`first-session.md.bak` as `first-session.md`. In `runnable_commands`, the
word boundary also matches before a hyphen, so `init-factory-missing`
counts as `init-factory`. Both assertions passed when the review supplied
those changes in memory and appended `-missing` to all three commands.

**Why this severity:** FH-06-LN-01 owns the check for the tutorial source
and the README commands. It reports success when both entry points break.

**Fix:** In the tour procedure, match the full backtick-delimited tutorial
path and check the file it names. In each README command block, compare
the full command token to the three supported script names. Add regression
cases for the filename and command suffixes.
