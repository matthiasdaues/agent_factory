# Phantom dependency on factory/scripts/validate

**What is wrong:** Phase 3's subagent handoff contract Part 5 lists "Required checks -- test_command, then factory/scripts/validate" as a mandatory step for every developer-agent. No script named `factory/scripts/validate` exists in the repository. It is not listed in the proposal's `impact.boundaries`, not listed in the Phase 1 or Phase 2 scope, and not mentioned in the "Explicitly deferred" list. The dispatch script would generate prompts referencing a nonexistent script, causing every developer-agent to fail its required checks.

**Fix:** Either (a) add `factory/scripts/validate` to the Phase 1 scope and `impact.boundaries` as a prerequisite, specifying what it validates, or (b) replace the reference with the actual validation mechanism (e.g., `backlog-lint`, `spec-lint`, or the test suite alone), or (c) remove it from the handoff contract if test_command is sufficient.
