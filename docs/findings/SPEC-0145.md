# The migration repurposes the spec-writer path guard

**What is wrong:** FH-11-01 says the checks in all three named test files read handbook pages containing the text under test. In test_core_layout_references.py, test_spec_writer_file_names_no_old_path scans a list of spec-writer files for forbidden paths. The guide is one scan target. [docs/spec/features/factory-handbooks.feature:564](../spec/features/factory-handbooks.feature)

**Why this severity:** Following the scenario literally can replace the spec-writer scan with a handbook content assertion and drop coverage of the other files. No code or completed story outside the run encodes this review target.

**Fix:** Keep the full spec-writer scan and replace only its retired guide target with the relevant handbook path. Keep the original content assertions in the other two tests.
