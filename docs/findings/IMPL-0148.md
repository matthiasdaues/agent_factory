# The page-format reference lists values that lint rejects

**What is wrong:** An author can follow the field table and still fail handbook lint. The table calls `order` a number, which includes `2.5`, and describes `title` as text without the non-empty constraint. BR-140 and the linter reject both a decimal order and an empty title.

**Why this severity:** The page is the contributor’s lookup reference for accepted fields. It gives the wrong value domain for required behavior on the story branch.

**Fix:** List `title` as a non-empty string and `order` as an integer with default 100.
