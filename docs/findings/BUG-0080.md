# `commit-safe` commits unrelated changes

**What is wrong:** After a hook modifies files, the second pass runs `git add -u`, which stages every modified tracked file. Work in progress in another file ended up in the commit. `commit-safe -m` without a value exits 1 and prints nothing. Source: [bug-hunt report § G-8](../reviews/bug-hunt-2026-10-15.md#g-8--commit-safe-commits-unrelated-changes).

**Fix:** Re-stage only the paths that were staged before the first pass.
