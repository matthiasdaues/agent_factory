# `context-lint` misjudges `testing.yaml` in both directions

**What is wrong:** Valid YAML with a block scalar fails `CX-PARSE`. Invalid YAML with an unclosed quote and bracket passes. Source: [bug-hunt report § L-13](../reviews/bug-hunt-2026-10-15.md#l-13--context-lint-misjudges-testingyaml-in-both-directions).

**Fix:** Parse with a YAML library.

**Resolution:** Fixed in commits `84dad3b5480deca1140394da342603ea309a2a2b`, `47e1d1f8aac02e63cebd026174319dbd89d6838a`, `da6dbb7c7cc39c4f114992279dc1a33bb4a13002`, merged into `dev` as `3921e522cc31f7fd454d9c908c9e8e42ceb201fe`. The full suite passed after the merge. `context-lint` declares PyYAML and guards the import: without it, one line on stderr and exit 2.
