# Factory hooks pass silently when the factory folder is missing

**What is wrong:** Each factory hook entry begins with `[ -d "$AF" ] || exit 0`. When `.agent-factory/` is missing or at another path, every gate passes without a word, so a broken install looks like a clean commit.

**Fix:** Print a warning on stderr when the folder is missing. Whether the hook should fail instead is a question for the gate proposal.

**Resolution:** Fixed in commit `dd2fe296` on `feature/factory-hook-fixes`; the full suite passed. `init-factory` sets `agent-factory.installed` in the clone's local git config and `remove-factory` unsets it. When the key is set and `.agent-factory/` is missing, every factory hook fails with a message naming `update-factory` and `SKIP`; without the key, a colleague without the factory still passes in silence.
