# Factory hooks pass silently when the factory folder is missing

**What is wrong:** Each factory hook entry begins with `[ -d "$AF" ] || exit 0`. When `.agent-factory/` is missing or at another path, every gate passes without a word, so a broken install looks like a clean commit.

**Fix:** Print a warning on stderr when the folder is missing. Whether the hook should fail instead is a question for the gate proposal.
