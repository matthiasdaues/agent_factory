# Lint can pass after deletion of a required top-level index

**What is wrong:** BR-141 requires a top-level `index.md`, but its lint failure covers only folders that contain pages. The handbook root may contain only chapter folders after its index is deleted. The remaining chapter lists can all be current, so the gate can let the deletion through. [`docs/spec/validation-rules.md:650`](../spec/validation-rules.md)

**Why this severity:** A planner following the stated failure conditions can build a gate that passes a handbook without its entry page. No existing code or completed story implements this requirement.

**Fix:** Require `handbook-lint` to fail and name the missing top-level index path for either handbook. Add an acceptance case with one top-level index deleted and all chapter lists current.
