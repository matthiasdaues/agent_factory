# The rewrite misses valid destinations and edits incomplete links

**What is wrong:** A reader can follow a valid Markdown link to a deleted file. The scanner misses `[a [b]](docs/arc42/concepts.md)` and a reference definition whose destination follows `[x]:` on the next line. It also changes the incomplete string `[x](docs/arc42/concepts.md` because it skips closing delimiter validation.

**Why this severity:** The story covers every Markdown link and reference definition and limits the edits to link destinations. The change exists only on the story branch.

**Fix:** Recognize balanced labels and continued reference definitions. Require a complete inline link before accepting its destination span. Add tests for all three cases.
