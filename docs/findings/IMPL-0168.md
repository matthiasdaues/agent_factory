# The rewrite mishandles link queries and encoded fragments

**What is wrong:** A reader keeps a dead link when its old URL has a query. An encoded fragment can stop the rewrite. With the migration map, `[x](docs/arc42/concepts.md?plain=1#the-phase-chain)` yields no edit and `[x](docs/arc42/concepts.md#the%2Dphase%2Dchain)` raises `UnmappedAnchor`. The error starts in `_section_destination`. It includes queries in the path lookup and compares encoded fragments with decoded slugs.

**Why this severity:** BR-151 requires both destinations to move. The change exists only on the story branch.

**Fix:** Parse path, query, and fragment separately. Decode the fragment for the map and heading lookups. Keep the query and the spelling of a retained fragment. Add tests for both cases.
