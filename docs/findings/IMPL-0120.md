# A linked chapter lets the index command rewrite files outside the handbooks

**What is wrong:** A contributor can change an index outside either handbook by running the generator. The folder reader follows a chapter symlink, then the writer uses the same path. In scratch, a chapter symlink to a sibling directory caused generation to rewrite that directory’s index and exit 0.

**Why this severity:** ST-0452 confines both commands to the two handbook roots. The reader and writer were introduced on the story branch.

**Fix:** Check path containment before traversing directories or reading Markdown files. Reject out-of-root symlink targets with a path diagnostic before planning any writes.
