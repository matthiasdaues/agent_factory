# The docs say the step guard enforces step boundaries, but it never runs

**What is wrong:** The factory guide says the `step-guard` hook blocks a read
outside the step manifest before it completes. `AGENTS.claude.md` says step
guards run automatically. `rules.md` § Step boundaries reads as if a gate
enforced it. The guard never runs, and five separate faults would keep it from
enforcing anything even if it did. Agents and users therefore rely on a
safety net that does not exist. Source:
[bug-hunt report § G-1](../reviews/bug-hunt-2026-10-15.md#g-1--the-step-guard-never-runs-and-its-denials-would-not-block).
The faults and the design to fix them are in
[step-guard-enforcement](../proposals/step-guard-enforcement.md).

**Fix:** State in `rules.md`, the factory guide, and `AGENTS.claude.md` that
the step guard does not enforce step boundaries yet, and that agents keep to
them by discipline. Change the text again when the proposal is built.
