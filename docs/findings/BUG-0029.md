# Matrix and index pre-commit hooks cannot receive matching files

**What is wrong:** The consumer
[`matrix-lint` hook](../../packages/factory/config/pre-commit-config.yaml) filters
for `.agent-factory/config/model.conf`, while the installer deliberately
gitignores `.agent-factory/`. The consumer `index-lint` hook filters for files
under `.agent-factory/factory/`, which is also gitignored. Pre-commit evaluates
tracked staged files, so neither hook can receive a matching path. Running both
hooks with `--all-files` reports "no files to check." The source-repository
`matrix-lint` hook repeats the ignored runtime path instead of the tracked
`packages/factory/config/model.conf` source.

**Fix:** Remove `index-lint` from the consumer hook block because consumers do
not edit the installed Factory index. Run `matrix-lint` after model
configuration and before dispatch instead of using a staged-file trigger. Keep
the source-repository `index-lint` hook on tracked `packages/factory/**` inputs.
Change the source-repository `matrix-lint` hook to validate the tracked
`packages/factory/config/model.conf` file. Add regression tests that reject
consumer hooks whose file filters can match only ignored Factory runtime paths.
