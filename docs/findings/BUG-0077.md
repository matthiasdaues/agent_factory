# The bootstrap installer writes its header into the installed factory

**What is wrong:** For Codex, Pi, and Copilot installs, `AGENTS.md` is a symbolic link into `.agent-factory/factory/config/`. The installer writes its header through the link and marks the entry "injected". The next `update-factory` sees a user change and refuses to run without `--force`. Source: [bug-hunt report § I-3](../reviews/bug-hunt-2026-10-15.md#i-3--the-bootstrap-installer-writes-its-header-into-the-installed-factory).

**Fix:** Skip symbolic links and files that `init-factory` linked.

**Resolution:** Fixed in commits `f7dc19231c4fea7bae9e800b50f70efb63a46114`, `b04426564293da4516104db6a5d8d5e5ebaa1e78`, merged into `dev` as `3921e522cc31f7fd454d9c908c9e8e42ceb201fe`. The full suite passed after the merge.
