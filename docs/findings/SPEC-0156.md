# Link checks depend on a handbook absent from the main checkout

**What is wrong:** The strategy assumes linked worktrees can resolve the new installed paths through the main checkout. Its installed copy still has the guide and lacks the handbook. [`docs/spec/work/factory-handbooks-qa-strategy.md:220`](../spec/work/factory-handbooks-qa-strategy.md)

**Why this severity:** Following the test setup as written rejects correct rewrites. A shared main checkout can also hold a handbook from a different revision. No code or completed story outside this run encodes the affected test requirement.

**Fix:** Give both link checks an installed fixture populated from the reviewed tree. Resolve installed links against that fixture.
