# A commit that only deletes a finding file skips finding-lint

**What is wrong:** An agent can end a stop on a critical finding by committing `git rm docs/findings/<ID>.md` alone. The agent gets no refusal, and the stakeholder loses the stop without confirming it. A removed register file passes the same way.

The first point of loss is the trigger of the pre-commit hook. The line `files: ^docs/findings/` filters the list of staged files that pre-commit builds, and pre-commit leaves deleted paths out of that list. So the hook sees no matching file and does not run. The behavior looks wrong, not intended. BR-109 says such a file "is never removed in any other way", and BR-091 relies on `finding-lint` to reject a removal at the commit. The Hook row of `docs/spec/interface-contracts.md` § finding-lint prescribes the same filter, so the contract holds the gap too.

```text
git rm docs/findings/<ID>.md, and nothing else under docs/findings/ is staged
        ↓
pre-commit lists the staged files without deleted paths
        ↓
files: ^docs/findings/ matches nothing, so the hook is skipped
        ↓
finding-lint --staged never compares the index with HEAD
        ↓
the commit lands, HEAD no longer holds the finding, and the stop ends
```

The review reproduced this in a temporary repository with `pre-commit` and a local hook that has `pass_filenames: false` and `files: ^docs/findings/`. The hook always fails when it runs. The deletion-only commit printed `(no files to check)Skipped` and succeeded. A commit that modified the same file ran the hook and failed.

**Why this severity:** The hook exists to enforce BR-109 and BR-110 at the commit, and a deletion-only commit is the exact case those rules name, so it fails its purpose (`fails_purpose`). The hook lines exist only on `feature/finding-classification`, so the code is not in use and `harms_downstream` is false.

**Fix:** In `packages/factory/config/pre-commit-config.yaml`, replace `files: ^docs/findings/` with `always_run: true` on the hook `agent_factory_hook-finding-lint`. Change the Hook row in `docs/spec/interface-contracts.md` and the assertion `hook["files"] == "^docs/findings/"` in `tests/factory/test_precommit_config_contract.py` to match. Add a test that commits only a deletion and expects the hook to run.
