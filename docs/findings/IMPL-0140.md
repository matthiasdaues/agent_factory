# The pre-commit page presents a failing hook bypass as a repair option

**What is wrong:** A reader who follows the page can proceed with a commit
without the failing hook's check. The page presents the diagnostic's per-hook
skip as one of two ways out. It then claims a broken installation never lets a
commit through unchecked. The Git workflow rule requires fixing a failing hook.

**Why this severity:** ST-0453 requires the handbook to describe the shipped
workflow and respect its binding rules. This new handbook page gives advice
that conflicts with the Git workflow rule.

**Fix:** Keep the shipped diagnostic in the code example. Explain that the
message includes a skip option and direct the reader to repair the installation
with `update-factory`. Put the no-bypass rule in a rule summary sourced to
[Git workflow](../../packages/factory/rulebooks/rules.md#git-workflow).
