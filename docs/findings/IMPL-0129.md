# Binding rules appear in ordinary handbook prose

**What is wrong:** Readers cannot tell which workflow instructions are binding or where to check their scope. The plain sentence after the guardrail callout restates the branch verification rule. The author/reviewer and separate-sessions pages also state session separation in plain prose. The dispatch page does the same for the wave boundary. The usage-capture reference repeats the test ownership rule before its callout and drops the guide’s instruction for handling overlap with a lower-level test.

**Why this severity:** BR-149 requires a sourced callout for each binding rule a page repeats. The QA strategy classifies a violation as a failure of the story’s purpose. The handbook text is new on the story branch.

**Fix:** Put branch verification in the guardrail callout. Cite the agent lifecycle protocol for session separation and the dispatch contract for the wave boundary. Put the complete test ownership rule in its existing callout. Check the remaining plain prose against its rulebook sources.
