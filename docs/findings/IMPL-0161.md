# The browser guide promises offline setup while requiring a download

**What is wrong:** A reader without the DuckDB UI extension cannot follow the first-run steps offline. The opening promises both paths need no network connection, then the DuckDB UI steps require `INSTALL ui` and say it downloads the extension. The add-on concept also states the network claim without limiting it to analysis.

**Why this severity:** The story requires instructions that reflect how the two browser tools run. The first-run procedure contradicts the page's stated prerequisite. The affected documentation is on the story branch.

**Fix:** Distinguish local analysis from fetching the CLI or installing the UI extension. State the cache prerequisites for running the DuckDB UI offline.
