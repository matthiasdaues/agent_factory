# The migration map can send users to the contributor handbook

**What is wrong:** [FH-05-01](../spec/features/factory-handbooks.feature) checks only that each destination page exists. The [accepted completion criteria](../proposals/factory-handbooks.md#completion-criteria) require each section of the deleted guide to map to a user handbook page.

**Why this severity:** A test can pass a map that sends a guide section to `docs/handbook/`, which never ships to users. That answers yes to `fails_purpose`. No story or code outside this run encodes the new check.

**Fix:** Require every guide row to name a page under `packages/factory/docs/handbook/` in FH-05-01 and its [QA owner row](../spec/work/factory-handbooks-qa-strategy.md).

**Resolution:** FH-05-01 requires each guide row to name an existing user handbook page. The QA owner row traces to FH-05-01.
