# spec-lint REQUIRED_ARTIFACTS omits scope-map.md

**What is wrong:** `REQUIRED_ARTIFACTS` in `factory/scripts/spec-lint` lists only `prd.md`, `supplementary_specs/entity-model.md`, and `supplementary_specs/validation-rules.md`. The agentic-quality proposal defines `scope-map.md` as a persistent required artifact, and both the greenfield-development and brownfield-onboarding playbooks list it in their terminal conditions. `check_required_artifacts()` cannot detect its absence.

**Fix:** Add `"scope-map.md"` to `REQUIRED_ARTIFACTS`.
