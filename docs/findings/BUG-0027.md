# Specification-review manifest excludes mandatory review inputs and outputs

**What is wrong:** The
[`feature-addition` spec-review step](../../packages/factory/playbooks/feature-addition.md)
allows proposal and specification inputs and only `docs/findings/SPEC-*.md`
outputs. The mandatory
[`inspect-spec` workflow](../../packages/factory/skills/inspect-spec/SKILL.md)
requires the reviewer to read `docs/CONTEXT.md` for terminology consistency and
write `docs/reviews/spec-review-YYYY-MM-DD.md`. A step manifest derived from the
playbook therefore denies required review work, so the Requirements-to-review
handoff cannot give the incoming reviewer a compliant next action.

**Fix:** Add `docs/CONTEXT.md` to the feature-addition `spec-review` inputs and
`docs/reviews/spec-review-*.md` to its outputs. Add or update a manifest-contract
test proving both paths are present, regenerate the Factory index if required,
and rerun the relevant playbook/step-manifest gates.
