# The usage `records/` directory is never used

**What is wrong:** `init-factory` creates `.agent-factory/usage/records/`. Capture writes its records directly into `.agent-factory/usage/`, and the analysis reads only that level, so `records/` stays empty. Source: [bug-hunt report § Found while fixing](../reviews/bug-hunt-2026-10-15.md#found-while-fixing).

**Fix:** Either write records into `records/` and read them from there, or stop creating the directory. Pick the option that keeps existing records readable.

**Resolution:** Not fixed in the bug-hunt fix run. The spec places records under `usage/records/`; whether to drop the folder or write records there is a design decision taken out of the run on 2026-10-15.
