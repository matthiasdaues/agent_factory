# `module-graph-check` reports "no change" for input it could not parse

**What is wrong:** With an empty architecture file and a contracts file it cannot read, the script prints `architecture_change=false` and exits 0. Its docstring promises exit 2 on a parse error. The routing gate then skips the architecture phase. Source: [bug-hunt report § L-5](../reviews/bug-hunt-2026-10-15.md#l-5--module-graph-check-reports-no-change-for-input-it-could-not-parse).

**Fix:** Exit 2 when it finds no components or no contract headings.
