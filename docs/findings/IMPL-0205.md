# A blank line in a page title breaks its generated link

**What is wrong:** A handbook reader cannot follow a generated index entry when the page title contains a blank line. The regression starts in `_link`, which now passes the title's line breaks into the list before Markdown formatting.

```yaml
title: |-
  Add a

  CLI integration
```

On a scratch handbook, set this title on an implemented page and run `handbook-index`. The generated entry starts with `- \[Add a`. After the blank line, `CLI integration\](add-an-integration.md)` renders as paragraph text. At `e5851118`, the same input generates a working link labeled “Add a CLI integration.” The formatter and `handbook-lint` both exit 0 on the broken entry because the generator expects those bytes.

**Why this severity:** BR-140 accepts this non-empty title, and BR-144 requires a working link in the chapter index. The same link builder serves BR-145. The reviewed code is on the story branch.

**Fix:** Normalize line breaks in the link label before building the Markdown link. Keep the description on its separate formatting path so inline code retains its spaces.
