# The update check permits extra installed files and omits the fresh install

**What is wrong:** FH-07-02 compares installed files with source counterparts. It can pass when an entire source file is missing from the installation. FH-07-01 checks chapter names in one index. Neither check shows that a fresh install ships the user handbook or that the contributor handbook stays in the source repository. [docs/spec/features/factory-handbooks.feature:428](../spec/features/factory-handbooks.feature)

**Why this severity:** A planner can cover only the update path and a test author can accept an incomplete installed tree, contrary to DEC-04. No code or completed story outside the run encodes this review target.

**Fix:** Compare the complete sets of relative paths and file bytes on update, including removal of stale files. Check a fresh installation and verify that it includes the user handbook and excludes the contributor handbook.
