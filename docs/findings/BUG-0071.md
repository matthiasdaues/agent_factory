# `dependency-check` passes files it cannot parse

**What is wrong:** A file with a forbidden import and a syntax error passes the rule. A Latin-1 file crashes the gate. The default rules file is `dependency-rules.dsl`, but the skill documents `architecture.dsl`, so a plain run exits 2. Source: [bug-hunt report § U-8](../reviews/bug-hunt-2026-10-15.md#u-8--dependency-check-passes-files-it-cannot-parse).

**Fix:** Report parse failures as findings, read files as bytes, and align the default path with the skill.
