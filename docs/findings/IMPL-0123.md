# Handbook lint writes a Python bytecode cache

**What is wrong:** A contributor running lint in a writable checkout gets a new file beside the scripts. The dynamic import executes `handbook-index` through `SourceFileLoader`, which writes bytecode by default. In scratch, a clean run exited 0 and created `__pycache__/handbook-indexcpython-314.pyc`.

**Why this severity:** BR-148 and the lint interface require a read-only command. The import was introduced on the story branch.

**Fix:** Load the shared code without creating a bytecode cache. Verify the CLI leaves a writable script directory unchanged with bytecode enabled in the calling environment.
