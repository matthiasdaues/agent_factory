# Lint omits a missing root index when another page in the root fails

**What is wrong:** A contributor gets an incomplete lint report when a handbook root lacks `index.md` and contains an invalid draft. In `layout_failures`, any root page failure suppresses the missing-index diagnostic.

To reproduce, keep the user handbook valid. Replace `docs/handbook/index.md` with `docs/handbook/draft.md` containing only `# Draft`, then run `handbook-lint`. The reviewed commit exits 1 and reports only the frontmatter failure. Commit `6463561e` also reports that the root has no `index.md`.

**Why this severity:** Reporting every failure in one run is a goal of ST-0452 and a requirement of BR-147. The new condition hides the separate BR-141 failure. The condition exists on the story branch.

**Fix:** Suppress the missing-index check only when the reader could not inspect the root itself. Add a lint case that expects both diagnostics when an inspectable root lacks an index and contains an invalid page.
