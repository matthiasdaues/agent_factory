# 25 in-scope Markdown artifacts failed the mdformat gate at branch head

**What is wrong:** Running the canonical Markdown gate
(`factory/scripts/mdformat --number .`, write mode, as the `validate` skill
and the pre-commit hook apply it) against branch head
`ff123986ad44494fd96f6a508a74a6294f496040` modified 25 tracked files, all
inside this branch's diff scope:

- six backlog stories (`ST-0119`, `ST-0120`, `ST-0121`, `ST-0126`, `ST-0128`,
  `ST-0131`)
- the previous QA pass's own artifacts: `docs/findings/BUG-0017.md`,
  `BUG-0018.md`, `BUG-HUNT.md`, `FAGAN-0025.md`–`FAGAN-0029.md`,
  `SEC-0005.md`, `SEC-0006.md`, `copilot-pretooluse-spike.md`,
  `qa-handoff-envelope.md`, `qa-review-summary.md`, the two
  `docs/reviews/*-mechanized-dispatch.md` reports, and the two
  `docs/handoffs/wave*-*.md` files
- `factory/playbooks/feature-addition.md` and
  `factory/rulebooks/conventions/dispatch-contract.md`

These files were committed without passing through the mdformat gate, so
the branch head did not satisfy its own deterministic Markdown gate.
Additionally, `docs/findings/FAGAN-0026.md` contained a Python code block
whose `def` had no body, which made the mdformat-ruff plugin emit a parse
warning for that file.

**Fix:** Applied the gate's own write mode to the affected files and
committed the result; added the missing body (`...`) to the FAGAN-0026
snippet so the block parses. After the commit, `mdformat --number .`
produces no changes on any tracked file.
