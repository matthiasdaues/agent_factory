# The installation page understates which files setup changes

**What is wrong:** A user who prepares for only the listed edits can miss changes to existing runtime configuration. The revised paragraph says `init-factory` changes no other file or folder. The installer can add hooks to existing `.claude/settings.json` and `.codex/hooks.json`. It can also create `docs/testing.yaml` when it detects one test command and the declaration is absent. See `packages/factory/scripts/init-factory:1668-1740,2059-2136,3503-3532,5043`.

**Why this severity:** The procedure exists to tell users what setup changes in an existing repository. The revised list still gives them an incorrect account, so it fails that purpose. The edit is on the story branch.

**Fix:** Describe the listed changes as examples and account for runtime hook configuration and the optional test declaration. State which existing user content the installer keeps.
