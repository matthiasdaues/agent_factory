# The tutorial's fallback instructions leave dispatch using CONFIGURE-ME

**What is wrong:** A new user who follows the fallback instructions still sends `--model CONFIGURE-ME` to Claude Code. Step 5 tells the user to set `on_missing = auto`, leaving the generated tier row in place. Both `resolve-model` and `trigger` return a present value before they read `on_missing`.

A scratch check ran `resolve-model --cli claude --tier standard --model-conf <scratch-file>` against the generated matrix after changing the setting to `auto`. It exited 0 and printed `CONFIGURE-ME`. After removing the `claude.standard` row, it exited 0 with empty output.

**Why this severity:** IMPL-0199 requires a working configuration or fallback before model-routed work. The documented fallback leaves the placeholder as the model argument. This tutorial revision is on the story branch.

**Fix:** In Step 5, tell readers to remove the generated row for each tier that should use its CLI default and set `on_missing = auto`. Keep the option to replace rows with valid model IDs. Explain the absent-row condition in the linked reference. If giving instructions for removing every model row, mention that `matrix-lint` reports `MX-EMPTY` on a matrix with no model rows.
