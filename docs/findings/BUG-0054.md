# Gates pass on a directory that does not exist

**What is wrong:** `arch-lint --docs-dir docs/arch42-typo` and three similar calls exit 0. Source: [bug-hunt report § L-10](../reviews/bug-hunt-2026-10-15.md#l-10--gates-pass-on-a-directory-that-does-not-exist).

**Fix:** Exit 2 when the input directory is missing.

**Resolution:** Fixed in commits `268870ad7b66862151f7028146c4a7e1ae4bc23e`, `c69684b732bd472bd2fd699313cfa9d64e270ef2`, `79c62e108e6ca81f73f8862a82a38d12691a4eb5`, merged into `dev` as `3921e522cc31f7fd454d9c908c9e8e42ceb201fe`. The full suite passed after the merge. `arch-lint` exits 2 on a missing `--docs-dir`; the new flag `--allow-missing-docs-dir` turns that into a warning, and the pre-commit hooks and gate 7 of the validate skill pass it.
