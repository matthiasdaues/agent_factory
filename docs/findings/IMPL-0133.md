# The install how-to promises that a collision leaves no partial setup

**What is wrong:** A maintainer can find installed files after `init-factory` reports a collision. In `_install`, the script copies the factory during scaffolding before it checks the CLI setup. For example, an invalid `.codex/hooks.json` raises a collision in the Codex preflight after that copy. The wiring error handler returns 1 and leaves the copy in place.

**Why this severity:** The how-to says the installer never applies part of a run. The current installer can stop after making changes. ST-0453 requires the page to describe current behavior and report drift from the guide. The handbook text is new on the story branch.

**Fix:** State that the installer can stop after earlier changes. Tell the reader to resolve the reported collision and rerun. Record the mismatch with the pinned guide in the story’s spec feedback.
