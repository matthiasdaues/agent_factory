# Proposal intake cannot hand off to Requirements through the mandatory gate

**What is wrong:** The
[`feature-addition` phase-boundary contract](../../packages/factory/playbooks/feature-addition.md#phase-boundary-contract)
requires a handoff from proposal intake to Requirements when an accepted
proposal changes specification behavior. The
[`handoff-lint`](../../packages/factory/scripts/handoff-lint) boundary registry
does not contain `proposal intake -> requirements`, so it reports
`HO-BOUNDARY` for the handoff that the playbook requires. The feature workflow
cannot enter Requirements without either violating its mandatory handoff rule
or bypassing its deterministic closure gate.

**Fix:** Add `proposal intake -> requirements` to the canonical handoff boundary
set in
[`handoff-format.md`](../../packages/factory/rulebooks/conventions/handoff-format.md#boundary-set)
and `handoff-lint`. Add a public-command regression test proving that a complete
handoff using this boundary passes, while an unregistered boundary still
produces `HO-BOUNDARY`.
