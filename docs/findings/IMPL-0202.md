# A valid bracketed title still makes the handbook hook fail

**What is wrong:** A contributor who regenerates the index for a page titled `Add [CLI] integration` still gets a stale-index error at commit. The generator's link renderer escapes the brackets, and the formatter removes those escapes. This leaves the generated region with two formatting owners.

```text
handbook-index writes [Add \[CLI\] integration](add-an-integration.md)
mdformat --number writes [Add [CLI] integration](add-an-integration.md)
handbook-index --check and handbook-lint each exit 1
```

**Why this severity:** BR-140 allows the title, and the IMPL-0197 fix requires the generated region to survive the formatter. The current handbooks have no bracketed titles, but the hook already fails for a valid page in a scratch handbook. The reviewed fix exists on the story branch.

**Fix:** Give the generated region one formatting owner and cover a bracketed title with the formatter and lint hooks in repository order.
