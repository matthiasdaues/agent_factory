# `remove-factory` leaves headers recorded as dictionaries

**What is wrong:** The script strips a header only when the entry equals the string `"injected"`. Installs and updates now store dictionaries, so after install and removal `AGENTS.md` still carries the orientation block. Source: [bug-hunt report § I-2](../reviews/bug-hunt-2026-10-15.md#i-2--remove-factory-leaves-headers-recorded-as-dictionaries).

**Fix:** Read `entry["status"]` when the entry is a dictionary, and take the newline record from the entry.

**Resolution:** Fixed in commit `58aa9e942b7854518bb8a77788772d3ee1f15417`, merged into `dev` as `3921e522cc31f7fd454d9c908c9e8e42ceb201fe`. The full suite passed after the merge.
