# Smaller install and removal faults

**What is wrong:** The install and removal scripts have six small faults. Source: [bug-hunt report § I-7](../reviews/bug-hunt-2026-10-15.md#i-7--smaller-install-and-removal-faults).

- `remove-factory` rewrites `.claude/settings.json` instead of restoring it byte for byte.
- When Codex is added after a Claude install, the original `.codex/hooks.json` is never saved (`init-factory:1482-1485`).
- The receipt prints the uninstall command with an unquoted path, which breaks for paths with spaces.
- A local update rewrites `install.json` to `"version": 1` and drops `resolved_source` and `archive_sha256`.
- `migrate-layout --dry-run` always reports that `install.json` is missing (`migrate-layout:91-95`, code reading).
- `remove-factory` deletes an empty `.codex/` directory that existed before the install.

**Fix:** Fix each fault in the list. Restore `.claude/settings.json` byte for byte, save `.codex/hooks.json` before a later Codex install, quote the path in the receipt, keep `resolved_source` and `archive_sha256` on a local update, make `migrate-layout --dry-run` find `install.json`, and keep a `.codex/` directory that existed before the install.

**Resolution:** Partly fixed. Still open: `install-agent-factory` prints an unquoted uninstall path; restoring `settings.json` byte for byte needs `init-factory` to record the original; pre-existing `.claude/`, `.github/` and `.pi/` folders are deleted on removal. The full suite passed after the merge.
