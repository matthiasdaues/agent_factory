# The tutorial’s clone command redirects input instead of cloning

**What is wrong:** A contributor who pastes the first command cannot reach the installation step. Bash treats the angle brackets as redirection operators and reports `agent-factory-repo-url: No such file or directory` before Git starts.

**Why this severity:** The clone step is the first required action on the path to a passing test run. The reviewed branch introduces the command.

**Fix:** Tell the reader where to copy the repository clone URL. Show how to substitute it, or use a quoted shell variable and show how to set it.
