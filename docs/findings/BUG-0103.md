# Three copies of `_main_checkout`

**What is wrong:** `scope-lint:138`, `concern-lint:242` and `link-check:199` each define their own `_main_checkout`.

**Fix:** Move the helper into one shared module. Belongs with BUG-0092 in the brief-storage run.

**Resolution:** Merged into `dev` with the brief-storage run; fixed in commit `7fc3ae57`, and the full suite passed. The new module `_main_checkout.py` holds `main_checkout` and `installed_copy_in_main_checkout`; `scope-lint`, `concern-lint`, and `link-check` import them. The two helpers in `dispatch` that resolve the main checkout from the current folder are left as they are.
