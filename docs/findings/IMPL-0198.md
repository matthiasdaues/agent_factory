# The installed usage guide omits the source checkout required to add usage

**What is wrong:** A user with a separate project cannot add usage analysis by running step 1. The installed `init-factory` looks up the source by walking its ancestor directories. With no ancestor holding `packages/factory/`, it falls back to the project's `.agent-factory/`. The component installer looks for `packages/usage/` below that path and exits 1. The add-component path does not read the installation's `factory_source` field.

A probe with the installed script location outside the source tree returned `packages/usage/ not found — cannot install usage component`. An installation nested under the source tree can find the checkout and conceal the failure.

**Why this severity:** DEC-15 moves installation guidance into the shipped handbook. The documented command fails for an existing project installed outside the source checkout. The reviewed feature is on the feature branch.

**Fix:** Add `--source /path/to/agent_factory` to the installed command and explain where to find the checkout. Verify the procedure with source and target in separate directory trees.
