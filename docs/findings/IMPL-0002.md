# A CONTEXT.md that follows the old format rules blocks every factory update

**What is wrong:** A project whose `CONTEXT.md` follows the factory's own old rules cannot update the factory, and the error message names a fix that does not help. The first point of loss is `convert_context` (line 473). It accepts only lines of the form `**Term**:` and raises `ListFormError` for any other line under `## Language`. Two forms that the old factory itself defined are refused:

- A `###` subheading. The old `context-format.md` says: "Group under subheadings when natural clusters emerge."
- A bullet term such as `- **Invoice**: A bill.` The old `spec-lint` read glossary terms only in this form: `^\s*[-*]\s*\*\*([A-Z]...)\*\*` in `check_glossary` at base `4040854f`.

`main` then exits 2 (line 1183). `init-factory` reports "Fix: run the factory update again" and exits 1, and `update-factory` rolls the update back. A second run fails the same way, so the project stays on the old version until the developer rewrites the file by hand. The refusal looks intended, because a test asserts it (`test_CAL_06_language_section_outside_the_list_form_is_an_error`). But no spec allows it. The `Exit code` row of the interface contract lists exit 2 only for a busy repository, an existing destination, and bad arguments. ADR-0026 and DEC-18 say that the vocabulary never stops the script.

```text
CONTEXT.md has "### Orders" under "## Language" (allowed by context-format.md)
        ↓
convert_context raises ListFormError
        ↓
migrate-spec-layout exits 2
        ↓
init-factory exits 1 and names "run the factory update again"
        ↓
update-factory rolls back; every later update fails the same way
```

Failing case:

```text
# Billing

## Language

### Orders

**Order**:
A request to buy.
```

```text
$ migrate-spec-layout .
migrate-spec-layout: refused, a ## Language section is not in the list form
of the template: docs/CONTEXT.md: line 5: ### Orders; no file changed
exit=2
```

**Fix:** Change the parser in `convert_context` of `migrate-spec-layout`. Accept a `###` subheading and close the current term there, and accept a leading `- ` or `* ` before `**Term**:`. A line that still fits no form joins the current definition, so no text is lost and the run continues. If the stakeholder wants the refusal, record it in the `Exit code` row and in ADR-0026, and let `init-factory` name the real fix (edit `CONTEXT.md`) instead of "run the factory update again".
