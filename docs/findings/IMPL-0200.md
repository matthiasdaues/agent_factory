# The handbook update command requires an undocumented self-install

**What is wrong:** A user who cloned the source and installed the factory into a separate project cannot run step 2. The command calls `.agent-factory/factory/scripts/update-factory` inside the source checkout. The checkout provides `packages/factory/scripts/update-factory`. The `.agent-factory/` path in the checkout appears only after a separate self-install, which the contributor tutorial performs. The handbook carried this command forward from the former guide. The package README already runs the installed updater from the target project.

The local configuration inventory also says freshness hooks run the update automatically. The freshness hook prints a warning and the command the user needs to run.

**Why this severity:** The proposal's update flow depends on users being able to bring the installed copy to the new release. The primary command in the replacement how-to fails on the documented clone-and-install setup. The reviewed feature is on the feature branch.

**Fix:** Use the package README's target-project command in step 2. Show `--source` for an explicit checkout. Describe the freshness hook as a prompt to run the updater and link to this how-to.
