# Required PyArrow output conflicts with the dependency contract

**What is wrong:** The accepted [Python interface design](../proposals/usage-processing-and-storage.md#local-python-and-dataframe-interface) requires a PyArrow table while claiming it adds no dependency beyond DuckDB. The [installed runtime](../proposals/usage-processing-and-storage.md#installed-runtime-and-invocation) limits the locked dependencies to DuckDB and its transitive closure. DuckDB provides Arrow integration but does not supply the Python `pyarrow` package needed to return a `pyarrow.Table`, so the required output is not feasible under the stated dependency set.

**Fix:** Declare and lock a compatible PyArrow dependency in the installed module and update the dependency-isolation, offline-cache, and test contracts. If that dependency is outside release 1, remove the required PyArrow result consistently from the proposal, feature, supplementary contracts, and QA strategy.
