# No test checks that the template traces only the changed kept files

**What is wrong:** A change that makes the template trace every file under `GATE_SCOPE=changed` passes every test of the story. The scenario of CG-03-IT-09 ends with "it traces only the changed files that the measure keeps", and DEC-85 exists for that step: one full run of this repository wrote about 1.8 GB of coverage data. The test `test_cg_03_with_changed_the_template_runs_the_select_command_with_the_changed_paths` checks the step through the files of the rows. But `code_files` decides which files get rows, and the coverage settings decide which files coverage traces. The two are separate, so the rows look the same whether coverage traces two files or the whole project. The code is right today. The test is wrong: its comment says it checks the tracing, and it cannot fail when the tracing breaks.

```text
main() computes traced = files under changed
        ↓
coverage_config() writes include = <the changed kept files>, else source = <root>
        ↓
measure() builds rows only for code_files(root, changed), whatever coverage traced
        ↓
the test compares the files of the rows, so it sees no difference
        ↓
a mutant that traces every file passes, and the disk use of DEC-85 comes back unnoticed
```

The review planted the mutant `traced = None` in `main()` of the worktree template with `/tmp/claude-1000/-home-matthiasdaues-Documents-datenschoenheit-agent-factory/89fd1670-49e4-4a59-97db-e1035150aa04/scratchpad/st0451-review/mutant_traced.sh`, ran the template tests, and restored the file with `mutant_traced.sh restore`:

```text
$ uv run --directory <worktree> pytest -q -x -n 4 tests/factory/test_crap_gate_template.py
27 passed in 6.40s
```

**Why this severity:** The step "it traces only the changed files that the measure keeps" is a contract that the story owns (CG-03-IT-09), and no test checks it, so the story does not meet its Evidence. The code exists only on `story/ST-0451`, so it is not in use.

**Fix:** In `tests/factory/test_crap_gate_template.py`, make CG-03-IT-09 observe the traced files. One way: the test project gets a `tests/conftest.py` whose `pytest_sessionfinish` writes `coverage.Coverage.current().get_data().measured_files()` to a log file. The test then asserts that the log holds `src/parser.py` and no file outside the changed paths, such as `scripts/import-orders`, while a test imports that file. A second way loads the template as a module and checks that `coverage_config` writes `include` with exactly the given files, plus a check that `main()` passes the changed kept files. Run the mutant script again to check that the new test fails on it.
