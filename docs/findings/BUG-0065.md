# Record IDs collide, so analysis keeps one record per session

**What is wrong:** Each capture numbers its records from `-0001` again. Two captures of one session both produced `s1-0001`. The analysis groups by session and record ID, so subagent and main-session records of a session collapse into one. Source: [bug-hunt report § U-6](../reviews/bug-hunt-2026-10-15.md#u-6--record-ids-collide-so-analysis-keeps-one-record-per-session).

**Fix:** Give each record a unique ID, such as the transcript ID or a UUID.
