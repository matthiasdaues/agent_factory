# `merge-precommit-config` adds duplicate hooks

**What is wrong:** The "already merged" check looks for `agent_factory_hook-mdformat`. The merge step removes that hook when the project runs its own mdformat. Two runs and one `--update` left three copies of `agent_factory_hook-link-check`. Source: [bug-hunt report § G-11](../reviews/bug-hunt-2026-10-15.md#g-11--merge-precommit-config-adds-duplicate-hooks).

**Fix:** Detect an earlier merge by the `agent_factory_hook-` prefix.
