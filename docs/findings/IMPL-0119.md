# An invalid YAML date stops the full handbook lint run

**What is wrong:** A contributor gets a Python traceback instead of the page path and field. In scratch, unquoted `title: 2000-01-99` caused PyYAML to raise `ValueError`. The frontmatter parser catches `yaml.YAMLError` only. That exception stops both commands before they can report the other handbook failures.

**Why this severity:** BR-140 and BR-147 require a diagnostic for the broken page and continued checks. The parser was introduced on the story branch.

**Fix:** Handle YAML scalar conversion errors at the frontmatter parser. Check that an invalid date yields a path and field diagnostic alongside a failure in the other handbook.
