# Escaped backticks make the rewrite refuse a live link

**What is wrong:** A contributor cannot migrate a live link when a paragraph contains escaped backticks. The following three lines reproduce the refusal in `README.md`. The previous revision rewrites the link. The new scanner counts the escaped backticks as code delimiters and raises `AmbiguousLink` at line 1. A Markdown reader sees literal backticks and a live link on line 2.

```markdown
Example \`open
[x](docs/arc42/concepts.md)
close\`
```

**Why this severity:** BR-150 requires migration of the live link. The change exists only on the story branch.

**Fix:** When scanning for a code span opener, account for backslash escapes. Add a test that rewrites the live link between the two escaped backticks.
