# The first-session tutorial skips the fitting prompt

**What is wrong:** A new user can say hello and see a fitting prompt where the tutorial expects four menu options. The shipped orientation files check fitting before they present the menu. For example, `config/AGENTS.claude.md` offers the fitting or a skip when `fitting.status` is `unfitted`. The tutorial gives no action for that prompt before its menu checkpoint.

**Why this severity:** The tutorial’s fixed path can stall on a normal first session. The story requires the tutorial to take a new user through the current flow. The handbook text is new on the story branch.

**Fix:** Tell the reader what to do at the fitting prompt to reach the menu. Keep the four options as the checkpoint once the menu opens.
