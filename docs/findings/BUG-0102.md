# Pi dispatch puts worktrees under `.current-work/worktrees/`

**What is wrong:** `dispatch-wave.ts:63` cuts worktrees under `.current-work/worktrees/`, and the Pi guard `block-dangerous-git.ts:57` demands that path. `rules.md:98` requires `.current-work/<feature-branch>/`.

**Fix:** Use the rulebook's path in both extensions. Belongs with BUG-0092 in the brief-storage run.

**Resolution:** Merged into `dev` with the brief-storage run; fixed in commit `7fc3ae57`, and the full suite passed. `dispatch-wave.ts` cuts worktrees under `.current-work/<target>/`, and `block-dangerous-git.ts` accepts any path under `.current-work/`, as the Claude guard does.
