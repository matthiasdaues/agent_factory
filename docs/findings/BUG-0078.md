# The Claude orientation header points outside the project

**What is wrong:** The root `AGENTS.md` starts with `@../../.agent-factory/factory/config/AGENTS.claude.md`. From the project root, that path resolves above the project. Every nested `AGENTS.md` gets the same fixed text. Source: [bug-hunt report § I-4](../reviews/bug-hunt-2026-10-15.md#i-4--the-claude-orientation-header-points-outside-the-project).

**Fix:** Compute each include path relative to the file it is written into.

**Resolution:** Fixed in commits `cb5c0347a407bc5dc9d9ae7cc0beda7b9adc0c39`, `b0a3feca158c6e473bbeae6c5b92bb400edaed17`, merged into `dev` as `3921e522cc31f7fd454d9c908c9e8e42ceb201fe`. The full suite passed after the merge.
