# `close-wave` cannot commit the ledger

**What is wrong:** `.current-work/` is ignored by git, so `git add` fails. The wave record is saved before the commit, so a second run exits 0 without committing. Run from the invocation worktree, the command crashes with a `ValueError`. Source: [bug-hunt report § D-5](../reviews/bug-hunt-2026-10-15.md#d-5--close-wave-cannot-commit-the-ledger).

**Fix:** Decide whether the ledger is committed. If it is, use `add -f` and save only after the commit. If it is not, change the contract.
