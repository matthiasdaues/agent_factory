# `index-lint` drops skills and accepts duplicate names

**What is wrong:** A `SKILL.md` that starts with a byte order mark, or that has no `name`, disappears from `INDEX.yaml` without a warning. Two skills with the same name are both listed. Source: [bug-hunt report § L-6](../reviews/bug-hunt-2026-10-15.md#l-6--index-lint-drops-skills-and-accepts-duplicate-names).

**Fix:** Read files as `utf-8-sig`, warn on unreadable frontmatter, and check names for uniqueness.
