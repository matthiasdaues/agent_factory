# The owner of "every gate passes" does not run three of the seven gates

**What is wrong:** `Scenario: Every gate passes on the migrated factory repository` names seven gates: `link-check`, `arch-lint`, `structurizr validate`, `dependency-check`, `spec-lint`, `scope-lint`, and `statemachine-lint`. The QA strategy assigns it to CAL-09-LN-01 with the command `pre-commit run --all-files`. The repository's `.pre-commit-config.yaml` has no hook for `scope-lint`, `dependency-check`, or `structurizr`. Its `arch-lint` hook runs with `--no-validate`. So the owner command can pass while three gates were never run, and the contract is marked verified without evidence.

**Fix:** Give CAL-09-LN-01 a command that runs each of the seven gates, for example one integration test in `tests/factory/test_core_layout_gates.py` next to CAL-09-IT-01, with the `structurizr` part under the `container` marker. Or list the seven gate commands in the Command column. Do not rely on the pre-commit configuration, unless the story also adds the three missing hooks.
