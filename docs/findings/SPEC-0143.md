# The index command leaves invalid frontmatter behavior open

**What is wrong:** The index contract reads every page but lists only broken markers and stale lists as error conditions. A page with order: first cannot be sorted by the specified integer order. The lint command still has to report every failure across both handbooks. [docs/spec/interface-contracts.md:1826](../spec/interface-contracts.md)

**Why this severity:** An implementer must choose whether the standalone generator rejects, skips, or substitutes a value for that page, and whether lint can complete its other checks. No code or completed story outside the run encodes this review target.

**Fix:** Define what both index modes do with malformed or invalid page metadata and how lint reports the underlying format error while continuing across both handbooks.
