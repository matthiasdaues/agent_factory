# Four ignore table rows exclude links the installer reuses

**What is wrong:** A maintainer who links a Factory skill before running setup can expect Git to list that untracked link. The handbook answers “No” for existing links in four cases that the installer ignores. The installer records matching Copilot child links at lines 907–910 and 951–956 of `packages/factory/scripts/init-factory`. It also records matching Codex hook links, the OpenCode plugin link, and Codex skill links at lines 1710, 1957, and 1112. A scratch Git check matched all four pre-existing symlinks against the emitted rules.

**Why this severity:** The inventory gives the wrong Git visibility for paths that setup accepts. The handbook text exists on the story branch.

**Fix:** State that the rules cover Factory links that setup creates or reuses. In the Codex hooks and agents row, also account for a previously installed agent that setup accepts by its manifest entry and ownership marker.
