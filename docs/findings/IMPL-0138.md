# The manual dispatch how-to states the wave boundary outside a sourced callout

**What is wrong:** The operator sees a binding instruction without its
source. Step 8 tells the operator to close the wave before starting the next
story. The dispatch contract defines that requirement in § Wave Boundary As
Hard Gate (BR-113).

**Why this severity:** ST-0453 requires a sourced callout for each binding
rule a handbook page repeats (BR-149). The QA strategy treats a violation as
a failure of the story’s purpose. This instruction is new on the story branch.

**Fix:** Keep the command in step 8. Put the requirement to close the wave
before starting the next story in a rule summary. Cite [Wave Boundary As
Hard Gate](../../packages/factory/rulebooks/conventions/dispatch-contract.md#wave-boundary-as-hard-gate).
