# The first-session tutorial promises model defaults that installation does not supply

**What is wrong:** A new user who follows the Help tour can skip fitting and reach model-routed work with an unconfigured matrix. Step 5 says the defaults work. The local configuration inventory repeats the default claim, and the model reference says Claude Code has no rows. A fresh Claude installation in scratch wrote three Claude rows set to `CONFIGURE-ME`, with `on_missing = halt`. The installer generates placeholders for each selected CLI. VIRGIL's fitting instructions tell users to replace them.

**Why this severity:** FH-06-01 routes new users to this tutorial. The tutorial and its linked reference give the wrong setup instructions for model-routed work. The reviewed feature is on the feature branch.

**Fix:** Keep the option to skip fitting for orientation. Before model-routed work, direct users to configure the generated rows or choose an explicit fallback. Align the local configuration inventory and model reference with the installer.
