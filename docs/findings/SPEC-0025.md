# A failed migration restores file paths but not file content

**What is wrong:** The proposal's completion criterion says: "When `migrate-spec-layout` fails partway during an update, the project's files and factory version are as before the update." The specification checks only paths. `Scenario: A failure partway undoes the script's own moves` ends with "every file is back at its old path". `Scenario: A failed migration rolls the update back` ends with "the project's files are at their old paths". The `migrate-spec-layout` contract in `interface-contracts.md` says the same ("after it has undone its own moves"). But the script also changes content before it can fail: it rewrites Markdown links in files that stay put, converts chapter 12, removes the `## Language` section from each `CONTEXT.md`, rewrites the `files:` values in `.pre-commit-config.yaml`, and changes the DSL's `theme` line. An implementation that moves every file back but leaves these edits passes both scenarios. The project then holds links to paths that do not exist and a hook block that matches the new layout. The QA strategy rates exactly this state as blocking ("a failed migration that leaves a half-moved project").

**Fix:** Change both scenarios and the contract's Exit code row so the undo covers every change the script made: moves, removals, and content edits. Assert it with a check such as "`git status` shows no change against the state before the run" in the script scenario. In the update scenario, assert that the project's files have their old content, `.pre-commit-config.yaml` included. Let one Given step fail after at least one link rewrite and the hook rewrite, so the test reaches those edits.

**Resolution:** `Scenario: A failure partway undoes every change of the script` lets the failure come after a link rewrite and the hook-block rewrite and asserts that `git status` shows no change against the state before the run. `Scenario: A failed migration rolls the update back` asserts the old path and the old content of every project file, `.pre-commit-config.yaml` included. The Exit code row of the `migrate-spec-layout` contract and the Layout move row of `update-factory` name every change the undo covers. CAL-03-IT-04, CAL-07-IT-03, and the boundary row follow.
