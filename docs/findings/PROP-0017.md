# Arithmetic error in estimated_consumption.min

**What is wrong:** `estimated_consumption.min` is 80,000, but
`normalized_tokens.min` (8,000) multiplied by `overhead_multiplier` (15) equals
120,000. The max value (300,000 = 20,000 x 15) is consistent. The min value
implies a 10x multiplier, contradicting the stated 15x.

**Fix:** Either correct `estimated_consumption.min` to 120,000, or lower
`overhead_multiplier` to 10 and adjust `estimated_consumption.max` to 200,000.
