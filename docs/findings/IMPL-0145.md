# The tutorial tells contributors that Git hooks are active after setup

**What is wrong:** A contributor can commit a change without the tests the tutorial says will run. In a fresh clone, `./init-factory .` keeps the tracked `.pre-commit-config.yaml` and skips hook installation. The scratch clone had only sample hook files. The repository configuration also runs `handbook-lint` from `packages/factory/scripts/` and runs affected tests through `tests/select_tests.py`.

**Why this severity:** The keep-change step gives the contributor a false expectation about commit verification. The claim is new on the story branch.

**Fix:** State that the configured checks run when pre-commit hooks are installed. Describe the installed copy as the source of the detected CLI’s factory tools and describe the repository hooks from their configuration.
