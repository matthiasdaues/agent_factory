# Hidden and nested pages escape handbook validation

**What is wrong:** A contributor can commit a hidden Markdown page that fails BR-140. The shared reader skips every dot-prefixed entry. It also stops at the first folder inside a chapter, so lint reports that folder without naming invalid pages inside it. In scratch, `testing/.draft.md` without frontmatter passed lint. With that file moved to `testing/nested/bad.md`, lint only named the folder and the index command exited 0.

**Why this severity:** Both scripts must validate every handbook page, and the index command must refuse to write when any page fails BR-140. The reader was introduced on the story branch.

**Fix:** Validate Markdown files and index markers at every depth inside both roots. Keep chapter list generation limited to immediate chapter pages. Report every nested folder and every page failure, including dot-prefixed paths.
