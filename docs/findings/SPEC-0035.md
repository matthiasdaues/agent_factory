# The pass rewrote seventeen unrelated notes of the entity model and broke their sentences

**What is wrong:** Commit `71d98112` replaced every semicolon in the Notes of other features' entities with a period and kept the lower-case letter after it. Examples are "glob whose `status` is exactly `open`" followed by ". open finding counts", "Every entry carries a `tokens` field. agents and playbooks", and "Component removal preserves evidence. full Factory removal does not." In **Path resolution** the change splits a parenthetical: "equals `global`. skipped in Open Stage)". These notes belong to the Catalog, Handoff, Dispatch, Scope Map, Concern Registry, Usage, Agent Definition, and Install Manifest entities. None of them is in the scope of this feature, and no gap or decision asks for the change. The Mermaid semicolon rule does not apply, because these lines are prose outside a Mermaid block.

**Fix:** Revert the changes to the Notes outside the section Core Artifact Ownership Entities with `git diff 27585221 a94ed69a -- docs/spec/entity-model.md` as the guide. Keep the new section and the `owner` field of FINDING.

**Resolution:** The eighteen Notes outside Core Artifact Ownership Entities have their sentence case back, and Path resolution has an unbroken parenthetical. Only the wording changed: each note differs from `27585221` only where a semicolon became a period, and Path resolution reads "equals `global`, except in Open Stage, which skips this step".
