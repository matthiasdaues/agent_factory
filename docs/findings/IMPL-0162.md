# The Python API launch changes the directory used by the sample

**What is wrong:** A user with `script.py` in the project root cannot launch it as shown. The handbook uses `uv run --directory` to select the environment, which also changes the working directory. A script placed in the package directory still looks for `.agent-factory/usage/` inside that directory.

**Why this severity:** The story requires a usable Python API example for the installed add-on. The affected documentation is on the story branch.

**Fix:** Select the package environment while keeping the project root as the working directory, or pass absolute paths for both the script and the evidence directory.
