# A rerun of init-factory wires command-line tools the user never chose

**What is wrong:** Without `--cli`, `init-factory` guesses the tools from the
folders in the project, even when the install record already lists the
user's choice. `update-factory` calls `init-factory` without `--cli`. A
Claude-only project with a `.github/workflows/` folder therefore gains
Copilot wiring after an update, and `init-factory --remove copilot` does not
last. Source:
[bug-hunt report § I-6](../reviews/bug-hunt-2026-10-15.md#i-6--update-factory-wires-command-line-tools-the-user-never-chose).

**Fix:** Without `--cli`, reuse the tool list from the install record when it
is not empty, and guess only on a fresh install. Add a test that reruns
`init-factory` on a Claude-only install with a `.github/` folder and expects
no Copilot wiring.
