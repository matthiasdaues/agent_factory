# `merge-story` blocks every file of a story that declares only `touches`

**What is wrong:** `merge-story` builds the scope globs for `premerge-check`
from the story's `outputs` field alone (`dispatch`, around line 1690). It
always adds `backlog/<id>.md` as well. A story that declares `touches` and no
`outputs` therefore gets a single scope glob, its backlog file, and every
changed script counts as out of scope. `_story_output_globs` already falls
back to `touches`, as wave planning does; `merge-story` does not use it.

A hook can also rewrite `packages/factory/INDEX.yaml` during a story commit.
That file lies outside every story's declared scope.

**Reproduction:** In the bug-hunt fix run, `dispatch merge-story ST-0297 --dry-run` printed:

```
BLOCK out-of-scope-paths: packages/factory/scripts/module-graph-check, packages/factory/scripts/schema-validate, tests/factory/test_contract_checks.py
```

All three files are in the story's `touches`.

**Fix:** Build the scope globs in `merge-story` with `_story_output_globs`,
so `touches` counts when `outputs` is absent. Scale `--max-files` from the
same list. Allow `packages/factory/INDEX.yaml` as an extra glob when it
exists in the project, because the `index-lint` hook writes it. Add a
regression test with a story that declares only `touches`.

**Resolution:** Fixed in commits `af7e446a667aa15d4ec02fb6555e796ff86b04bf`, `bf7121ea28d1869d47e232542985cb6ce7bd5597`, and `75ceef4f212751d55c942800791490742be2efde`, merged into `dev` as `d22b613c90872c8f313669012ec51725e38b7cda`. `merge-story` builds its scope from `touches` when `outputs` is absent. An entry with `*` or `?` goes to `premerge-check` as `--scope-glob`; every other entry goes as `--scope`, which matches an exact path or a folder prefix. `packages/factory/INDEX.yaml` is always allowed, not only when it exists: in a consumer project the path never shows up in a diff, and in this repository only `index-lint` writes it. Known gap: a folder entry counts as one output when `--max-files` is scaled. The full suite passed after the merge.
