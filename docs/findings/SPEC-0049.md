# The term candidate "Factory Producer" of the domain area counter-ids waits for the stakeholder

**What is wrong:** `docs/spec/work/term-candidates.md` holds the term **Factory Producer** in the domain area `counter-ids` with the status `proposed`. The term is not in the glossary until the stakeholder confirms it (BR-065). The glossary already defines **Producer** as "the one agent that declares a core or seam artifact as an output". A Factory Producer is a file, not an agent, and the feature file calls it "producer" alone. SPEC-0050 covers this.

**Fix:** Present the term and its proposed definition to the stakeholder at the next pause point. On confirmation, move the row into `docs/spec/glossary.md` and remove it from `term-candidates.md`. On rejection, keep the stakeholder's note in the row.
