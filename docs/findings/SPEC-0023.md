# OpenCode session semantics leak into the onboarding sandbox contract

**What is wrong:** The First-task sandbox contract repeats three OpenCode
session-start constraints: plugin-injected orientation, no legacy
`instructions` field, and preservation of the root `AGENTS.md`. These
constraints already belong to the OpenCode CLI Integration contracts. Their
duplication under value-first onboarding creates a false cross-feature
dependency.

**Fix:** Remove the three OpenCode-specific rows from the First-task sandbox
table. Keep their canonical definitions in the OpenCode CLI Integration
section unchanged. On repeat review, verify that the onboarding sandbox
contract contains only task-isolation behavior and that the OpenCode section
still owns the session-start constraints.
