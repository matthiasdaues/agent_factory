# Rule-summary checks can pass when pages introduce binding rules

**What is wrong:** The automated check starts from callouts already marked Rule summary. It cannot find a binding rule written as ordinary handbook prose. The QA strategy assigns the lector and reviewer the page-type table but gives no explicit review check for binding prose in both handbooks. [docs/spec/work/factory-handbooks-qa-strategy.md:102](../spec/work/factory-handbooks-qa-strategy.md)

**Why this severity:** A planner can assign only the automated callout check and ship a handbook with a second home for a binding rule, contrary to DEC-02. No code or completed story outside the run encodes this review target.

**Fix:** Give the handbook content review an explicit check for binding rules in ordinary prose in both handbooks. Keep the automated check for callout structure and source links.
