# The Python template reports a property and its setter as one function twice

**What is wrong:** A Python project that has a property with a setter in a measured file cannot use the gate. Every gate run exits `2` with "measure python reports Box.width of src/shape.py twice", so every story that the run dispatches is `blocked`, and the proof fails "Repeatable". The information is lost in the template, in `function_blocks`: radon gives the getter and the setter each a block named `width`, and the template names both `Box.width`. `crap-score` then applies DEC-12 correctly and refuses the second row. The same happens for `@typing.overload` stubs and for a function that a file defines twice under `if`/`else`. DEC-12 means a real duplicate, so the behavior looks unintended. No test of `tests/factory/test_crap_gate_template.py` has a property setter.

```text
src/shape.py holds `@property def width` and `@width.setter def width` in class Box
-> function_blocks names both blocks Box.width
-> crap-score check_duplicates sees (src/shape.py, Box.width) twice
-> crap-score exits 2: "measure python reports Box.width of src/shape.py twice"
-> the gate-check step and premerge-check set every story blocked
```

Reproduction: a scratch repository with `src/shape.py` as above and one test that sets and reads `width`. The measure `python` has `files: "src/**"` and the filled template as its command, with `TEST_COMMAND` set to the project's pytest.

```text
$ crap-score --all
crap-score: cannot measure: measure python reports Box.width of src/shape.py twice
exit 2
```

Expected: one row per function, each with its own name, and exit `0` or `1` by the scores. Actual: exit `2`, no verdict.

**Why this severity:** The template exists only on the feature branch (`in_use: false`). Its job is to measure the Python code of a project, and for any file with a property setter it gives no verdict at all (`fails_purpose`). The only workaround is an `exclude` pattern, which takes the whole file out of the gate.

**Fix:** In `function_blocks` of the template, give an accessor its decorator in the name, such as `Box.width.setter` and `Box.width.deleter`, and leave out a block decorated with `overload` or `typing.overload`, because it is a stub that never runs. Keep every other repeated name as it is, so DEC-12 still stops a real duplicate. Add a test with a property setter and an overload to `tests/factory/test_crap_gate_template.py`, and name the setter rule in the `Rows` section of the template header.
