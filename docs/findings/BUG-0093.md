# `architecture-agent` requires inputs the brownfield playbook produces later

**What is wrong:** `architecture-agent.md` lines 17 to 21 declare `docs/spec/*.feature` and `docs/spec/scope-map.md` as required inputs. The brownfield playbook builds `architecture.dsl` at Step 2.2 and fills the scope map at Step 2.5, so the agent's declared inputs do not exist when the playbook calls it.

**Fix:** Mark both inputs optional for brownfield entry, or reorder the playbook so the scope map comes before the DSL.
