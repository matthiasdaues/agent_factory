# test_research_survey_playbook reads the moved research-survey-mode design doc at its old path

**What is wrong:** `_SURVEY_DESIGN = _ROOT / "factory" / "docs" / "design" / "research-survey-mode.md"` (line 13) was not updated when this branch moved that
design doc to `docs/proposals/implemented/research-survey-mode.md` (commits
`5f92617` and `e620890`). `test_FAGAN0009_design_records_the_implemented_schema_boundary`
therefore raises `FileNotFoundError` at HEAD; it passed at the merge-base
(`04256d9`) where the old path existed. The new file satisfies every assertion
the test makes (verified: all three positive substrings present, both negative
substrings absent), so the defect is the stale path, not the content. This is a
branch-introduced test regression: the suite was green at the merge-base and is
red at HEAD for this test. In a consumer repo whose pre-push gate runs
`run-tests --full` (ST-0073), a red suite blocks `git push`, so the gate
inherits this failure wherever the suite is run.

**Fix:** Update `_SURVEY_DESIGN` to
`_ROOT / "docs" / "proposals" / "implemented" / "research-survey-mode.md"` and
re-run the test to confirm green. (`_FACTORY_GUIDE` on line 12 still exists at
its path and needs no change.)
