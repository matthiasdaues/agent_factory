# The test reference promises staged tests on commit

**What is wrong:** A user can commit without running staged tests even though the reference says a project hook runs them. The revised pre-commit row correctly says the factory installs no test hook. It then assumes the project has a hook that selects staged tests. BR-029 leaves both the trigger and test selection to the project. The installer records a detected `test_command` without configuring test execution in `.pre-commit-config.yaml` (`packages/factory/scripts/init-factory:3490-3512`).

**Why this severity:** The reference exists to tell the user when tests run. A user who relies on the promised pre-commit check may commit without running it. The edit is on the story branch.

**Fix:** State that pre-commit runs tests only if the project configures a test hook. Say that the project's hook controls which tests run. Qualify the pre-push row the same way.
