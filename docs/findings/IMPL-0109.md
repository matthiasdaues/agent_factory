# A function assigned to an object member still looks covered when no test calls it

**What is wrong:** The CRAP gate can still pass a changed TypeScript function that no test calls, when the code assigns the function to an object member, such as `box.pick = (a) => ...`. The story receives the wrong verdict. The fix of IMPL-0105 matches the lcov function record by start line and name, and the loss starts in `neverCalled`. It looks for the own name from ESLint, `pick`. Node names the record after the whole member expression, `box.pick`. No record matches, so `neverCalled` returns false, and the row falls back to the line count, which is 100 %. The behavior looks unintended, because the header of the command now promises 0 % for a function with a count of 0.

```text
V8 names the function after the assignment target: FN:3,box.pick and FNDA:0,box.pick
        ↓
the rule crap/range gives the own name pick
        ↓
neverCalled looks for pick on line 3 and finds no record
        ↓
coveragePct counts line 3, which ran as module code
        ↓
the row says coverage_pct 100, and crap-score passes the function
```

The reproduction is `/tmp/claude-1000/-home-matthiasdaues-Documents-datenschoenheit-agent-factory/89fd1670-49e4-4a59-97db-e1035150aa04/scratchpad/st0449-review/repro_typescript.sh`. Call it with the path of the command and the case `member-assign`. It reports `pick` with complexity 7 and `coverage_pct` 100. At 0 %, the function scores 56 and fails the threshold 30.

The fix is safe in the other direction. A wrong match can only mark a function as never run, so it can lower coverage but never raise it. A function nested inside a function with a count of 0 gets 0 %, and such a function cannot have run.

**Why this severity:** The measure exists to give the gate the true coverage of each function. For this form of code, it still gives too high a coverage, so the gate can pass a story wrongly, which DEC-84 rules out. The command exists only on `story/ST-0449`, so it is not in use.

**Fix:** In `neverCalled` of `scripts/crap-measure-typescript`, also accept a record whose name ends with `.` followed by the own name, such as `box.pick` for `pick`. A stronger rule also helps: when no record matches by name but the start line holds exactly one function record, use that record. Add the case `member-assign` to the test `test_cg_13_a_function_that_no_test_calls_gets_zero_coverage`.
