# The lint acceptance cases omit present but invalid titles

**What is wrong:** BR-140 says title is text. Its failure clauses and the FH-04 outlines cover missing titles and invalid type, status, or order. An integer title is present but cannot serve as the required text label. [docs/spec/validation-rules.md:649](../spec/validation-rules.md)

**Why this severity:** A test author following the listed classes can accept a linter that passes a non-text title. No code or completed story outside the run encodes this review target.

**Fix:** State the error and field diagnostic for a present non-text title. Define how null and an empty title count, then add representative lint cases.
