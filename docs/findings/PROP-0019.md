# Factory glossary stub has no output path

**What is wrong:** The Scope section lists "Factory glossary stub produced
during Stage 1" and describes its content (factory-specific terms), but gives
no file path. A planning agent writing the story for this deliverable cannot
determine the output location.

**Fix:** Specify the output path in the Design or Scope section — for example,
`docs/glossary.md` or `factory/docs/glossary.md`.
