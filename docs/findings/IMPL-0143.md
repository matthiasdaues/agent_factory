# The pre-commit page still claims a missing installation always blocks the commit

**What is wrong:** A reader may assume a commit passed the factory gate after
pre-commit skipped that hook. The handbook still says a broken installation
never lets a commit through unchecked. The diagnostic on the same page
describes a per-hook skip that prevents the guard from running. This is the
remaining defect from IMPL-0140.

**Why this severity:** ST-0453 requires the handbook to describe the shipped
behavior. The unconditional claim gives the reader a false guarantee about
a gate that can be skipped.

**Fix:** Replace the last sentence of the paragraph with the guard's actual
behavior. When the hook runs in a clone marked as installed, the guard exits
with an error if the factory folder is missing. Keep the repair instruction
and the sourced no-bypass rule.
