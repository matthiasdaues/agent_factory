# usage-capture reads the project identity from the wrong path

**What is wrong:** `_project_identity` reads `<root>/config/project.json`. `init-factory` writes the identity to `.agent-factory/config/project.json`, so every capture fails with `No such file or directory`. The fixture in `tests/integration/test_capture_independence.py:24` seeds the same wrong path, so its test passes. Source: [bug-hunt report § U-2](../reviews/bug-hunt-2026-10-15.md#u-2--usage-capture-reads-the-project-identity-from-the-wrong-path).

**Fix:** Read `.agent-factory/config/project.json`, and seed the fixture at that path.
