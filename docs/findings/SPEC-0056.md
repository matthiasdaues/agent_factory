# The seed range of 0 to 9998 has no Scenario row and no record against the proposal

**What is wrong:** BR-069 and the seed error table now refuse `9999` and a second pair for one prefix. The Scenario Outline "A seed with a wrong argument fails before it reaches the remote" has neither case. Its examples are `10000`, `abc`, `1000 XX=5`, and `1000 ST=x`.

The proposal, § The script `next-id` step 1 and its seed error table, says 0 to 9999. The specification narrows the range by one value to keep the first claim at four digits. The gaps report records no choice for this change, so a reader who compares the spec with the proposal finds a silent deviation.

**Fix:** Add two rows to the Outline: `9999` names the argument `9999`, and `1000 ST=5 ST=7` names `ST`. Add a choice row to `counter-ids-gaps.md` that states the narrower range, its reason, and BR-069. Tell the stakeholder, so the proposal's step 1 can follow at its next revision.
