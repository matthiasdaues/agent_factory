# Check the race on a GitHub repository

**Priority:** must-have

## Goal

The stakeholder runs the race harness against a GitHub repository and sees that no number comes out twice. The run's output is recorded in this story. An agent cannot do this run, because it pushes to GitHub.

## Domain Rule

- The run uses a scratch GitHub repository without a counter in use, because the harness seeds `refs/ids/counters` (`CID-QG03`).
- The stakeholder deletes `refs/ids/counters` on the scratch repository after the run.
- The run never targets this project's own `origin`.

## Outputs

- The output of the run, pasted into § Run record below.
- The story's `status` set to `done` by the stakeholder.

## Demo Scenario

1. The stakeholder creates the scratch repository of Demo Data on GitHub, with write access from the local git setup.
2. The stakeholder runs `uv run python tests/factory/next_id_race.py --remote https://github.com/matthiasdaues/next-id-race.git --rounds 20`.
3. The harness reports 40 different IDs and no number handed out twice.
4. The stakeholder runs `git push https://github.com/matthiasdaues/next-id-race.git :refs/ids/counters` to delete the scratch counter.

| Item               | Value                                                                                                     |
| ------------------ | --------------------------------------------------------------------------------------------------------- |
