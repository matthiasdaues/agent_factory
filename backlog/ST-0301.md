# Make usage capture count tokens once and keep every record

**Priority:** must-have

## Goal

Fix the findings of cluster `usage-capture` in the [bug-hunt fix run](../docs/reviews/bug-hunt-2026-10-15-fix-run.md).

## Findings

- [BUG-0064](../docs/findings/BUG-0064.md): Claude Code token counts are inflated
- [BUG-0065](../docs/findings/BUG-0065.md): Record IDs collide, so analysis keeps one record per session
- [BUG-0066](../docs/findings/BUG-0066.md): One cut-off character drops a whole capture
- [BUG-0067](../docs/findings/BUG-0067.md): The usage `records/` directory is never used

## Acceptance criteria

- Each finding above has a regression test that fails on the code before
  this story and passes after it.
- New tests go into `tests/factory/test_usage_capture.py`, unless a test file
  for the changed script already exists.
- The full suite passes with `pre-commit run run-tests --all-files`.
- Each finding has its own commit, `fix: <what changed> (BUG-NNNN)`.
- No file outside the list below changes, except tests and the
  documentation of a changed script. Nothing under `.agent-factory/`
  changes.
- The final report names each fix in one or two sentences, the test that
  proves it, and any finding that turned out wrong or needs a decision.
