# Update factory agents, skills, and playbooks to reference agent-context

Update all factory agent markdown files, skill SKILL.md files, and playbook markdown files to reference `docs/agent-context/` with format-detection fallback instead of hardcoded `docs/charter/` paths. Update `inputs:`, `skills:`, body references, and descriptions. Regenerate `factory/INDEX.yaml` with updated descriptions via `index-lint`.

**Priority:** should-have

## Demo

Operator runs `grep -r 'docs/charter' factory/agents/ factory/skills/ factory/playbooks/` across the active factory code. Zero matches appear (legacy templates under `factory/rulebooks/templates/charter-*.md` are exempt -- retained for backward compatibility). Operator runs `index-lint` and `factory/INDEX.yaml` regenerates cleanly with updated descriptions that reference agent-context. Operator opens `factory/agents/developer-agent.md` and confirms that `inputs:` references `docs/agent-context/` with format-detection fallback to `docs/charter/`.

## Acceptance Criteria

- No hardcoded `docs/charter/` path remains in any agent markdown file under `factory/agents/` (agent-context.feature Rule: Convention codifies agent context composition rules, Scenario: Path updates completed across all factory consumers).
- No hardcoded `docs/charter/` path remains in any skill SKILL.md file under `factory/skills/` (same trace).
- No hardcoded `docs/charter/` path remains in playbook files `feature-addition.md`, `greenfield-development.md`, `brownfield-onboarding.md` (same trace).
- Legacy template files under `factory/rulebooks/templates/charter-*.md` are exempt from path updates and retained for backward compatibility.
- `factory/INDEX.yaml` regenerates cleanly via `index-lint` with updated descriptions after frontmatter changes.
- Every updated reference uses format-detection fallback language: "reads from `docs/agent-context/` (falls back to `docs/charter/` for legacy projects)."

## Scope

**Status quo:** Factory agents, skills, and playbooks reference `docs/charter/` with hardcoded paths in `inputs:`, `skills:`, body text, and descriptions. INDEX.yaml contains descriptions with charter references. Format-detection logic exists in context-lint (from ST-0192).

**Adds:** Updated path references across all agent markdown files (~6 agents), all skill SKILL.md files that reference charter paths, and three playbook files. Regenerated INDEX.yaml with updated descriptions.

**Out of scope:** Script and hook path updates (ST-0197). factory-guide.md, README.md, and newcomer-tour (EPIC 5). Backlog story path updates (explicitly deferred per proposal). SVG diagram regeneration (explicitly deferred per proposal).

## Notes for the Implementer

This is a mechanical find-and-replace across ~25 markdown files. The replacement pattern is: change `docs/charter/` references to `docs/agent-context/` with format-detection fallback wording. For `inputs:` frontmatter arrays, reference `docs/agent-context/stack.yaml` (or equivalent) instead of `docs/charter/tech-stack.md`. After all changes, run `index-lint` to regenerate INDEX.yaml. Verify with `grep -r 'docs/charter' factory/agents/ factory/skills/ factory/playbooks/` -- only `factory/rulebooks/templates/charter-*.md` should match.
