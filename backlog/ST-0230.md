# Expand QA agent Fagan inspection with test-design-pass validation and contract-to-test cross-referencing

The QA agent's Fagan inspection gains review criteria for the new test traceability fields: cross-reference the test suite against traced contracts and check the `test-design-pass` field.

**Priority:** must-have

## Demo

The QA agent runs Fagan inspection against a completed non-`.feature`-governed story. It reads `test-design-pass: done` and the `tests:` field, cross-references each listed test module against the story's traced contracts, and confirms every contract has a corresponding test. No finding. A second story has no `test-design-pass` field and is not `.feature`-governed. The QA agent flags this: "non-feature-governed story missing test-design-pass field." A third story has `test-design-pass: done` but the traced contract for the domain entity has no corresponding test in the `tests:` list. The QA agent flags: "contract X traced but no corresponding test in tests: field."

## Acceptance Criteria

- The QA agent's Fagan inspection criteria at `factory/agents/qa-agent.md` include cross-referencing the test suite against traced contracts — every traced contract has a corresponding test or a justified exclusion (completion criterion 9).
- The QA agent checks the `test-design-pass` field and flags non-`.feature`-governed stories where the field is absent (completion criterion 9).
- The QA agent checks whether `done` stories have test coverage for owned contracts — a `done` status with no integration tests for identified gaps is a finding (completion criterion 9).
- The QA agent assesses whether testability red flags from the planning probe were addressed at story level (completion criterion 9).

## Scope

**Status quo:** The QA agent at `packages/factory/agents/qa-agent.md` (v0.4.2) runs Fagan inspection, security review, and bug-hunt. Its Fagan criteria review code correctness and test quality but do not check `test-design-pass` or cross-reference tests against traced contracts. It reads `factory/rulebooks/conventions/testing-strategy.md` for quality context. ST-0229 delivers the `tests:` and `test-design-pass` fields in story files.

**Delivers:** New Fagan inspection criteria for `test-design-pass` validation, contract-to-test cross-referencing, and testability-flag follow-up. No structural change to the QA agent — its skill list, inputs, and workflow remain the same.

**Out of scope:** QA authoring tests (the QA agent judges, not authors). Reconciliation agent changes (ST-0231). Gate script changes (ST-0232).
