# Run scope-lint, statemachine-lint, and link-check against the new layout

**Priority:** must-have

## Goal

In a project in the new layout, `scope-lint` exits non-zero on a seeded error
in `docs/spec/features/core-artifact-layout.feature`, `statemachine-lint` on
one in `docs/spec/state-machines.md`, and `link-check` on a dead link in
`docs/spec/work/todo.md`. Each gate reads the file at its new path.

## Contract

| Operation                                | Input state                                                                       | Outcome                                 | Persistence |
| ---------------------------------------- | --------------------------------------------------------------------------------- | --------------------------------------- | ----------- |
| `scope-lint`                             | `docs/spec/features/core-artifact-layout.feature` without a `# scope:` first line | Finding for that file; exit non-zero    | None        |
| `scope-lint`                             | `docs/spec/architecture.dsl` and `docs/spec/entity-model.md` with valid scope     | Both checked at their new paths; exit 0 | None        |
| `statemachine-lint --spec-dir docs/spec` | `docs/spec/state-machines.md` with a Mermaid transition the pseudocode lacks      | Finding for that file; exit non-zero    | None        |
| `link-check docs/spec/work/todo.md`      | `todo.md` links to `../reviews/missing.md`                                        | Dead-link finding; exit non-zero        | None        |
| Any of the three                         | The same fixture without the seeded error                                         | Exit 0                                  | None        |

## Demo Scenario

1. The maintainer builds the fixture `new-layout-gates` of ST-0325 and removes
   the first line `# scope: global` from
   `docs/spec/features/core-artifact-layout.feature`.
2. The maintainer runs `packages/factory/scripts/scope-lint`. It names that file
   and exits non-zero.
3. The maintainer adds the transition `Draft --> Archived` to the Mermaid
   diagram of `docs/spec/state-machines.md` and runs
   `packages/factory/scripts/statemachine-lint --spec-dir docs/spec`. It exits
   non-zero.
4. The maintainer runs `packages/factory/scripts/link-check docs/spec/work/todo.md`
   on a `todo.md` that links to `../reviews/missing.md`. It exits non-zero.

## Boundaries

- Each gate reads the new path only (DEC-11).
- A gate that finds no input file at the new path must not pass on the seeded
  error. The test fails if the gate exits 0 with the error in place.
- `link-check` needs no code change. This story adds its row to the gate test.
- The repository's own local `statemachine-lint` hook keeps
  `--spec-dir docs/spec` and stays green on the old layout.

## Affected Paths

- `packages/factory/scripts/scope-lint` — existing; feature files from
  `docs/spec/features/`, the DSL from `docs/spec/architecture.dsl`, the entity
  model from `docs/spec/entity-model.{md,yaml}`.
- `packages/factory/scripts/statemachine-lint` — existing; help text and any
  default that names an old path.
- `tests/factory/test_scope_lint.py` — existing; every old path removed.
