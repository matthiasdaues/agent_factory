# Turn chapter 12 into the glossary file and a link line

**Priority:** must-have

## Goal

After `migrate-spec-layout` runs, `docs/spec/glossary.md` holds every chapter
12 table as a section with the columns Term, Definition, and Avoid.
`docs/arc42/12_glossary.md` starts with one line that links to the glossary and
keeps its sections without a table. Git shows the glossary as added and
chapter 12 as modified, so `git log` on chapter 12 keeps its history.

## Contract

| Operation             | Input state of `docs/arc42/12_glossary.md`                       | Outcome                                                                                                                                           | Persistence                                  |
| --------------------- | ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------- |
| `migrate-spec-layout` | Section "Usage Analysis Vocabulary" with a two-column table      | `glossary.md` has section "Usage Analysis Vocabulary" with the same rows under Term, Definition, Avoid                                            | New file, staged                             |
| `migrate-spec-layout` | Two-column table directly under the chapter title                | `glossary.md` has section "Terms" with that table's rows                                                                                          | New file, staged                             |
| `migrate-spec-layout` | Table with the columns "Begriff" and "Bedeutung"                 | Columns renamed to Term and Definition; an empty Avoid cell in every row                                                                          | New file                                     |
| `migrate-spec-layout` | Section "Referenced from" with a list of links                   | The section stays in chapter 12, below the link line                                                                                              | Chapter 12 rewritten at its old path, staged |
| `migrate-spec-layout` | Chapter 12 with earlier commits                                  | `git status` shows `new file: docs/spec/glossary.md` and `modified: docs/arc42/12_glossary.md`; `git log` on chapter 12 lists the earlier commits | Index                                        |
| `migrate-spec-layout` | Chapter 12 holds only the link line and sections without a table | No glossary work; no output from this step                                                                                                        | None                                         |
| `migrate-spec-layout` | A step fails after the glossary step                             | `glossary.md` gone, chapter 12 byte-equal to before; exit 1                                                                                       | Restored                                     |

## Demo Scenario

1. The maintainer copies the fixture `old-layout-glossary` (Demo Data) into
   `/tmp/demo` and runs `packages/factory/scripts/migrate-spec-layout /tmp/demo`.
   It exits 0.
2. `docs/spec/glossary.md` has the sections "Terms" and "Usage Analysis
   Vocabulary", each a table with the columns Term, Definition, and Avoid.
3. `docs/arc42/12_glossary.md` starts with a line that links to
   `../spec/glossary.md`, followed by the section "Referenced from".
4. `git -C /tmp/demo log --oneline docs/arc42/12_glossary.md` lists the two
   commits from before the migration.

## Boundaries

- No definition is dropped. Each row of each chapter 12 table becomes one row
  in the glossary, with the cell text copied as it is.
- Every glossary section is one table with the columns Term, Definition, and
  Avoid, in this order (DEC-12).
- Chapter 12 stays at its old path. The script writes a new chapter 12; it
  never runs `git mv` on it.
- The glossary step joins the undo journal.
- `glossary.md` is created only when chapter 12 or a `CONTEXT.md` has terms.

## Out of Scope

- Terms from `CONTEXT.md` files and the duplicate listing (ST-0324).
- Rendering the glossary as chapter 12 of the PDF (ST-0334).
- Cleaning up or merging terms.

## Agent Stop Conditions

- A chapter 12 table has more or fewer than two columns. Report the table; the
  proposal defines only two-column tables.
- The factory's own chapter 12 holds a construct the conversion would drop.
  Report it; ST-0343 runs the script on that file.

## Resolve Before Implementation

1. Text between the chapter title and the first table, such as the factory's
   intro paragraph. Default: it stays in chapter 12 below the link line, like a
   section without a table.
2. Emphasis in term cells, such as `**Agent**`. Default: the conversion copies
   the cell text as it is; `spec-lint` strips emphasis when it reads a term
   (ST-0327).
