# Consolidate factory layout under .agent-factory and update all path references

After this story ships, `init-factory` installs all factory content under `.agent-factory/` and no top-level `factory/` or `config/` directory exists.

**Priority:** must-have

## Goal

When the developer runs `init-factory`, factory scripts, agents, skills, rulebooks, and engine land at `.agent-factory/factory/` instead of `factory/`. Project configuration (`project-context.json`, `testing.yaml`) lands at `.agent-factory/config/` instead of `config/`. Metadata files drop the `factory-` prefix (`install.json`, `checksums.json`). Usage sibling directories (`usage-analysis/`, `usage-control/`, `usage-runtime/`) collapse into `.agent-factory/usage/` subfolders (`records/`, `transcripts/`, `control/`, `store.duckdb`). All scripts, agent definitions, skill definitions, CLI index files, and the session menu reference `.agent-factory/` paths. `.current-work/` stays unchanged.

## Domain Rule

- All factory-delivered content lives under `.agent-factory/`
- `factory/` moves to `.agent-factory/factory/`; `config/` moves to `.agent-factory/config/`
- `factory-install.json` becomes `install.json`; `factory-checksums.json` becomes `checksums.json`
- Usage siblings collapse into `.agent-factory/usage/` subfolders
- `.current-work/` retains all existing path contracts unchanged (worktrees, dispatch ledgers, verification markers)
- `.gitignore` references `.agent-factory/` entries instead of `/factory/`

## Demo Scenario

1. Run `init-factory --target .` in the project root.
2. Inspect `.agent-factory/factory/`. It contains `scripts/`, `agents/`, `skills/`, `rulebooks/`, and `engine/`.
3. Inspect `.agent-factory/config/`. It contains `project-context.json` and `testing.yaml`.
4. Verify no top-level `.agent-factory/factory/` directory exists. Verify no top-level `config/` directory exists.
5. Inspect `.agent-factory/install.json` (not `factory-install.json`). Inspect `.agent-factory/checksums.json` (not `factory-checksums.json`).
6. Inspect `.agent-factory/usage/`. Subfolders `records/`, `transcripts/`, `control/` exist. `store.duckdb` exists at `.agent-factory/usage/store.duckdb`. No sibling `usage-analysis/`, `usage-control/`, `usage-runtime/` directories exist at `.agent-factory/` level.
7. Inspect `.current-work/`. Worktrees, dispatch ledgers, and verification markers are unchanged.
8. Open `.gitignore`. The factory-related block references `.agent-factory/` entries. No `/factory/` entry exists.
9. Run `.agent-factory/factory/scripts/backlog-lint --backlog-dir backlog`. The script finds its dependencies through `.agent-factory/` paths.
