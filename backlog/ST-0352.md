# Send an open finding to the agent in owner

**Priority:** must-have

## Goal

The orchestrator sends each open finding to the agent that its `owner:` field names, not to the author of the reviewed phase. An open finding without `owner:` goes to the producer of the artifact it names. The finding format defines `owner:` and the two new tags `ARCH` and `QA`, and drops `RECON`.

## Contract

| Operation                   | Input state                                                                           | Outcome                                                                                  | Persistence |
| --------------------------- | ------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ----------- |
| Read `finding-format.md`    | After this story                                                                      | Frontmatter has `owner:`, defined as the agent that acts on the finding next             | —           |
| Read the tag table          | After this story                                                                      | Lists `ARCH` and `QA`; no `RECON`                                                        | —           |
| Read `templates/finding.md` | After this story                                                                      | Has an `owner:` line                                                                     | —           |
| Orchestrator loop           | `SPEC-0040` open, about `docs/spec/state-machines.md`, `owner: domain-modeling-agent` | Sent to the domain-modeling agent only                                                   | None        |
| Orchestrator loop           | `SPEC-0041` open, about `docs/spec/state-machines.md`, no `owner:`                    | Sent to the producer of `state-machines.md`, read from the output declarations (CAO-G26) | None        |

## Demo Scenario

1. The maintainer reads `packages/factory/rulebooks/conventions/finding-format.md`. The frontmatter has `owner:`, and the tag table lists `ARCH` and `QA` and no `RECON`.
2. The maintainer files `SPEC-0040` (Demo Data) in a fixture project.
3. The maintainer runs the review loop of the feature-addition playbook. It sends `SPEC-0040` to the domain-modeling agent and not to the requirements agent.
4. The maintainer files `SPEC-0041` without `owner:`. The loop sends it to the producer of `docs/spec/state-machines.md`.
