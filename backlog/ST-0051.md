# Consolidate usage-capture core contract tests

Reduce the large core module to explicit contracts for normalization, token
conservation, secure containment, atomic reservation, persistence, and
best-effort failure.

**Priority:** must-have

## Acceptance Criteria

- Record the module's before/after collected cases and lines.
- Replace data-only variations with equivalence tables where this reduces test
  code without hiding unrelated assertions.
- Preserve each distinct security boundary and concurrency invariant.
- Remove finding-ID-driven duplication when an existing contract owner can be
  strengthened instead.
- Demonstrate representative token-conservation and containment faults are
  detected by surviving tests.
- The module and full suites pass with warnings treated as errors.

## Implementation Evidence

- Reduced `test_usage_capture.py` from 1,747 to 1,658 lines and from 81 to
  71 collected cases.
- Consolidated only same-contract variations: tokenizer fixtures, record
  schema/defaults, derived totals, UUID fallback, append persistence,
  transcript references, and Claude role-split text.
- Kept distinct containment, symlink, hardlink, permission, concurrency,
  reservation, and best-effort failure contracts independent.
- A temporary `normalized_total` subtraction mutant was rejected by
  `TestNormalizedTotalInvariant::test_total_is_derived_from_input_and_output`.
- A temporary slash-preserving filesystem-key mutant was rejected by
  `TestSecureOpaqueIdentifierStorage::test_hostile_session_ids_map_to_one_contained_component[slash/name]`.
- Module suite: 71 passed with warnings treated as errors.
- Full suite: 438 passed with warnings treated as errors.
