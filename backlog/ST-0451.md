# Hand the changed paths to each measuring command

A story's gate run measures only the files the story changed, so one run costs minutes instead of ten.

**Priority:** must-have

## Goal

With `--base`, `crap-score` tells each measuring command which paths the judged diff holds, and the Python template then runs only the tests that select and traces only the changed files it keeps. A command that runs fewer tests can fail a story wrongly but never pass it.

## Domain Rule

- With `--base`, `GATE_SCOPE` is `changed` and `GATE_CHANGED_FILES` holds the paths of the judged diff, one repository-relative path per line. With `--all`, `GATE_SCOPE` is `all` and `GATE_CHANGED_FILES` is empty. No path outside the diff appears (DEC-84, BR-129).
- `crap-score` stays free of language code. It sets the two variables and never reads them (BR-129).
- Fewer tests can only lower coverage, so the verdict can only get worse for a story, never better (DEC-84).
- With `changed`, the duty of BR-130 covers only the changed files that the measure keeps. A file the diff leaves alone and no test reaches gets no row, and the template exits `0` (DEC-84, BR-130).
- With `changed` and a filled constant `SELECT_COMMAND`, the template runs that command with the changed paths appended. With an empty `SELECT_COMMAND`, or with `all`, it runs `TEST_COMMAND` (DEC-85).
- The template runs pytest with `--basetemp` inside its own work folder and with the cache provider off, so a run leaves no pytest temp folder and no `.pytest_cache` behind (DEC-85).

## Outputs

- `crap-score` sets `GATE_SCOPE` and `GATE_CHANGED_FILES` for every measuring command.
- The template `crap-measure-python` has the constant `SELECT_COMMAND`, empty by default, traces only the changed kept files under `changed`, and keeps pytest's temp folders in its work folder.
- `crap-score/SKILL.md` and `setup-crap-score/SKILL.md` describe the two variables, and the second also `SELECT_COMMAND`.

## Demo Scenario

1. The maintainer runs `crap-score --base dev` with a recording stub as measuring command, on a story that changes `packages/factory/scripts/finding-lint` and `packages/factory/scripts/dispatch`. The stub logs `GATE_SCOPE=changed` and those two paths.
2. The maintainer runs `crap-score --all` with the same stub. The log shows `GATE_SCOPE=all` and an empty `GATE_CHANGED_FILES`.
3. In a temporary project with two tested files, the maintainer runs the Python template with `GATE_SCOPE=changed` and one path. The output holds rows of that file only, and no `.pytest_cache` remains.
4. The maintainer fills `SELECT_COMMAND` with a script that logs its arguments and runs the template again. The log shows the changed path as the last argument.

## Analysis

- `crap-score` hands each measuring command the scope through two variables. The paths of the judged diff are the files that `changed_lines` reads from the diff, so a deleted file is not among them. A path with a line break cannot sit on one line, so it makes the gate exit `2`, as a pattern with a line break does (DEC-65).
- The scope travels on `Measure`, so `run_measure` keeps its three parameters. Tests outside `touches`, such as `test_crap_gate_judging.py`, replace `run_measure` with a function of three parameters.
- Under `changed`, the template measures only the changed files that `GATE_FILES` and `GATE_EXCLUDE` keep. coverage.py traces them through `include` instead of `source`. With no such file, the template runs no test and writes an empty array.
- `SELECT_COMMAND` runs with every path of `GATE_CHANGED_FILES` appended, test files included, because the selector decides which tests a path selects.
- The pytest options reach any test command through `PYTEST_ADDOPTS`. The `sitecustomize.py` of the template sets the variable in each Python process, with a `--basetemp` per process ID below the work folder. So a pytest that a test starts cannot clear the temp folder of the pytest that runs that test.
- Tests: CG-03-IT-06, CG-03-IT-07 and CG-04-IT-18 in `test_crap_gate_score.py`; CG-03-IT-04, CG-03-IT-08, CG-03-IT-09 and CG-03-IT-10 in `test_crap_gate_template.py`.
