# Supersede cycle-based orchestration proposal and write characterization tests

After this story ships, the cycle-based orchestration proposal carries `status: superseded` and characterization tests verify that every standard check, branch safety command, and indexed agent/skill name from the acceptance commit still works after the layout migration.

**Priority:** should-have

## Goal

The `docs/proposals/cycle-based-orchestration.md` frontmatter status changes from `accepted` to `superseded`. Characterization tests (tests that verify existing contracts survive the migration) cover three areas: standard check commands retain their command name, triggers, result format, and exit behavior; branch safety commands (`verify-base`, `premerge-check`) retain their contracts; every indexed agent and skill name from the acceptance commit still exists in the post-migration index.

## Domain Rule

- Every standard check retains its command name, triggers, result format, and exit behavior after migration
- Branch safety commands (`verify-base`, `premerge-check`) retain their existing contracts
- Every indexed agent and skill name from the acceptance commit still exists in the post-migration index
- The superseded proposal keeps its full content; only the `status` field changes

## Demo Scenario

1. Open `docs/proposals/cycle-based-orchestration.md`. The frontmatter `status` field reads `superseded`.
2. Run the characterization test suite. All tests pass.
3. Inspect the standard-check characterization test. It invokes `backlog-lint`, `index-lint`, `concern-lint`, and other standard checks and verifies each retains its command name and exit behavior.
4. Inspect the branch-safety characterization test. It verifies `verify-base` and `premerge-check` retain their contracts.
5. Inspect the indexed-name characterization test. It reads INDEX.yaml and verifies every agent and skill name from the acceptance commit still exists.

## Demo Data

No seeded data required. The characterization tests run against the post-migration repository state (ST-0275 delivered). The acceptance commit's INDEX.yaml provides the baseline agent and skill names.
