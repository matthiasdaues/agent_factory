# Claude Code Stop and SubagentStop hook script

The shared hook script Claude Code runs on session end. On a `Stop` (human
main session) or `SubagentStop` (dispatched sub-agent) event it reads the
transcript path and session id from the hook payload and invokes
`usage-capture` with `--cli claude-code` and the available context. One
hook-pair covers both the human main session and every sub-agent within the
CLI.

The script mirrors the existing `block-dangerous-git.sh` guardrail hook:
factory-owned under `factory/config/hooks/`, symlinked into a project by
init-factory, and resolving its target through `$CLAUDE_PROJECT_DIR`.

**Priority:** must-have

## Acceptance Criteria

- `factory/config/hooks/capture-usage.sh` reads the Claude Code hook payload
  (transcript path and session id) and invokes `usage-capture` with
  `--cli claude-code --transcript <path>` and the session context it can
  extract.
- It handles both the `Stop` and the `SubagentStop` payload shapes.
- It resolves `usage-capture` under `$CLAUDE_PROJECT_DIR`, the way
  `block-dangerous-git.sh` resolves its own target.
- It runs without blocking and always exits zero, so ending a session is
  never delayed or failed by capture.

## Analysis

**Traces:** Capture Triggers per CLI, Core Principles (proposal
`token-usage-tracking.md`)

**Hook contract verified:** Claude Code sends Stop and SubagentStop events
to the registered hook on STDIN as JSON. Fields extracted:

- Common: `session_id`, `transcript_path`, `hook_event_name`
- SubagentStop adds: `agent_type`, `agent_id`

**Implementation:**

- Reads hook payload from stdin, parses with `jq`
- Validates transcript_path and session_id are non-empty; exits 0 if missing
- Resolves usage-capture: prefer `$CLAUDE_PROJECT_DIR`, fallback to git
  toplevel or derived path
- Builds command: `usage-capture --cli claude-code --transcript ... --session ...`
- For SubagentStop: adds `--agent <agent_type>` when available
- Runs in background (non-blocking) to never delay session end
- Redirects stderr to /dev/null to silence best-effort errors
- Always exits 0 per spec: "capture never fails, blocks, or slows the run"

**Verification:**

- Stop hook: exit 0, record written to `.agent-factory/usage/test-s1.jsonl`
- SubagentStop hook: exit 0, record includes `"agent": "my-agent"`
- Missing transcript_path: exit 0 (silent skip)
- Missing session_id: exit 0 (silent skip)
- Transcript copies persisted under `.agent-factory/usage/transcripts/`

**Spec alignment:** Matches "Capture Triggers, per Claude Code" in proposal;
resolves via $CLAUDE_PROJECT_DIR following block-dangerous-git.sh pattern.
