# Lead the User through a run by hand

**Priority:** must-have

## Goal

The implementation agent's instructions stop before each step of a run by hand that needs the User, name the command, and wait for the go. They leave the User three commands. The developer agent's instructions run no gate script and never set `done`.

## Domain Rule

- By hand, the agent stops before a story starts, before it merges, when it stops as `failed` or `blocked`, and before the merge into `dev`. In a run by hand, `dispatch add` also waits for the go (RL-C08).
- At each stop, the agent shows the story and its branch head, the findings with their status, and the output of `premerge-check`, then names the command.
- The User runs only `dispatch return-story`, `dispatch close --drop` and `dispatch close`, with `!` in Claude Code or in a terminal.
- Every story follows the same steps on both ways: implement and commit, review, fix each open blocking finding with a repeat review, gate-check step, `merge-story`.
- The developer agent commits on both ways and never runs a gate script or sets `status: done`.

## Outputs

- `implementation-agent.md` gets the stops by hand and the story workflow order; the line that names reconciliation before the feature checks stays for ST-0424.
- `developer-agent.md` drops the gate run by hand and the `done` update.
- `rules.md` drops the line that the human owns every gate decision by hand and the rule that the ledger is an audit trail.
- `branching-policy.md` describes story branches by hand, cut from the feature branch.
- The `test_st_0365_*` tests of `TestSt0365FourGatesInBothModes` and the four `test_st_0362_manual_mode_*` tests change in the same commit.

## Demo Scenario

1. The User asks the implementation agent for a run by hand of ST-0350 on `feature/login`.
2. The agent stops, shows ST-0350, and names `dispatch prepare-story ST-0350`. It runs the command only after the User's go.
3. After the review and the gate-check step, the agent stops again, shows the findings and the `premerge-check` output, and names `dispatch merge-story ST-0350`.
4. The developer agent's commits contain no gate result and no `status: done`.
