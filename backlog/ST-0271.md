# Build Housekeeping About section and Re-fit and Update Factory actions

The Housekeeping K lane displays factory state and offers maintenance actions so the developer can inspect and update the installation without reading files manually.

**Priority:** should-have

## Goal

After this story ships, the developer selects lane K in the session menu and sees an About section showing the installed Factory version, fitting status, configured CLI integrations, and usage pipeline health. Unreadable values appear as "unknown" with the source error. The developer can run Re-fit to rerun all five fitting steps, or Update Factory to install the latest factory version and refresh the About display.

## Domain Rule

- About section reads from four sources: `install.json` (installed version), `project-context.json` (fitting status), project configuration (CLI integrations), and usage state (pipeline health)
- Each source is read independently; a failure in one source does not prevent reading others
- Unreadable values appear as "unknown" with the source error message, not as blank or omitted
- Re-fit reruns all five fitting steps: model matrix, fingerprint, agent context, test regime, hooks
- Re-fit reports completed and remaining steps after running
- Update Factory runs `init-factory --update <project-root> --force`
- Update Factory relays the command output and exit status to the developer
- About section refreshes after a successful Update Factory

## Demo Scenario

1. Start a factory session. Select K (Housekeeping).
2. The About section shows: "Factory version: 0.12.0", "Fitting: 5/5 (model matrix, fingerprint, agent context, test regime, hooks)", "CLI integrations: claude, copilot, pi, codex", "Usage pipeline: healthy".
3. Remove `install.json` temporarily. Select K again. The version line shows "unknown (FileNotFoundError: install.json not found)".
4. Restore `install.json`. Select Re-fit. The factory runs the five fitting steps and reports "Fitting complete: 5/5 done".
5. Select Update Factory. The factory runs `init-factory --update . --force`, relays the output ("Factory updated to 0.12.0"), and refreshes the About section.
