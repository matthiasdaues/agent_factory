Wire the `detect-test-regime` skill into `factory/scripts/init-factory` (main flow at lines 2008-2034) so that it runs during project onboarding. When Factory onboards a project, it scans for existing test regime evidence and records findings in `docs/charter/testing.yaml`.

**Priority:** must-have

## Acceptance Criteria

- `init-factory` invokes the `detect-test-regime` skill during the onboarding flow
- The skill runs after the factory directory is set up but before the final summary
- When a test regime is detected, `docs/charter/testing.yaml` is populated with the result
- When no test regime is detected, the gap is surfaced to the user
- Factory does not inject any test-related hooks into `.pre-commit-config.yaml` during init
- Existing project test hooks are preserved during init
- The init-factory script remains functional for projects with and without existing test regimes
