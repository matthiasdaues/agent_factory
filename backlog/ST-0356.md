# Review every structure file and the glossary

**Priority:** must-have

## Goal

The spec-review agent reports on each structure file that exists and on the glossary. It files a finding for every term that waits for the stakeholder's confirmation. It runs in a project without schemas or area specs.

## Contract

| Operation      | Input state                                                                       | Outcome                                     | Persistence               |
| -------------- | --------------------------------------------------------------------------------- | ------------------------------------------- | ------------------------- |
| Spec review    | Feature files, scope map, glossary, `entity-model.md`; no `schemas/`, no `areas/` | Review runs                                 | Review report             |
| `inspect-spec` | Each present structure file                                                       | One check section per file                  | Review report             |
| `inspect-spec` | Glossary holds `Batch` and `PaymentBatch` for one concept                         | Finding: two terms for one concept          | `docs/findings/SPEC-*.md` |
| `inspect-spec` | A term used without a definition                                                  | Finding: term not defined                   | `docs/findings/SPEC-*.md` |
| `inspect-spec` | A term from an Avoid column in use                                                | Finding: avoided term in use                | `docs/findings/SPEC-*.md` |
| Spec review    | Work-file row with status `proposed`                                              | Finding with `owner: domain-modeling-agent` | `docs/findings/SPEC-*.md` |
| Spec review    | Scope map                                                                         | Read only; no finding on its content        | None                      |

## Demo Scenario

1. The operator runs the spec-review agent on the fixture `structure-review` (Demo Data). The review runs, although `schemas/` and `areas/` are missing.
2. The review report holds a section for `entity-model.md`, `state-machines.md`, and the glossary.
3. The report records a finding for `Batch` and `PaymentBatch`, and a `SPEC` finding for the `proposed` row `LedgerLine` with `owner: domain-modeling-agent`.
