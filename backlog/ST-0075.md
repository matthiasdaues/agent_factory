# Create charter-lint script

Create `factory/scripts/charter-lint` — a deterministic validation gate for the project charter. Python 3.10+ stdlib only, matching the pattern of `spec-lint`, `arch-lint`, and `backlog-lint`. Exit 0 = pass, non-zero = findings on stderr.

**Priority:** must-have

## Acceptance Criteria

- Script at `factory/scripts/charter-lint` with shebang, executable
- Default mode validates: all three files exist under `docs/charter/`, required sections present per template, no section empty, YAML frontmatter parses
- `--planning-gate` mode additionally checks: tech-stack.md has no "To be decided" entries, development.md has no "To be decided" entries, house-rules.md may have "To be decided" without failing
- Exit code is the number of error-severity findings (0 = clean)
- Findings printed to stderr in the same format as other lint scripts
- `--format json` and `--report-only` flags supported, matching `backlog-lint` conventions

## Implementation Notes

Follow the structural pattern of `factory/scripts/backlog-lint`. The script reads the template files to know which sections are required — do not hardcode section names in the script if it can be derived from the templates.
