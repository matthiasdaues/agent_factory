# Fold the factory's routing into the agent context file

**Priority:** must-have

## Goal

The factory maintainer runs `capture-context --fold-context-map` on the
migrated repository and gets one domain concern in `docs/agent-context.md` per
context of the old `docs/arc42/CONTEXT-MAP.md`. After the maintainer deletes
`docs/CONTEXT.md` and `docs/arc42/CONTEXT-MAP.md`, `concern-lint` and
`link-check` pass.

## Domain Rule

- `docs/agent-context.md` is the one routing file (DEC-07).
- Each folded concern carries the fold mark of ST-0328 and routes to
  `docs/spec/glossary.md`.
- The fold never deletes a file; the maintainer deletes the two old files after
  the review.

## Outputs

- `docs/agent-context.md` with one folded domain concern per context of the old
  context map.
- Every Markdown link under `docs/` that pointed at `CONTEXT.md` or
  `CONTEXT-MAP.md` points at `docs/agent-context.md`.
- `docs/CONTEXT.md` and `docs/arc42/CONTEXT-MAP.md` deleted with `git rm`.
- The story report records the fold's output and the two gate runs as the
  acceptance record of CAL-08-AC-01.

## Demo Scenario

1. The factory maintainer runs `capture-context --fold-context-map` on the
   migrated repository and confirms the proposed concerns.
2. `docs/agent-context.md` has one domain concern per context listed in
   `docs/arc42/CONTEXT-MAP.md`, each with the fold mark.
3. The maintainer runs `git rm docs/CONTEXT.md docs/arc42/CONTEXT-MAP.md`.
4. `packages/factory/scripts/concern-lint` passes, and
   `packages/factory/scripts/link-check` on every Markdown file under `docs/`
   passes.

## Demo Data

None. The story runs on the factory's repository after ST-0343. It needs
`docs/arc42/CONTEXT-MAP.md` and `docs/CONTEXT.md` without a `## Language`
section, which ST-0343 leaves in place.

## Boundaries

- The fold runs with the maintainer present, as every mode of
  `capture-context` does.
- Only `docs/` changes. The skill text is ST-0328's.
- Story `concerns:` fields in `backlog/` must still resolve after the fold
  (`concern-lint` `CTX-REFS`).

## Affected Paths

- `docs/agent-context.md` — existing; folded domain concerns.
- `docs/CONTEXT.md`, `docs/arc42/CONTEXT-MAP.md` — existing; removed.
- `docs/` — Markdown files whose links the fold rewrites.
