# Keep the factory free of old paths

**Priority:** must-have

## Goal

The factory maintainer runs the eleven old-path greps of the Completion
Criteria and `grep -rE 'CONTEXT(-MAP)?\.md' packages/factory/` and finds
nothing outside the exclusions. A test in the default suite fails as soon as an
old path comes back.

**Added 2026-11-02 (stakeholder):** also clean up the `ruff` findings in the
Python files this feature changed (`git diff --name-only 4040854f..HEAD`,
`.py` files and the extensionless scripts under `packages/factory/scripts/`).
At the wave-5 head, `ruff check` reports 32 there: FURB167, C4, ISC004,
FLY002, I001, RUF100. The cleanup is one mechanical commit with no change in
behaviour; the full suite passes before and after it. Leave findings in files
this feature did not touch.

**Added 2026-11-02 (stakeholder):** set `packages/factory/VERSION` to
`1.4.0`, the layout release (CAL-G02), and add the matching `packages/factory/CHANGELOG.md`
entry. Without it, `init-factory` sees every later update as one from a
version before the layout and runs the migration again, which then has no
work.

## Contract

| Operation          | Input state                                                                                            | Outcome                                                | Persistence |
| ------------------ | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------ | ----------- |
| Default test suite | No old path in `packages/factory/`, `tests/factory/`, `.pre-commit-config.yaml` outside the exclusions | Guard test passes                                      | None        |

## Demo Scenario

1. The factory maintainer runs, for each of the eleven patterns,
   `grep -rnE '<pattern>' packages/factory/ tests/factory/ .pre-commit-config.yaml`,
   then `grep -rnE 'CONTEXT(-MAP)?\.md' packages/factory/`. No hit lies outside
   the exclusions.
2. On a scratch branch, the maintainer adds `docs/spec/prd.md` to
   `packages/factory/skills/write-prd/SKILL.md` and runs
   `uv run pytest --tb=short --quiet tests/factory/test_core_layout_references.py`.
   The guard test fails and names the file.

## Demo Data

None. The guard reads the repository itself.

## Boundaries

- The eleven patterns are exactly those of the Completion Criteria:
  `supplementary_specs`, `docs/arc42/[a-z-]+\.dsl`, `docs/spec/[^/]+\.feature`,
  `docs/spec/prd\.md`, `docs/spec/[^/]+-(gaps|qa-strategy)\.md`,
  `docs/spec/todos?\.md`, `docs/arc42/themes`, `arc42/\(architecture`,
  `UC-XX`, `use_cases`, `actor-goal-list`.
- Exclusions for the eleven patterns: `CHANGELOG.md`, `reports/`,
  `scripts/migrate-spec-layout`, and that script's tests.
- Exclusions for `CONTEXT(-MAP)?\.md`: `CHANGELOG.md`,
  `scripts/migrate-spec-layout` and its tests, and the `--fold-context-map`
  section of `capture-context/SKILL.md`.
- The guard test file itself must not trip the guard; it builds the patterns
  so that its own text is not a match, or excludes itself by name.
- The guard runs in the default suite, without the `container` marker.
