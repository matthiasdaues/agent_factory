# Update factory/README.md with test execution overview

Add a "Test Execution" section to `factory/README.md` documenting the three
hook integration points (pre-commit, pre-push, phase advance), agent
prohibition on bare test commands, and the `--staged` mode for agent test
iteration. This provides you and your agents with a single reference for how
tests run in Agent Factory.

**Priority:** should-have

## Acceptance Criteria

- `factory/README.md` gains a new "Test Execution" section (placed after
  "Validation Gates" or similar).
- Section documents all three hook integration points:
  - **Pre-commit**: `run-tests --changed-only`, fast feedback, bypassable with
    `--no-verify`
  - **Pre-push**: `run-tests --full`, ready-to-share gate, not bypassable
  - **Phase advance**: `script_exit_zero: factory/scripts/run-tests --full` as
    FSM entry condition
- Section explains agent prohibition (BR-024): agents cannot run bare test
  commands, must use `factory/scripts/run-tests --staged` for iteration.
- Section includes a "Test Iteration for Agents" subsection with the workflow:
  1. Write test
  2. Stage: `git add test_foo.py`
  3. Run: `factory/scripts/run-tests --staged`
  4. Fix and re-run until green
  5. Commit
- Section cross-references ADR-0003 and UC-09.
- No other sections of the README restructured.

## Implementation Notes

**Section structure:**

```markdown
## Test Execution

Tests run via three unavoidable hooks only. Agents are blocked from running test commands directly.

### Hook Integration Points

1. **Pre-commit** (fast feedback)
   - Runs: `factory/scripts/run-tests --changed-only`
   - When: Every `git commit`
   - Scope: Tests for changed files only (pytest `--lf`, jest `--onlyChanged`)
   - Bypass: `git commit --no-verify` for WIP (discouraged)

2. **Pre-push** (ready-to-share gate)
   - Runs: `factory/scripts/run-tests --full`
   - When: Every `git push`
   - Scope: Complete test suite, no filtering
   - Bypass: None — work cannot leave local machine with failing tests

3. **Phase advance** (FSM gate)
   - Evaluated as: `script_exit_zero: factory/scripts/run-tests --full`
   - When: Phase transition attempts
   - Effect: Phase refuses to advance while tests are red

### Agent Test Iteration

Agents cannot run bare test commands (`pytest`, `npm test`, etc.) — these are blocked by `block-dangerous-git.sh` (BR-024). For test iteration during development:

1. Write test file (e.g., `test_foo.py`)
2. Stage: `git add test_foo.py`
3. Run: `factory/scripts/run-tests --staged`
4. See immediate feedback without committing
5. Fix test if needed, re-run
6. Commit when green

This preserves "tests run via factory mechanisms" while unblocking TDD workflows.

**Referenced from:**

- [UC-09 — Run Tests via Hook](../docs/spec/use_cases/UC-09-run-tests-via-hook.md)
```
