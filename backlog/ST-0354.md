# Review the dependency rules against the component view

**Priority:** must-have

## Goal

The architecture-review agent checks `docs/spec/dependency-rules.dsl` against the component view of `architecture.dsl`. In a project without the rules file, the review still runs.

## Contract

| Operation           | Input state                                       | Outcome                                 | Persistence               |
| ------------------- | ------------------------------------------------- | --------------------------------------- | ------------------------- |
| `atam-review`       | A rule names a component the component view lacks | Finding in the review                   | `docs/findings/ATAM-*.md` |
| `atam-review`       | Every rule names existing components              | No finding on the rules                 | Review report             |
| Architecture review | No `dependency-rules.dsl`                         | Review runs; the rules check is skipped | Review report             |

## Demo Scenario

1. The reviewer runs the architecture-review agent on the fixture `rules-unknown-component` (Demo Data). The review files a finding that the rule names `ledger`, which the component view lacks.
2. The reviewer runs it on `no-rules`. The review runs and reports no rules check.

## Demo Data

| Fixture                   | Content                                                                                                     |
| ------------------------- | ----------------------------------------------------------------------------------------------------------- |
| `rules-unknown-component` | `architecture.dsl` with the components `payments` and `api`; `dependency-rules.dsl` with a rule on `ledger` |
| `no-rules`                | `architecture.dsl` with `payments` and `api`; no `dependency-rules.dsl`                                     |
