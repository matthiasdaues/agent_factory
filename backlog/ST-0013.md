# Configure pre-push hook to run full test suite

Create a `pre-push` git hook that invokes `factory/scripts/run-tests --full`,
running the complete test suite before any push. This is the "ready to share"
gate — no bypass available. Work cannot leave the local machine with failing
tests.

Unlike the pre-commit hook (which uses pre-commit framework and is bypassable),
the pre-push hook is a raw git hook script installed via
`factory/scripts/install-hooks`, matching the pattern of
`block-dangerous-git.sh`.

**Priority:** must-have

## Acceptance Criteria

- `.github/hooks/pre-push` script created.
- Script invokes `factory/scripts/run-tests --full`.
- If `run-tests` exits `0`: push proceeds.
- If `run-tests` exits `1` or `2`: push is blocked, stderr shows test failures
  or error message.
- No `--no-verify` bypass available (pre-push hooks cannot be easily bypassed).
- `factory/scripts/install-hooks` updated to install `.github/hooks/pre-push`
  to `.git/hooks/pre-push`.
- Hook script includes a header comment explaining: "Pre-push test gate — full
  suite runs before push. No bypass. Work cannot leave local machine with
  failing tests."

## Implementation Notes

**Hook script structure:**

```bash
#!/usr/bin/env bash
# pre-push — Run full test suite before push (no bypass)
#
# Installed by factory/scripts/install-hooks
# See: ADR-0003 (Test execution via unavoidable hooks)

set -euo pipefail

factory/scripts/run-tests --full
exit_code=$?

if [ $exit_code -ne 0 ]; then
    echo "❌ Pre-push blocked: tests failed. Fix tests and retry." >&2
    exit 1
fi

exit 0
```

**install-hooks integration:**

`factory/scripts/install-hooks` already installs `block-dangerous-git.sh` to
`.git/hooks/`. Add a similar stanza to install `pre-push`:

```bash
# Install pre-push hook for full test suite validation
cp .github/hooks/pre-push .git/hooks/pre-push
chmod +x .git/hooks/pre-push
```

**Relationship to pre-commit:**

- **pre-commit**: fast feedback (changed files only), bypassable for WIP
- **pre-push**: ready-to-share gate (full suite), not bypassable
