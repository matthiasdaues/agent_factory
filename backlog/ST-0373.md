# Commit an indexed artifact on the branch where it is made

**Priority:** must-have

## Goal

The User and the agents commit a new story, finding, todo entry, or ADR on the branch where they make it. No Factory rule requires indexed artifacts on `dev`. Two sessions on two branches get different IDs for the same ID prefix.

## Contract

| File                                                         | Rule after the story                                                                 |
| ------------------------------------------------------------ | ------------------------------------------------------------------------------------ |
| `packages/factory/rulebooks/rules.md` § Branching            | An indexed artifact may be created and committed on any branch                       |
| `packages/factory/rulebooks/conventions/branching-policy.md` | § Indexed Artifacts On Dev is replaced by a rule that allows any branch              |
| `packages/factory/agents/planning-agent.md`                  | Phase 5 allows the backlog on any branch and no longer calls `dev` the index for IDs |

| Operation                                    | Input state                                                                          | Outcome                  | Persistence                                                      |
| -------------------------------------------- | ------------------------------------------------------------------------------------ | ------------------------ | ---------------------------------------------------------------- |
| `next-id IMPL` in two clones, one per branch | One clone on `dev`, one on `feature/counter-ids`; neither holds the other's findings | Two different `IMPL` IDs | Each clone commits `docs/findings/<its ID>.md` on its own branch |

## Demo Scenario

1. The User makes two clones of the bare repository of Demo Data: `/tmp/a` on `dev` and `/tmp/b` on `feature/counter-ids`.
2. In `/tmp/a`, the User runs `next-id IMPL`. It prints `IMPL-1001`. In `/tmp/b`, `next-id IMPL` prints `IMPL-1002`.
3. Each clone commits its finding file on its own branch. The two file names differ.
4. The User reads `rules.md` § Branching and `branching-policy.md`. Both allow indexed artifacts on any branch, and neither requires `dev`.

| --------------- | ---------------------------------------------------------------------------------------------------------------- |
