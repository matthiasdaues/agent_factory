# Add Goal column to create-backlog-story-slices slice table

Add a Goal column to the story-level slice table in the Phase 3 story-slicing skill. The Goal column forces the planning agent to state what each story delivers in plain language before writing the full story file.

**Priority:** must-have

## Demo

1. Open `packages/factory/skills/create-backlog-story-slices/SKILL.md`.
2. The story-level slice table header reads: `| # | Capability | Goal (one sentence) | Boundaries crossed | Demo sentence |`.
3. The accompanying instructions explain that the Goal column states what each story delivers in plain language and seeds the story's Goal section in Phase 4.

## Acceptance Criteria

- The slice table header includes a Goal column between Capability and Boundaries crossed (agent-ready-story-format.md § Changes to create-backlog-story-slices).
- The Goal column description states: one sentence of concrete behavior per story, written in plain language.
- The instructions explain that the Goal column seeds the story's Goal section in Phase 4.

## Scope

**Status quo:** `packages/factory/skills/create-backlog-story-slices/SKILL.md` defines a 4-column slice table: `| # | Capability (what a person can do after) | Boundaries crossed | Demo sentence |`. No Goal column.

**Delivers:** A 5-column slice table with the Goal column added.

**Out of scope:** Changes to the EPIC-level slice table in create-backlog-epics. Changes to other Phase 3 instructions.
