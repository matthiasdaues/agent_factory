# Create a validated phase handoff contract

Give an outgoing phase one CLI-neutral restart contract whose structural
defects are blocked mechanically and whose semantic completeness is reviewed
separately against durable evidence.

**Priority:** must-have

## Acceptance Criteria

- The handoff convention defines every Factory phase boundary, mandatory stop,
  fresh-session entry, and exemption for work remaining within one phase.
- The handoff skill preserves decisions, open items, artifact paths, branch and
  upstream state, gate and verification evidence, next action, and exact
  40-character SHAs in dense prose.
- `handoff-lint` reports all detectable missing sections, malformed declared
  fields, missing referenced paths, and malformed SHAs in one non-zero run.
- Passing structural lint makes no semantic-losslessness claim; the contract
  requires an independent semantic review before phase closure.
- Installation/index coverage proves the skill is generated for every
  supported CLI.

## Implementation Notes

Owns the handoff format, skill, deterministic validator, catalog entry, and
focused contract tests. It excludes in-place transcript compaction.
