# Generate Codex custom agents from canonical Factory agents

Create a deterministic, standard-library-only adapter from
`factory/agents/*.md` to project-scoped `.codex/agents/*.toml`.

**Priority:** must-have

## Acceptance Criteria

- Every canonical agent generates one TOML file with `name`, `description`, and
  the full Markdown body as `developer_instructions`.
- Generated TOML is parseable, stable, and marked as Factory-owned.
- Re-running refreshes only Factory-owned generated files.
- A real file, directory, or foreign symlink at a destination fails before that
  destination is overwritten.
- No model, reasoning-effort, sandbox, or MCP settings are pinned.
- Focused tests cover multiline descriptions, TOML escaping, idempotent refresh,
  stale owned-file pruning, and foreign collisions.
