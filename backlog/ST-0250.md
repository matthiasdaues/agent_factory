# Prove capture works without analysis and enforce the dependency boundary

Add a capture-independence test and a dependency boundary rule confirming Factory and Usage Analysis do not depend on each other.

**Priority:** should-have

## Goal

After this story ships, the operator removes the usage-analysis component, runs capture, and sees a new JSONL record appended to `.agent-factory/usage/`. Running `dependency-check` exits zero, confirming Factory has no import dependency on Usage Analysis and Usage Analysis consumes only the published record contract.

## Domain Rule

- Capture appends records without invoking DuckDB or analysis components.
- Factory has no import dependency on Usage Analysis.
- Usage Analysis consumes only the published record contract.

## Demo Scenario

1. Install Factory with the usage-analysis component present. Remove `.agent-factory/usage-analysis/` (or run `init-factory --remove usage`).
2. Run the capture pipeline. Verify a new JSONL record is appended to `.agent-factory/usage/`.
3. Run `packages/factory/scripts/dependency-check`. Verify it exits zero, reporting no import leaks between Factory and Usage Analysis.

## Affected Paths

- `packages/factory/scripts/dependency-check` — existing file, add Usage Analysis boundary rule
- `tests/integration/test_capture_independence.py` — new file (capture-independence test)

- ST-0249 deliverables: component lifecycle operations in distribution scripts

- QA strategy: `docs/spec/local-usage-processing-and-analysis-qa-strategy.md` — contract owners LU-09 (capture independence, test ID LU-09-IT-01) and LU-11 (dependency boundary, test ID LU-11-LN-01)

## Outputs

- `packages/factory/scripts/dependency-check` gains a boundary rule that scans Factory source for Usage Analysis imports and Usage Analysis source for Factory imports beyond the published contract. The gate exits non-zero if any boundary violation is found.
- `tests/integration/test_capture_independence.py` — test that removes the analysis component (or asserts its absence), runs capture, and verifies a new JSONL record appears in the spool.

## Constraints

- Do not modify the capture pipeline behavior. The test asserts existing behavior.
- The dependency-check boundary rule scans import statements only. It does not execute the modules.
- Do not add new dependencies to `packages/factory/`.

## Suggested Agent Plan

1. Read the existing `dependency-check` script to understand how boundary rules are defined.
2. Add a boundary rule for the Factory/Usage Analysis boundary: Factory must not import from `usage`, and `usage` must not import from Factory beyond reading the installed contract copy.
3. Write `tests/integration/test_capture_independence.py`: set up a fixture directory without `.agent-factory/usage-analysis/`, run `usage-capture`, assert a new JSONL line exists in `.agent-factory/usage/`.
4. Run `packages/factory/scripts/dependency-check` and verify exit zero.
5. Run the full test suite and verify all tests pass.
