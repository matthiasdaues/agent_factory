# Wire Project Work lane for workstream creation and continuation

The Project Work lane creates new workstreams and continues existing ones, binding the session and showing agents with precondition evidence.

**Priority:** must-have

## Goal

The Project Work lane (P) in the session menu creates a new workstream when none is bound (prompts for topic, optional proposal origin, creates state file, binds session) or lists existing workstreams for continuation (displays topics, binds selected workstream, calls the precondition evaluator to present all agents with requirement evidence). When no workstreams exist and the developer chooses to continue, the factory offers to start a new workstream or return to the menu.

## Domain Rule

- Creating a workstream: the developer provides a topic description and optionally names an existing proposal as the origin reference.
- The workstream state file is created using the workstream engine module (ST-0269).
- A session binding is created immediately after workstream creation.
- Continuing a workstream: the factory lists existing workstream topics and lets the developer select one.
- After binding (creation or continuation), the precondition evaluator checks all agents against the repository and presents results.
- When no workstreams exist, the factory offers to start a new workstream or return to the menu. It never selects a workstream automatically.

## Demo Scenario

1. Start a factory session. Select P (Project Work). No workstream exists.
2. The factory asks for a topic description. The developer types "activity graph orchestration".
3. The factory asks whether an existing proposal should be the origin. The developer names "docs/proposals/activity-graph-orchestration.md".
4. A workstream state file is created at `.agent-factory/workstreams/activity-graph-orchestration.yaml`. A session binding is created at `.agent-factory/workstreams/sessions/<session-id>.yaml`.
5. The precondition evaluator runs. All agents are listed with their requirement evidence: satisfied inputs show matched paths, unsatisfied inputs show what is missing.
6. Start a new session. Select P. Choose to continue. The workstream "activity graph orchestration" appears in the list.
7. Select it. The session binding is created. The evaluator runs and presents agents with evidence.
8. Start a new session. Select P. Choose to continue. Delete all workstream files first. The factory says no workstreams exist and offers to start a new one or return to the menu. It does not select a workstream automatically.
