# Build intent select script and wire agent presentation into Project Work

Create the `intent select` CLI command and integrate agent evidence display into the Project Work lane.

**Priority:** must-have

## Goal

After this story ships, the developer runs `intent select` and sees every agent listed with its name, description, and each required input marked satisfied or unsatisfied. Evidence shows the matched artifact path for satisfied inputs and names the gap for unsatisfied ones. The Project Work lane in the session menu calls the evaluator after workstream binding and displays the same agent evidence, allowing the developer to select an agent.

## Domain Rule

- `intent select` is read-only: it writes nothing to the repository
- `intent select [--workstream ID]` calls the precondition evaluator for all agents
- When a workstream is bound, scope filtering applies; without `--workstream`, it uses the session binding
- stdout lists every agent with its name, description, and each required input as satisfied or unsatisfied with evidence
- Exit code 0 on success, 2 on invalid input
- Agents with all inputs satisfied are visually distinguishable from agents with unsatisfied inputs
- The Project Work lane shows the same evidence after binding to a workstream

## Demo Scenario

1. Run `intent select`. The terminal lists all 17 agents. The `architecture-agent` shows one required input as satisfied: `docs/proposals/activity-graph-orchestration.md` matches its proposal requirement with `status: accepted`. The `developer-agent` shows one unsatisfied input: no story file exists matching `backlog/ST-NNNN.md` with `status: pending`.
2. Agents with all inputs satisfied appear with a distinct marker (e.g., a checkmark prefix). Agents with unsatisfied inputs appear with an unsatisfied marker and the gap named.
3. Run `intent select --workstream activity-graph-orchestration`. Scope filtering narrows proposal candidates to those with scope `activity-graph-orchestration` or `global`.
4. In the Project Work lane, bind to the `activity-graph-orchestration` workstream. The same agent evidence appears. Select `architecture-agent` from the list.
5. Run `intent select` with an invalid `--workstream` value. Exit code is 2.
