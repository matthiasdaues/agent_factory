# Prove background dispatch permission argv

Exercise the actual Claude and Copilot child command construction so the
shipped repository-derived permissions cannot regress into blanket bypass or
bare-interpreter wildcards.

**Priority:** must-have

## Acceptance Criteria

- Tests inspect actual background argv for both supported trigger CLIs.
- Claude argv contains scoped allow and deny lists and excludes
  `--dangerously-skip-permissions` and bare interpreter wildcards.
- Copilot argv contains scoped allow and deny lists and excludes
  `--allow-all-tools` and bare interpreter wildcards.
- Dangerous Git verbs are denied and the repository-evidenced validation,
  formatting, and test commands remain allowed.

## Implementation Notes

This is an evidence-only story. If a test exposes a mismatch, restrict any
runtime edit to `factory/scripts/trigger` and update this story's declared
