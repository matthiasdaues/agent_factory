# init-factory installs the capture hooks

Teach init-factory to install the Claude Code capture triggers the same way
it installs the git-safety guardrail: symlink `capture-usage.sh` into
`.claude/hooks/` and wire `Stop` and `SubagentStop` entries into
`.claude/settings.json` — created if absent, merged if present, never
clobbering hooks the project already owns. The wiring is idempotent and
reversible through `remove-factory` by its `agent_factory` marker.

The runtime area needs no new ignore entry: `.agent-factory/usage/` already
falls under the existing `/.agent-factory/` line in the init-factory ignore
manifest, resolving that open question.

**Priority:** must-have

## Acceptance Criteria

- init-factory symlinks `capture-usage.sh` into `.claude/hooks/` and adds
  `Stop` and `SubagentStop` command entries to `.claude/settings.json`,
  mirroring the guardrail install (created if absent, merged if present).
- Existing unrelated hooks in a project's `.claude/settings.json` are
  preserved; a second run is a no-op.
- The added entries carry the `agent_factory` marker so `remove-factory`
  extricates them without a trace.
- A test asserts `.agent-factory/usage/` is git-ignored via the existing
  `/.agent-factory/` manifest entry, with no new ignore line added.
- A test proves a fresh install adds both `Stop` and `SubagentStop` hooks and
  that re-running leaves settings unchanged.
