# Fix arch-lint for new architecture model

Make the DSL-to-arc42 coupling check pattern-agnostic and scoped correctly to
the current architecture:

- Pattern-agnostic extraction: `dsl_core_components` no longer hardcodes
  `core = container`; falls back to full-DSL scan of `= component "Name"`
  declarations when the parent-container pattern doesn't match.
- §5.2-§5.4 scoping: `ch5_core_components` now scans through §5.4
  (Validator + State Manager + Dispatcher tables), not just §5.2.
- Component name normalization: both extractors strip trailing parenthetical
  suffixes so `run-agent (Pi extension)` and `run-agent` compare as equivalent.
- Fix regex: `\*\*bold** text |` pattern now uses non-greedy capture and
  `.*?\|` to handle bold cells with continuation text before the table pipe.
