# Record open work in the todo lists of the work folder

**Priority:** must-have

## Goal

The coaching agent, `retrospective`, and `create-backlog-make-concrete` add
their todo entries to `docs/spec/work/todo.md` or `docs/spec/work/todos.md`.
The rules and conventions that describe the two lists name the new paths.

## Contract

| Operation                                            | Input state      | Outcome                                                          | Persistence               |
| ---------------------------------------------------- | ---------------- | ---------------------------------------------------------------- | ------------------------- |
| `retrospective` with one action item                 | Migrated project | New entry in `docs/spec/work/todo.md`                            | `docs/spec/work/todo.md`  |
| `create-backlog-make-concrete` with an open question | Migrated project | New `- [ ]` item in `docs/spec/work/todos.md`                    | `docs/spec/work/todos.md` |
| Rules and conventions                                | —                | Name only `docs/spec/work/todo.md` and `docs/spec/work/todos.md` | —                         |

## Demo Scenario

1. In the migrated fixture `todo-project` (Demo Data), the maintainer runs
   `retrospective` with the action item "Pin the Structurizr image".
2. `docs/spec/work/todo.md` gains an entry for "Pin the Structurizr image".
3. `ls docs/spec/todo.md` reports that the file does not exist.

## Demo Data

The skills run in a session, so the demo uses a hand-built fixture.

| -------------- | --------------------------------------------------------------------------------------- |
| `todo-project` | New layout with `docs/spec/work/todo.md` holding `T-0001` and `docs/spec/work/todos.md` |

## Analysis

This story renames todo paths in twelve lines across eight owned files. It adds no behavior and no new test. The path table in the proposal maps `docs/spec/todo.md` to `docs/spec/work/todo.md` and `docs/spec/todos.md` to `docs/spec/work/todos.md`.

Files that change:

- `packages/factory/agents/coaching-agent.md`: the context input and the action-item target.
- `packages/factory/skills/retrospective/SKILL.md`: the filing target.
- `packages/factory/skills/create-backlog-make-concrete/SKILL.md`: the deferred-question target.
- `packages/factory/rulebooks/rules.md`: the MUST line for deferred decisions.
- `packages/factory/rulebooks/conventions/todo-format.md`: the single-file path and the lint command.
- `packages/factory/rulebooks/conventions/cross-reference-format.md`: the code span and the example links.
- `packages/factory/rulebooks/conventions/report-format.md` and `packages/factory/rulebooks/templates/todo-entry.md`: the todo path.

Tests: no `.feature` Scenario names the todo lists. The red step is the grep in Verification, which finds the old paths before the edit. CAL-13-LN-01 (ST-0345) guards these files.

Concern: the Contract row for `create-backlog-make-concrete` names `docs/spec/work/todos.md` with a `- [ ]` item. The skill today sends deferred questions to `todo.md` in the T-NNNN format. This story renames the path and keeps the destination. The destination change needs a decision.
