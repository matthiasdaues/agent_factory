# End-to-end capture demonstrable and scope recorded

Prove the MVP end to end: a Claude Code session, driven through the installed
hook path, appends one well-formed record and a persisted transcript copy.
This story closes the loop by verifying every completion criterion against an
accepted story and by recording what is deliberately deferred, so a later
reader does not mistake an absence for a defect.

**Priority:** must-have

## Acceptance Criteria

- An end-to-end test drives a Claude Code `.jsonl` transcript fixture through
  the installed hook path and asserts a well-formed record line is appended
  to `.agent-factory/usage/<session_id>.jsonl` and that a transcript copy
  exists at the `transcript_ref` path.
- The record validates against the full field set: `normalized_*` present,
  `reported_*` populated from the fixture, `usage_granularity` `full`.
- A capture failure injected into the path leaves the simulated run
  unaffected — the run exits zero and its output is intact.
- A coverage checklist maps every proposal Completion-Criteria item to the
  accepted story that satisfies it, with none unmapped.
- The deferred scope — reader / aggregation / presentation, dollar-cost math,
  the PostgreSQL adapter, budget enforcement, and Pi / orchestrator / Copilot
  capture wiring — is recorded as out of scope, including that Pi
  human-session hook timing is settled in the Pi rollout, not here.
