# Name the architecture agent as owner of every dependency violation

**Priority:** must-have

## Goal

Every violation in the JSON report of `dependency-check` names the architecture agent as its owner. Whoever reads the report knows which agent fixes the rules.

## Contract

| Operation          | Input state          | Outcome                                           | Persistence |
| ------------------ | -------------------- | ------------------------------------------------- | ----------- |
| `dependency-check` | One forbidden import | The violation carries `owner: architecture-agent` | JSON report |
| `dependency-check` | No violation         | Report unchanged in shape; no owner entry         | JSON report |

## Demo Scenario

1. The architect runs `packages/factory/scripts/dependency-check` on the fixture `forbidden-import` (Demo Data).
2. The JSON report lists one violation, `payments → ledger`, with `owner: architecture-agent`.

## Demo Data

| Fixture            | Content                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------ |
| `forbidden-import` | `dependency-rules.dsl` forbids `payments → ledger`; `src/payments/pay.py` imports `ledger` |

The story extends the fixtures of `tests/factory/test_core_layout_gates.py`.
