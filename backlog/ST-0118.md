# dispatch prepare-wave: wave gate, branch and worktree creation, verify-base

Implement `dispatch prepare-wave <N>`. The subcommand verifies all stories in
waves less than N are terminal (mechanical wave gate), then for each story being
prepared: creates a story branch and worktree off the feature branch, verifies
the branch-to-worktree mapping with `git worktree list --porcelain`, runs
`verify-base`, and records `prepared` in the ledger. Parallel-safe stories and
serial-chain heads are prepared from the feature branch tip; chain links stay
`pending`.

**As a** dispatch operator,
**I want** prepare-wave to set up branches and worktrees mechanically,
**so that** each subagent gets an isolated, verified workspace without manual
git operations.

**Priority:** must-have

## Acceptance Criteria

1. `dispatch prepare-wave <N>` exits non-zero when any story in waves less
   than N is non-terminal, reporting the non-terminal stories.
2. Each parallel-safe story gets a story branch from the feature branch tip and
   a dedicated worktree.
3. The branch-to-worktree mapping is verified via `git worktree list --porcelain`
   after creation.
4. `verify-base --expect-base <sha>` runs for each branch and exits non-zero on
   failure.
5. Serial chain heads are prepared (branch, worktree, verified); chain links
   remain pending.
6. Each prepared story is recorded as `prepared` in the ledger.
7. Re-running after success is a no-op (already-prepared stories recognized).
8. Re-running after partial failure resumes from recorded state (prepared
   stories skipped, remaining stories prepared).
