# Reach the user handbook from every factory entry point

A new user who picks H in the session menu is walked through the user handbook's `getting-started/` tutorial, and every other factory entry point names the user handbook instead of the guide.

**Priority:** must-have

## Goal

A new user who picks H in the session menu gets the `newcomer-tour` skill on the `getting-started/` tutorial of the installed user handbook. `guided-tour`, `explain-concept`, VIRGIL, and the inputs of VIRGIL in `INDEX.yaml` name `.agent-factory/factory/docs/handbook/`. `packages/factory/README.md` keeps the install, update, and removal commands and links to the user handbook for every other topic.

## Domain Rule

- The H section of `session-menu.md` routes a new user to `newcomer-tour` with the tutorial page of `getting-started/` (FH-06-01).
- The procedure of `newcomer-tour` reads the tutorial page of `.agent-factory/factory/docs/handbook/getting-started/`, not a section of a longer file.
- `explain-concept` names the user handbook as its first source and reads the one page that answers the question, not the whole handbook.
- The inputs of VIRGIL name `.agent-factory/factory/docs/handbook/index.md`. The input is a file, because `INDEX.yaml` lists files as context inputs.
- A topic of `packages/factory/README.md` other than install, update, and removal moves out as a link to the user handbook page that holds it.

## Demo Scenario

1. The user runs `update-factory` in a project with the previous release and opens a new Claude Code session there.
2. VIRGIL shows the session menu. The user picks H and says they are new.
3. VIRGIL loads `newcomer-tour`. The tour opens `.agent-factory/factory/docs/handbook/getting-started/` and walks the tutorial page from its first checkpoint.
4. The user asks "What is a playbook?". `explain-concept` answers from the page of the user handbook that holds playbooks and names that page.
5. The user opens `.agent-factory/factory/README.md`. It shows the install, update, and removal commands and a link to the user handbook.

## Demo Data

None. The demo needs the user handbook of ST-0453, with its `getting-started/` tutorial and a page on playbooks.

## Boundaries

- The story changes no page of the user handbook. A tutorial step that the tour cannot walk is a finding for ST-0453's page, not an edit here.
- `INDEX.yaml` is regenerated from the agent and skill files in the same commit, and `index-lint --check` passes.
- The newcomer journey keeps its order and its confirmations; only the source of the tour changes. `test_onboarding_journey.py`, `test_value_first_routing.py`, and `test_fitting_text.py` keep their checks.
- No entry point names `factory-guide.md` after this story.
- No edit of the feature files or `docs/spec/scope-map.md`; the requirements agent changed them before planning.
- `quality-gates` is empty, because the story changes Markdown and generated YAML, not production code.
