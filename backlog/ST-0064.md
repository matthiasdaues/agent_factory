# Prove a portable survey run end to end

Exercise one bounded landscape question from a mode-defaulted brief through a
validated cited synthesis, using the same canonical artifacts across every
supported CLI discovery surface.

**Priority:** must-have

## Acceptance Criteria

- The fixture run validates its brief, survey plan, source records, and survey
  report through the declared gates.
- Repeated or related sources remain distinguishable by source family.
- Every finding resolves to at least one source record, and unsupported source
  references fail deterministically.
- The run creates no conjecture, test, review, vote, or claim-register artifact.
- Installed discovery exposes the required survey playbook, skills, and agents
  under Claude Code, Copilot, Codex, and Pi.
- The complete existing falsification research test suite remains green.

## Analysis

Implement one portable, offline end-to-end survey fixture in
`orchestrator/tests/test_research_survey_e2e.py`. The test will drive the
checked-in schema-validation CLI over a mode-defaulted brief, survey plan,
source records, and survey report, then exercise the existing Factory installer
to check Claude Code, Copilot, Codex, and Pi discovery surfaces. It will use
related records with distinct `source_family` values, verify every report
finding resolves to a supplied record, and prove an unsupported reference is a
deterministic validation failure. It will also assert that the fixture output
contains none of the falsification-only artifact families.

The test covers the Survey Mode source-gathering and synthesis flow, the CLI
Portability discovery contract, and the Validation Gate traceability named in
this story. `factory/docs/design/research-survey-mode.md` will gain short
evidence describing that executable fixture and its boundary checks. No
runtime behaviour, schemas, or dispatch contracts are needed: predecessors
already define those public contracts.

The seams are the public `factory/scripts/schema-validate` process boundary and
the installed CLI discovery layout produced by `factory/scripts/init-factory`.
The fixture needs a small local semantic source-reference resolver because the
existing schema deliberately cannot know which independently created source
record files participate in a run.
