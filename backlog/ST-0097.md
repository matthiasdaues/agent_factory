# Create qa-strategy-from-spec skill

Create a skill that produces a per-feature QA strategy document from the
consolidated `.feature` file and supplementary specs. The document tells the
QA agent how to specialise the generic testing strategy for a specific
feature's contracts and risk profile.

**As a** requirements-agent,
**I want** a skill that derives a per-feature QA plan from the `.feature`
file and supplementary specs,
**so that** Phase 5 receives a scoped QA plan rather than re-deriving test
scope from generic convention.

**Priority:** must-have

## Acceptance Criteria

1. `factory/skills/qa-strategy-from-spec/SKILL.md` exists and documents the
   skill's inputs, outputs, and template sections.
2. The skill reads `docs/spec/<feature-name>.feature` (Rule groupings
   provide the actor-goal matrix), `entity-model.md`, and
   `interface-contracts.md` as source inputs.
3. Output file: `docs/spec/<feature-name>-qa-strategy.md`.
4. Output contains all template sections: Feature (with proposal and
   Gherkin traces), Test Layers in Scope, Contract Owners (table),
   Boundary Cases, Defect Severity Triage, Test Retention Policy.
5. Each boundary case maps to a Gherkin scenario or an explicit gap.
6. The document is a per-feature QA plan, not a reformatted
   `testing-strategy.md`.
7. The output passes `factory/scripts/validate`.
