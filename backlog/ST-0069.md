# Prove dispatch base and merge gates on negative paths

Close the verified assurance gaps around exact declared bases and contaminated
diffs without replacing the shipped preflight or pre-merge gates.

**Priority:** must-have

## Acceptance Criteria

- `verify-base --expect-base` rejects anything other than an exact lowercase
  40-character object name before writing a success marker.
- Direct tests prove stale-target and wrong-declared-base failures leave no
  marker that authorizes subsequent work.
- Direct tests prove stale/target-reverting, out-of-scope, and file-count
  blowout diffs block and that only a clean in-scope diff writes the matching
  merge marker.
- Tests use real temporary Git histories and distinguish usage errors from
  blocking findings.

## Implementation Notes

The target-revert case is evidenced through the shipped stale-base signature:
a branch missing target commits necessarily proposes their reversal. No new
diff algorithm is planned unless the regression test exposes a defect.
