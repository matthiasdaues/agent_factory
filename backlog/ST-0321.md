# List every old path the script does not rewrite

**Priority:** must-have

## Goal

The project maintainer reads, at the end of the output of
`migrate-spec-layout`, every old path that occurs outside a Markdown link, with
its file and line. The listed files stay unchanged, including the project's CI
files and its own pre-commit hooks.

## Contract

| Operation                       | Input state                                                                                                               | Outcome                                                                    | Persistence |
| ------------------------------- | ------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------- | ----------- |
| `migrate-spec-layout`           | `.github/workflows/docs.yml` line 12 names `docs/arc42/architecture.dsl`                                                  | One listing line with that file, line 12, and the old path; file unchanged | None        |
| `migrate-spec-layout`           | A project hook in `.pre-commit-config.yaml` (outside `agent_factory_hook-*`) has `files: ^docs/spec/supplementary_specs/` | One listing line for it; hook unchanged                                    | None        |
| `migrate-spec-layout`           | An old path in plain Markdown text or a code span, not in a link                                                          | One listing line; text unchanged                                           | None        |
| `migrate-spec-layout`           | No old path outside links                                                                                                 | No listing section                                                         | None        |
| `migrate-spec-layout --dry-run` | Old-layout project with an old path in a CI file                                                                          | The listing is printed as in a real run (default of question 2)            | None        |

## Demo Scenario

1. The maintainer copies the fixture `old-layout-ci` (Demo Data) into
   `/tmp/demo` and runs `packages/factory/scripts/migrate-spec-layout /tmp/demo`.
2. The end of the output holds the line for `.github/workflows/docs.yml`, line
   12, and `docs/arc42/architecture.dsl`, and the line for the project hook
   `payments-spec-check` in `.pre-commit-config.yaml`.
3. `git -C /tmp/demo diff .github/` prints nothing.
4. `.pre-commit-config.yaml` still has `files: ^docs/spec/supplementary_specs/`
   for `payments-spec-check`.

## Demo Data

## Boundaries

- The script never rewrites an old path outside a Markdown link. The factory
  hook block (ST-0322) and the DSL `theme` line (ST-0318) are the only
  exceptions.
- The project's own hooks are project files. The script lists them and never
  changes them.
- The listing goes to one stream with one line format, recorded in
  `interface-contracts.md`.
- Binary files are not scanned.

## Affected Paths

- `packages/factory/scripts/migrate-spec-layout` — existing; adds the scan of
  non-Markdown files and of Markdown text outside links, and the listing.
- `tests/factory/test_migrate_spec_layout.py` — existing; adds the listing
  cases.
- `docs/spec/supplementary_specs/interface-contracts.md` — existing; records the
  line format, the stream, the scanned non-Markdown files, and the dry-run
  behaviour of the listing.

## Out of Scope

- Rewriting any listed occurrence.
- The factory hook block (ST-0322).
- The listing of duplicate glossary terms (ST-0324).

## Agent Stop Conditions

- An old path occurs inside the factory hook block of the fixture. That block
  belongs to ST-0322; report if the listing would name it.
- The no-work rule of ST-0318 would print a listing on a new-layout project
  because a file still names an old path. Report the case: the contract says a
  new-layout project prints nothing.

## Resolve Before Implementation

1. CAL-G05, line format and stream. Default: standard output, one line per
   occurrence in the form `old path: <file>:<line>: <old path>`, under a heading
   line `Old paths the script did not rewrite:`.
2. CAL-G12, dry-run listing. Default: `--dry-run` prints the listing too,
   because the listing changes no file.
3. CAL-G11, non-Markdown scan set. Default: every text file git tracks or that
   is untracked and not ignored, outside `.git/` and `.agent-factory/`.
4. Old paths in the listing on a new-layout project: the no-work rule says the
   script prints nothing. Default: the listing runs only when the run has work,
   so a migrated project stays silent.
