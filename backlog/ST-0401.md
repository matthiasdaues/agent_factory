# Refuse the same call in Codex and Copilot CLI, patches included

**Priority:** must-have

## Goal

An agent in Codex or Copilot CLI is refused when its edit, write, patch, or shell call sets a human field. The guard reads the paths from the text of an `apply_patch` call and refuses a patch it cannot parse whose raw text names a guarded path. `init-factory` registers the guard in both CLIs.

## Contract

| CLI and call                                                                                                            | Result   |
| ----------------------------------------------------------------------------------------------------------------------- | -------- |
| Codex `apply_patch` whose patch for `docs/findings/BUG-0037.md` adds `stop_confirmed_by: human`                         | exit `2` |
| Codex `apply_patch` that changes only body text of a finding file                                                       | exit `0` |
| Copilot CLI `edit` or `write_file` that sets `status: waived` in a finding file                                         | exit `2` |
| `apply_patch` of Codex, Copilot CLI, or Pi that the guard cannot parse and whose text names `docs/findings/BUG-0037.md` | exit `2` |
| Unparsable `apply_patch` that names no guarded path                                                                     | exit `0` |

`init-factory` writes `PreToolUse` entries for `Edit`, `Write`, `apply_patch`, and `Bash` in `.codex/hooks.json`, and a hook file under `.github/hooks/` with `preToolUse` entries for `edit`, `apply_patch`, `write_file`, `create`, and `bash`, beside the `step-guard` entries.

## Demo Scenario

1. The User runs `init-factory --cli codex copilot` on `/tmp/guard-demo` of ST-0400. `.codex/hooks.json` and `.github/hooks/` hold the guard entries.
2. In Codex, the User asks the agent to confirm the stop of BUG-0037. Its `apply_patch` is refused.
3. In Copilot CLI, the User asks the agent to waive FAGAN-0042. Its `edit` is refused.
