# Create newcomer-tour skill

Create `factory/skills/newcomer-tour/SKILL.md` — the skill VIRGIL loads for
option A (newcomer walkthrough). The skill reads the Getting Started section
of `factory/docs/factory-guide.md` and walks the user through it
conversationally.

**Priority:** must-have

## Acceptance Criteria

- `factory/skills/newcomer-tour/SKILL.md` exists with valid skill frontmatter.
- The skill instructs the agent to read the Getting Started section of
  `factory/docs/factory-guide.md` and walk the user through it one subsection
  at a time, pausing for questions after each subsection.
- Before starting, the skill checks for signs of prior work (a completed
  poc-spike, a charter, prior playbook outputs) and offers to skip ahead or
  start fresh if found.
- At the end, the skill offers to run `poc-spike`.
- The skill does not reference `docs/arc42/beginner-intro.md`.

## Literary Frame

**Mr. Tumnus** (Lewis, *The Lion, the Witch and the Wardrobe*) — the
friendly local who walks you through an unfamiliar world without making
you feel stupid. The newcomer-tour should welcome, not lecture. The user
just stepped through the wardrobe; show them Narnia, don't hand them a
textbook about it.
