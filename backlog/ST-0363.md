# Report each drift as a row for the artifact's owner

**Priority:** must-have

## Goal

The reconciliation agent writes one report per run, with one row per drift that names the artifact's owner. It changes no other file. With its wide patterns gone, every core list entry has one producer, and the expected-failure list is empty.

## Contract

| Operation               | Input state                                             | Outcome                                                              | Persistence                             |
| ----------------------- | ------------------------------------------------------- | -------------------------------------------------------------------- | --------------------------------------- |
| Read the declarations   | After this story                                        | Only output `docs/reviews/reconciliation-*.md`; no `capture-context` | —                                       |
| Reconciliation run      | Code says `WAITING`, `state-machines.md` says `PENDING` | Row with `owner: domain-modeling-agent`, status `open`               | `docs/reviews/reconciliation-<date>.md` |
| Reconciliation run      | Stale ADR; stale `agent-context.md`                     | Rows for the architecture agent and Virgil                           | The report                              |
| Reconciliation run      | Any drift                                               | No file outside the report changes                                   | None                                    |
| Next reconciliation run | Row `fixed` from the previous report                    | The row is checked again                                             | The new report                          |

## Demo Scenario

1. The operator runs the reconciliation agent on the fixture `renamed-status` (Demo Data).
2. `docs/reviews/reconciliation-2026-11-10.md` holds a row for `docs/spec/state-machines.md` with `owner: domain-modeling-agent` and status `open`. `state-machines.md` is unchanged.
3. Demo exception: the stakeholder accepted the contract test as this step's interface (2026-11-04). The operator runs `pre-commit run run-tests --all-files` (the `run-tests` hook or `validate`, never `pytest` directly, BR-024). It passes, and the expected-failure list is empty.
