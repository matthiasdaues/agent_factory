# Seven-part subagent handoff contract generation

Extend `prepare-wave` and `prepare-story` to generate the seven-part subagent
prompt. The contract contains: (1) Outcome -- story ID, title, path to
acceptance criteria, (2) Workspace -- worktree path, story branch,
(3) Allowed writes -- story output globs verbatim, (4) Forbidden actions --
merge, push, branch creation, ledger writes, hook bypass, (5) Required checks
-- test_command from config/project.json, (6) Stop conditions -- ambiguous
criterion, missing input, out-of-scope write needed, suspect test, (7) Return
envelope -- status, commit_sha, files_changed, checks, blockers, failure_class.
Remove three legacy clauses. Enforce 800 normalized token budget.

**As a** dispatch operator,
**I want** a machine-generated handoff contract that is complete, concise, and
budget-capped,
**so that** subagents receive everything they need and nothing they do not,
replacing hand-written prompts that drift and bloat.

**Priority:** must-have

## Acceptance Criteria

1. The generated contract contains all seven parts with the specified content.
2. Acceptance criteria are referenced by file path (Part 1), not inlined.
3. The generated contract does not contain a verify-base preamble, a sub-agent
   addressing clause, or a workflow restatement (legacy clauses removed).
4. The generated contract measures at most 800 normalized tokens (3200 bytes).
5. Direct and seams-first strategies both produce valid seven-part contracts.
