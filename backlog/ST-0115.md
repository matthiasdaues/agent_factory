# dispatch plan: wave planning with dependency graph and file-overlap detection

Implement `dispatch plan --backlog-dir backlog [--stories ST-NNNN,...]`. The
subcommand reads story files, builds the dependency graph, computes file-overlap
sets by expanding output globs against the working tree, and outputs a wave plan
as YAML. It assigns stories to waves, identifies parallel-safe sets and serial
chains within each wave, and reports a model tier per story. No state changes.

**As a** dispatch operator,
**I want** a computed wave plan from my backlog stories,
**so that** I know which stories can run in parallel, which must be serialized,
and in what wave order.

**Priority:** must-have

## Acceptance Criteria

1. Stories with no dependencies or file overlaps are assigned to wave 1 and
   marked parallel-safe.
2. A dependency chain produces sequential waves (dependent story in a later
   wave than its dependency).
3. File-overlapping stories within the same wave are placed in a serial chain.
4. File overlap is computed by expanding output globs against the working tree.
   Disjoint expansions are parallel-safe.
5. A glob matching zero files falls back to its directory prefix for
   conservative serialization.
6. The plan output includes serial chains and parallel sets per wave.
7. Each story carries its declared tier in the plan output.
8. The plan is output as YAML to stdout.
