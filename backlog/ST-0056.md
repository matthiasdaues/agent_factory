# Adapt the shared git guardrail to Codex hooks

Prove the existing policy parser consumes Codex `PreToolUse` shell payloads and
denies dangerous commands without weakening Claude or Copilot behavior.

**Priority:** must-have

## Acceptance Criteria

- The shared hook extracts shell commands from current Codex `PreToolUse`
  payloads in addition to Claude and Copilot payloads.
- Synthetic payload tests cover allow and deny paths for all three CLIs.
- Codex denial uses a supported non-zero hook outcome and a useful stderr
  reason; CLI-specific JSON output remains harmless to other consumers.
- Existing verify-base, premerge, and dangerous-command protections remain
  green.
