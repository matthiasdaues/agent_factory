# Create crap-score gate skill, script, and fixture

Create the CRAP scoring gate: a skill document, a CLI wrapper script, and
a test fixture. CRAP combines cyclomatic complexity with test coverage into
a single risk metric: `CRAP(m) = comp(m)^2 * (1 - cov(m)/100)^3 + comp(m)`.
The gate blocks when any function exceeds the threshold.

**As a** implementation-agent dispatcher,
**I want** a deterministic CRAP score gate that runs on committed artifacts,
**so that** structurally risky code is caught before merge without relying
on agent self-report.

**Priority:** must-have

## Acceptance Criteria

01. `factory/skills/crap-score/SKILL.md` exists and documents the CRAP
    scoring gate, its formula, inputs, outputs, and threshold semantics.
02. `factory/scripts/crap-score` is an executable script that computes CRAP
    per function for the given source files.
03. The script produces a JSON report per function: function name, file,
    cyclomatic complexity, coverage percentage, CRAP score, pass/fail.
04. Reports are logged to `.agent-factory/crap-score/<story-id>.json`.
05. Default threshold: CRAP \<= 30 per function (industry standard).
06. The script reads threshold overrides from `docs/charter/house-rules.md`
    when present.
07. The script exits non-zero when any function exceeds the threshold.
08. Tool candidates: `radon` + `coverage` (Python).
09. `factory/fixtures/quality-gates/high-crap/` contains a self-contained
    test project with: one function with cyclomatic complexity >= 10 and 0%
    coverage (CRAP > 100, expected FAIL), and one function with complexity 2
    and full coverage (CRAP < 6, expected PASS).
10. The script runs against the fixture and produces the expected results.
11. All outputs pass `factory/scripts/validate`.
