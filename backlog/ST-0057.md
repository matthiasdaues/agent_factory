# Install Codex skills agents aliases and hooks

Extend `init-factory` with a dedicated Codex adapter instead of treating Codex
as another shared dot-directory layout.

**Priority:** must-have

## Acceptance Criteria

- Each Factory skill is symlinked individually under `.agents/skills`.
- Every Factory agent is generated under `.codex/agents`; INDEX, playbooks,
  rulebooks, and scripts are linked under `.codex`.
- `.codex/hooks.json` merge-installs `PreToolUse`/`^Bash$`, `Stop`, and
  `SubagentStop` entries using Git-root-resolved commands.
- Re-runs are idempotent and refresh Factory-owned generated agents.
- Project-owned `.agents`, `.codex`, hooks, skills, agents, and root `AGENTS.md`
  are preserved; collisions stop without overwriting.
- Orientation documents Codex's local skill and agent paths and full 40-character
  SHA rule.
- Installation reports skipped project orientation and `/hooks` trust actions.
