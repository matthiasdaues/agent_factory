# Implement run-tests framework detection and core execution

Implement the `factory/scripts/run-tests` script with auto-detection of test
frameworks from project structure markers and execution of the appropriate test
command. This is the foundational component that all three hook integration
points (pre-commit, pre-push, phase advance) will invoke.

The script must detect exactly one test framework (pytest, jest, go test, cargo
test) from project markers (`pyproject.toml`, `package.json`, `go.mod`,
`Cargo.toml`) and fail loudly if multiple frameworks are detected (BR-023,
ATAM-0002). This prevents silent partial test coverage in monorepos.

**Priority:** must-have

## Acceptance Criteria

- `factory/scripts/run-tests` executable script created with Python 3.8+
  stdlib-only implementation (no third-party dependencies, matching ADR-0006).
- Framework detection scans for all framework markers: `pyproject.toml` with
  pytest, `package.json`, `go.mod`, `Cargo.toml`.
- If zero frameworks detected: exit `2` with error message listing all checked
  markers.
- If multiple frameworks detected: exit `2` with error message listing all
  found markers (ATAM-0002 fix — fail loudly, never silently skip).
- If exactly one framework detected: construct and execute the appropriate test
  command (`uv run pytest`, `npm test`, `go test ./...`, `cargo test`).
- `--full` mode implemented: runs complete test suite with no filtering
  (BR-026).
- JSON summary emitted on stdout after execution: `{"passed": int, "failed": int, "skipped": int, "duration_ms": int}` (BR-027).
- All test progress, failure details, and error messages go to stderr only —
  stdout reserved for JSON output (BR-027).
- Exit codes: `0` (all tests passed), `1` (one or more tests failed), `2`
  (framework detection error or configuration error).
- Script includes usage help (`--help` flag).

## Implementation Notes

**Framework detection logic (BR-023, ATAM-0002):**

1. Scan for all four framework markers
2. Count how many were found
3. If count == 0: error "No test framework detected"
4. If count > 1: error "Multiple frameworks detected: [list]" (fail-loud)
5. If count == 1: proceed with that framework

**Test command construction:**

- pytest: `uv run pytest --tb=short --quiet`
- jest: `npm test`
- go: `go test ./... -v`
- cargo: `cargo test`

**JSON output parsing:**

- pytest: parse from `pytest --json-report` or count from stderr output
- jest: parse JSON from jest's `--json` flag
- go: parse from `go test -json`
- cargo: parse from stderr output format
