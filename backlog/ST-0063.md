# Make research dispatch CLI-neutral

Define research dispatch in Factory terms and map it to each supported CLI
without weakening falsification independence or assuming Claude-specific model
names and tools.

**Priority:** must-have

## Acceptance Criteria

- Every research assignment declares `agent`, Factory `tier`, `task`, unique
  output path, and whether it requires an independent session.
- Research preflight blocks when source access is unavailable.
- Falsification mode blocks when independent agent identities cannot be
  established.
- Survey source gathering may fall back from a wave to sequential execution.
- Claude Code, Copilot, Codex, and Pi invocation mechanisms are documented and
  covered by installed-surface tests.
- Canonical research workflow artifacts contain no vendor model names or
  unqualified assumptions about a native Agent tool.

## Implementation Notes

Pi maps separate sessions to `run_agent` and file-disjoint waves to
`dispatch_wave`; Codex maps them to generated native agents and parallel
threads. Claude Code and Copilot use their native agent mechanisms.
