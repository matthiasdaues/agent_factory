# Restructure session menu to four lanes with Help, Housekeeping, Project Work, and Open Stage

The session menu presents four clear lanes instead of five lettered options.

**Priority:** must-have

## Goal

The session menu at `packages/factory/config/session-menu.md` presents four lanes: H (Help), K (Housekeeping), P (Project Work), and O (Open Stage). Help routes to tour skills. Housekeeping shows a stub that EPIC 4 fills later. Project Work handles workstream creation and continuation. Open Stage routes to VIRGIL for freeform conversation with no workstream binding. The explain-concept skill remains available at any point.

## Domain Rule

- The menu offers exactly four lanes: H, K, P, O.
- H routes to the newcomer-tour or guided-tour skill.
- K routes to the Housekeeping lane (stub until EPIC 4 fills it).
- P routes to the Project Work lane (workstream creation and continuation).
- O routes to VIRGIL for freeform conversation with no structure and no workstream binding.
- Concept explanation via the explain-concept skill is available at any point in any lane.
- VIRGIL routes to the appropriate skill or agent when the conversation reaches a concrete next step.

## Demo Scenario

1. Start a factory session with no fitting pending. The session menu displays four lanes: H (Help), K (Housekeeping), P (Project Work), O (Open Stage). The prompt says "At any point, ask 'what is [concept]?' for a plain-language explanation."
2. Select H. The session routes to the newcomer-tour skill. The tour begins.
3. Return to the menu. Select K. The Housekeeping lane opens with a stub message: "Housekeeping actions are coming soon. Return to the menu to continue."
4. Return to the menu. Select O. VIRGIL enters freeform conversation. No workstream binding is created. Ask "what is a workstream?" — the explain-concept skill looks up the concept and explains it.
5. Return to the menu. Select P. The Project Work lane opens (workstream creation and continuation are wired by ST-0270).
