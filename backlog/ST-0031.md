# Claim-formulation and refutation-design skills

Author the two claim-forming skills as `SKILL.md` capability definitions.

Claim-formulation turns recorded evidence into one precise and testable claim,
producing a conjecture against its template and schema. Refutation-design
defines the evidence or observations that would count against a claim and the
tests that would expose it, producing planned tests and test records. Both
skills reinforce that a claim which cannot state what would count against it is
not ready for review.

**Priority:** must-have

## Acceptance Criteria

- `claim-formulation/SKILL.md` describes producing one precise, testable claim
  with scope, assumptions, and a content hash from recorded evidence.
- `refutation-design/SKILL.md` describes defining refuting evidence and severe
  tests, and states that a claim with no refutation condition is not ready for
  review.
- Each skill states that it provides a capability and does not control
  sequence.
- Each skill carries the frontmatter `index-lint` requires (including a
  `category`) so it is discovered and grouped.
