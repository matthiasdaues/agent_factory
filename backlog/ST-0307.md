# Fix the small install, commit, and merge-config faults

**Priority:** must-have

## Goal

Fix the findings of cluster `small-scripts` in the [bug-hunt fix run](../docs/reviews/bug-hunt-2026-10-15-fix-run.md).

## Findings

- [BUG-0079](../docs/findings/register/runtime/BUG-0079.json): Smaller install and removal faults
- [BUG-0080](../docs/findings/BUG-0080.md): `commit-safe` commits unrelated changes
- [BUG-0081](../docs/findings/BUG-0081.md): `merge-precommit-config` adds duplicate hooks

Of BUG-0079, this story fixes the items outside `remove-factory`. Story ST-0301 also changes `init-factory`, in another function; this story starts after ST-0301 has merged.

The stakeholder added one onboarding finding on 2026-10-15, filed as
BUG-0091: `spec-lint` reads `docs/spec/work/todos.md`, but `todo-format.md`
requires `docs/spec/work/todo.md`, so the todo check never inspects an entry.
Make `spec-lint` read `todo.md`.

The review of ST-0305 found a gap in `init-factory`, approved for this story
on 2026-10-15: `init-factory` creates `.claude/hooks/` with a bare `mkdir`
and never records it in the manifest's `remove_paths`. Since ST-0305,
`remove-factory` prunes `.claude/hooks/` only when `remove_paths` lists it,
so a project that already had `.claude/` keeps an empty `hooks/` after
removal. Record `.claude/hooks` in `remove_paths` when the install creates
it, the way `_ensure_project_directory` handles `.codex`. Add an end-to-end
test: init into a project with an existing `.claude/CLAUDE.md`, then
remove, and no `.claude/hooks/` is left.

## Acceptance criteria

- Each finding above has a regression test that fails on the code before
  this story and passes after it.
- New tests go into `tests/factory/test_small_scripts.py`, unless a test file
  for the changed script already exists.
- The full suite passes with `pre-commit run run-tests --all-files`.
- Each finding has its own commit, `fix: <what changed> (BUG-NNNN)`.
- No file outside the list below changes, except tests and the
  documentation of a changed script. Nothing under `.agent-factory/`
  changes.
- The final report names each fix in one or two sentences, the test that
  proves it, and any finding that turned out wrong or needs a decision.
