# Implement script_exit_zero condition evaluation in phase script

Extend `factory/scripts/phase` (the phase advance mechanism) to evaluate
`script_exit_zero` entry conditions by executing the specified script and
checking its exit code (SF-02, T-03). This enables FSM gates like "tests must
pass before advancing to next phase" via `script_exit_zero: factory/scripts/run-tests --full`.

The `script_exit_zero` condition type already exists in the spec
(supplementary_specs/validation-rules.md § SF-02) but is not yet implemented.
This story completes its implementation.

**Priority:** must-have

## Acceptance Criteria

- `factory/scripts/phase` (or its entry condition evaluator) recognizes
  `script_exit_zero` condition type.
- When evaluating `script_exit_zero: <script-path> [args]`:
  1. Executes the script with the provided arguments
  2. Captures exit code
  3. If exit code is `0`: condition is **met** (true)
  4. If exit code is non-zero: condition is **unmet** (false)
- Stderr and stdout from the script are captured and included in the phase
  advance report when the condition is unmet (so the operator sees why tests
  failed).
- If the script is not found or not executable: treat as unmet, report error.
- Phase advance logic updated: if any entry condition is unmet, refuse to
  advance, report which conditions are unmet and their output.

## Implementation Notes

**Existing entry condition types:**

`factory/scripts/phase` already evaluates:

- `file_exists: <path>` (SF-02)
- `files_exist: [<path1>, <path2>]` (SF-02)
- `no_open_findings: <catalog-query>` (SF-02)

Add `script_exit_zero` to the same evaluation dispatch.

**Condition evaluation pseudo-code:**

```python
def evaluate_script_exit_zero(script_with_args: str) -> Tuple[bool, str]:
    """Evaluate script_exit_zero condition.

    Returns:
        (True, "") if script exits 0
        (False, captured_stderr) if script exits non-zero or not found
    """
    parts = shlex.split(script_with_args)
    script_path, args = parts[0], parts[1:]

    if not os.path.isfile(script_path):
        return False, f"Script not found: {script_path}"

    try:
        result = subprocess.run(
            [script_path] + args,
            capture_output=True,
            text=True,
            timeout=300,  # 5 minute timeout for test suites
        )
        if result.returncode == 0:
            return True, ""
        else:
            return False, result.stderr
    except subprocess.TimeoutExpired:
        return False, "Script timed out (5 minute limit)"
    except Exception as e:
        return False, f"Script execution error: {e}"
```

**Phase advance report format:**

When `script_exit_zero` is unmet:

```
Entry conditions unmet:
  ❌ script_exit_zero: factory/scripts/run-tests --full
     Exit code: 1
     Output:
     [captured stderr from run-tests]
```

**Integration with run-tests:**

When FSM specifies:

```yaml
entry_conditions:
  tests_pass:
    script_exit_zero: factory/scripts/run-tests --full
```

Phase advance will:

1. Execute `factory/scripts/run-tests --full`
2. If exit `0`: condition met, advance allowed
3. If exit `1` or `2`: condition unmet, advance blocked, show test failures
   from stderr
