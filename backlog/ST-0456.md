# Get from git clone to a passing test run with the contributor handbook

A contributor follows the root `README.md` to the contributor handbook's tutorial and gets from `git clone` to a passing test run, and agents find the contributor pages through the agent context.

**Priority:** must-have

## Goal

A contributor follows the "Contributing" link of the root `README.md` to the `getting-started/` tutorial of `docs/handbook/` and reaches a passing test run with commands that exist in this repository. The `contributing/` chapter describes the page format, the stub rule, `handbook-index`, and `handbook-lint`. `docs/agent-context.md` routes the concerns "write a skill or agent", "add a gate", and "release" to contributor handbook pages.

## Domain Rule

- `docs/handbook/` holds an `index.md` and nine chapter folders: `getting-started/`, `architecture/`, `agents-and-skills/`, `gates-and-hooks/`, `cli-integrations/`, `testing/`, `workflow/`, `release/`, and `contributing/` (acceptance criterion 03).
- `getting-started/` and `contributing/` are written in full (DEC-08). Each other chapter holds its `index.md` and at least one stub with one sentence of scope and a link to a source.
- The tutorial names only scripts and paths that exist. It covers clone, `./init-factory .`, editing `packages/`, refreshing the installed copy, running the tests, and making a change, as the chapter brief of the proposal lists.
- The tutorial states that source edits go to `packages/factory/` and never to `.agent-factory/factory/`, as a `> Rule summary:` callout with a `> Source:` line, because that rule lives in `rules.md` (BR-149).
- The three concerns of `docs/agent-context.md` are new `###` sections under "Technical concerns". Each holds a one-line description and a `Read:` line to the `index.md` of its chapter: `agents-and-skills/`, `gates-and-hooks/`, and `release/`.

## Demo Scenario

1. The contributor runs `git clone <repository> agent_factory` and opens `README.md`. The section "Contributing" links to `docs/handbook/getting-started/`.
2. The contributor follows the tutorial page step by step: `cd agent_factory`, `./init-factory .`, an edit under `packages/factory/`, the refresh of the installed copy, and the test command.
3. The test run passes. The tutorial's last checkpoint names that result.
4. The contributor opens `docs/handbook/index.md` and sees the nine chapters. `release/` is listed although it holds only a stub.
5. The contributor opens `docs/handbook/contributing/index.md` and finds pages on the page format, the stub rule, and both scripts.
6. An agent reads `docs/agent-context.md`, finds the concern "Add a gate", and follows its `Read:` line to `docs/handbook/gates-and-hooks/index.md`.
