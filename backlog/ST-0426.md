# Clean up old runs with dispatch close --orphans

**Priority:** must-have

## Goal

`dispatch close --orphans` removes each worktree that no ledger owns and whose branch is merged into `dev`, and each ledger without a branch whose stories are all `done`. It lists everything else for the User. In this repository it leaves only the `core-artifact-layout` ledger.

## Domain Rule

- It lists the worktrees and branches that belong to no ledger, removes each such worktree whose branch is merged into `dev`, and lists every other one (BR-120).
- It finds each ledger whose feature branch is gone, also inside a worktree. It removes a ledger whose stories are all `done` and lists every other one.
- It does not read `mode`, so it handles an old ledger with `mode: automated` like any other.

## Outputs

- The flag `--orphans` of `close`.
- One run of `dispatch close --orphans` in this repository's primary checkout, with its output in the story's evidence.

## Demo Scenario

1. In this repository, the User runs `dispatch close --orphans` in the primary checkout.
2. The ledgers of `brownfield-onboarding` and `bug-hunt-fixes` are gone.
3. The output lists the `core-artifact-layout` ledger with ST-0344 `blocked`, and lists each worktree whose branch is not merged, such as those of `data-model-dsl-poc`.

## Demo Data

None. The tests build their own ledgers and worktrees; the one-time run reads this repository's real ones.

## Boundaries

- `--orphans` never removes a ledger that holds a story that is not `done`, and never removes a worktree whose branch is not merged.
- Only the one-time run reads this repository's ledgers; no retained test does.
- Source edits go to `packages/factory/`, never to `.agent-factory/factory/`.
- No edit of the specification, the architecture, the QA strategy, or `docs/testing.yaml`. A needed change there becomes a row of `docs/spec/work/spec-feedback-<id>.md`.
- Each pytest test carries `@pytest.mark.spec("<Test ID>")` with the Test ID of its QA strategy row. Every git test builds its own repository in `tmp_path`.
- `quality-gates` is empty, because `docs/testing.yaml` disables both test guardrails.
