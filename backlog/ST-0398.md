# Loop a blocking finding back and leave its confirmation or waiver to the stakeholder

**Priority:** must-have

## Goal

The orchestrator loops each open blocking finding back to its owner until none is open, and a waived finding drops out of the loop. When `dispatch` or `premerge-check` prints a stop notice, the orchestrator explains each stopping finding in an interactive session, and a headless run ends with the notice in its final summary. `finding-format.md` tells the stakeholder how to confirm a stop or waive a finding.

## Domain Rule

- The loop greps match the frontmatter line only, `^status: open`, so a waived finding whose body quotes "status: open" is not listed (FC-QG17).
- A confirmed `critical` finding loops back like a `major` one and keeps severity `critical`.
- The orchestrator explains each stopping finding with `explain-review-finding`, which leads with cause and effect. A headless run does not wait.
- The stakeholder runs each check under `## Possible damage`, then writes `stop_confirmed_by` and `stop_confirmed_reason`, saying what was checked and found.
- The stakeholder writes the human fields in an editor or with a `!` command, which runs outside the tool hooks.
- A waiver sets `status: waived` with `override_by` and `override_reason`.

## Outputs

- Every playbook with a review loop uses the anchored grep and, after `dispatch` or `premerge-check` exits `1` with a stop notice, tells the orchestrator to explain and stop, or to end a headless run with the notice.
- `explain-review-finding` and `run-step` name the stop notice as an input.
- `finding-format.md` holds the confirmation step, the loop of a confirmed `critical` finding, the waiver, and where the human writes the fields.

## Demo Scenario

1. The User places `docs/findings/FAGAN-0042.md` (`major`, `open`) and `docs/findings/FAGAN-0043.md` (`major`, `waived`, whose body quotes "status: open") in a fixture.
2. The User runs the review-loop grep of `feature-addition.md` on the fixture. It lists FAGAN-0042 only.
3. In a session on `/tmp/stop-demo` of ST-0397, `dispatch prepare-wave 1` exits `1`. The orchestrator explains BUG-0037 with `explain-review-finding` and waits.
4. The User opens `finding-format.md` and follows the confirmation step: run the merges check, then write both fields in an editor.
