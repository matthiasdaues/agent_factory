# Phase 1 end-to-end smoke test: two-story two-wave dispatch

Create an end-to-end smoke test that exercises the golden path through the
entire Phase 1 dispatch lifecycle with the real `dispatch` script, real git
operations, and a real test suite runner. The test creates a temporary
repository with two stories (wave 1 and wave 2, where wave 2 depends on
wave 1), runs every dispatch subcommand in sequence, simulates subagent work
by committing changes, and asserts that both stories reach `done` with a clean
ledger and no stale worktrees or branches.

**As a** dispatch user,
**I want** proof that the entire dispatch lifecycle works end to end,
**so that** I can trust the system before using it for real dispatches.

**Priority:** should-have

## Acceptance Criteria

1. The test creates a tmp repo with two stories, ST-001 (wave 1) and ST-002
   (wave 2, depends on ST-001), and a passing `test_command`.
2. The full subcommand sequence runs: `init`, `plan`, `prepare-wave 1`,
   `mark-dispatching`, simulate work, `mark-dispatched`, `verify-story`,
   `merge-story`, `close-wave 1`, `prepare-wave 2` (cuts from ST-001's merge),
   and the same for ST-002.
3. At completion: both stories are `done`, the ledger is clean, no stale
   worktrees remain, and no stale story branches remain.
4. The test runs in under 60 seconds.
