# Confirm proposed definitions one domain area at a time

**Priority:** must-have

## Goal

The stakeholder confirms or rejects each proposed definition of one domain area in a session with the domain-modeling agent. Only confirmed terms reach the glossary. A rejected term stays in the work file with the stakeholder's note.

## Contract

| Operation                         | Input state                                          | Outcome                                                                                                                                                      | Persistence                               |
| --------------------------------- | ---------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ | ----------------------------------------- |
| Domain-modeling agent run         | Row `candidate`                                      | Proposed definition written; status `proposed`                                                                                                               | Work file                                 |
| Pause point, stakeholder present  | `proposed` rows of area `payments`                   | Asks for the rows of `payments` only                                                                                                                         | None                                      |
| Stakeholder confirms              | Row `proposed`                                       | Term moves into the Term/Definition/Avoid table                                                                                                              | Glossary row added; work-file row removed |
| Stakeholder rejects               | Row `proposed`                                       | Status `rejected`; Note holds the reason                                                                                                                     | Work file                                 |
| New definition for a rejected row | Row `rejected`                                       | Status `proposed`; the Note stays (CAO-G09)                                                                                                                  | Work file                                 |
| Agent run                         | Row `confirmed` from another session                 | Moves into the glossary without a question                                                                                                                   | Glossary row added; work-file row removed |
| Unattended run                    | Rows `proposed`                                      | Nothing moves                                                                                                                                                | Work file unchanged except new proposals  |
| Agent run                         | Terms the layout migration moved into the glossary   | Counted as confirmed; no question                                                                                                                            | None                                      |
| Workflow step 2                   | `domain-modeling-agent.md` invokes `domain-modeling` | Passes `--write-glossary`, so a settled term goes into the glossary, not `term-candidates.md` (ST-0350 row 1; name confirmed by the stakeholder, 2026-11-04) | None                                      |

## Demo Scenario

1. The work file holds `PaymentBatch` (`candidate`) and `LedgerLine` (`candidate`) in the area `payments` (Demo Data). The operator runs the domain-modeling agent with the stakeholder present.
2. Both rows get a proposed definition and status `proposed`. The agent asks the stakeholder to confirm the terms of `payments`.
3. The stakeholder confirms `PaymentBatch` and rejects `LedgerLine` with the note "means the bank statement line".
4. `docs/spec/glossary.md` holds `PaymentBatch`. The work file holds `LedgerLine` with status `rejected` and the note (CAO-05-AC-01).
