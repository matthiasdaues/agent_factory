# Update composition rules and quality gates in create-backlog parent skill

Revise the composition rules and quality gates in the create-backlog parent skill to match the new 13-section story template. Rule 1 becomes "Goal First, then Demo." Rule 2 output shape changes. A new Rule 4 (Constraints Are Boundaries) is added. The quality gate gains eight concrete agent-answerability checks and a third gate for International Readability.

**Priority:** must-have

## Demo

1. Open `packages/factory/skills/create-backlog/SKILL.md`.
2. Rule 1 reads "Goal First, then Demo" and instructs writing the Goal statement before the Demo Scenario. The recut trigger reads: "If you cannot write the Goal, the story is not deliverable."
3. Rule 2 (Forward from Status Quo) states that Status Quo content feeds Inputs and Affected Paths instead of a three-part Scope block.
4. Rule 4 (Constraints Are Boundaries) states: every must-not from ADRs, conventions, testing regime, and scope exclusions goes in Constraints.
5. The quality gate section contains an 8-row table mapping each agent-answerability question to a story section (Goal, Affected Paths, Domain Rule, Inputs, Acceptance Criteria, Verification, Out of Scope, Agent Stop Conditions).
6. The quality gate section includes an International Readability gate with six concrete checks (no idioms, no ambiguous pronouns, short sentences, active voice, consistent domain terms, abbreviations spelled out).

## Acceptance Criteria

- Rule 1 heading and body read "Goal First, then Demo" with the Goal statement written before the Demo Scenario (agent-ready-story-format.md § Story composition rules update).
- Rule 2 references Inputs and Affected Paths as output targets instead of a three-part Scope block.
- Rule 3 (Criteria Are Invariants) remains unchanged.
- Rule 4 (Constraints Are Boundaries) exists and states that every must-not goes in Constraints.
- The quality gate section contains the 8-question agent-answerability table (agent-ready-story-format.md § Quality gate changes).
- The International Readability gate lists six concrete sentence-level checks.
- The Done Check list at the bottom remains valid and references the new section names where applicable.

## Scope

**Status quo:** `packages/factory/skills/create-backlog/SKILL.md` defines three composition rules: Rule 1 (Demo First), Rule 2 (Forward from Status Quo), Rule 3 (Criteria Are Invariants). The quality gate mentions Junior Clarity and Senior Acceptance with no agent-answerability table and no International Readability gate.

**Delivers:** Updated composition rules (Goal First, Status Quo feeds Inputs/Affected Paths, new Constraints rule) and an expanded quality gate with agent-answerability checks and International Readability.

**Out of scope:** Changes to child skills (ST-0236, ST-0237, ST-0238). Template changes (ST-0234). The Done Check line items that mention Demo remain valid because Demo Scenario still exists as section 3.
