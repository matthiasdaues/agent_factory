# Rate each proposal review row with two questions

**Priority:** must-have

## Goal

The proposal-review agent rates each Appendix row it writes in adversarial mode with two questions and ends the Finding cell with a `Severity:` sentence. The proposal template lists the status `waived` as set only by the stakeholder.

## Contract

| Row answers                                                                         | Severity         | Status the agent writes |
| ----------------------------------------------------------------------------------- | ---------------- | ----------------------- |
| `fails_purpose` true: a planner would ask the author or cut a wrong story           | `major`          | `open`                  |
| `fails_purpose` false, `raises_cost` true: the planner can act, a reader pays later | `minor`          | `open`                  |
| both false                                                                          | `note`           | `open`                  |
| any                                                                                 | never `critical` | never `waived`          |

## Demo Scenario

1. The User runs the proposal-review agent in adversarial mode on `docs/proposals/review-loop-cap.md`.
2. A row on an undefined term reads, at the end of its Finding cell, "Severity: major, because a planner would have to ask the author what the cap counts (fails_purpose)."
3. The User opens `packages/factory/rulebooks/templates/proposal.md`. Its Appendix status list holds `waived`, marked as set only by the stakeholder.
