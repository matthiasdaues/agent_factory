# Split brownfield-onboarding into Stage 1 and Stage 2

Restructure `factory/playbooks/brownfield-onboarding.md` into two stages with an explicit exit point between them.

**Stage 1 — Enough to work:** produces three anchor files (`docs/arc42/architecture.dsl`, `docs/spec/scope-map.md`, `docs/CONTEXT.md`). Invokes the reverse-map skill to populate the scope map. Presents the user with a choice to stop or go deeper.

**Stage 2 — Full reverse engineering:** the current Phases 3-6 (specification extraction, component resolution, ATAM review, reconciliation). Opt-in deepening.

**Priority:** must-have

## Acceptance Criteria

- Stage 1 completes when three anchor files exist: `architecture.dsl`, `scope-map.md`, `docs/CONTEXT.md`
- Stage 1 invokes the reverse-map skill for scope-map population
- Structurizr validation passes on the DSL at Stage 1 exit
- The playbook presents the explicit exit message: "You now have the structural shape and the functional inventory. You can start feature work from here. Want to go deeper, or start building?"
- The user can exit after Stage 1 or continue to Stage 2
- Stage 2 contains the current Phases 3-6 unchanged
- No gate marker is written at Stage 1 exit — anchor file presence is the signal
- `spec-lint`, `link-check`, and `mdformat` pass
