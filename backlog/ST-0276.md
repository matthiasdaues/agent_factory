# Retire packages/orchestrator and migrate still-needed tests

After this story ships, `packages/orchestrator/` does not exist, no file in the repository references it, and any tests that covered behavior the factory engine still needs have been migrated.

**Priority:** must-have

## Goal

The `packages/orchestrator/` directory is deleted. Every reference to the orchestrator package in documentation, backlog stories, and CI configuration is removed. Tests from `packages/orchestrator/` that cover behavior the factory engine still needs are migrated to `packages/factory/engine/` or the appropriate test directory.

## Domain Rule

- `packages/orchestrator/` must not exist after this story ships
- No file in the repository may reference the orchestrator package
- Still-needed tests migrate to `packages/factory/engine/` or the appropriate package
- Tests that cover orchestrator-specific behavior not needed by the factory engine are deleted, not migrated

## Demo Scenario

1. Verify `packages/orchestrator/` does not exist in the project tree.
2. Run `grep -r "orchestrator" docs/ backlog/` and confirm no results reference the orchestrator package. (Hits for the word "orchestrator" in the activity-graph proposal context are acceptable; hits referencing `packages/orchestrator/` as a path are not.)
3. Run the test suite. All migrated tests pass under their new location.
4. Inspect `packages/factory/engine/` (or `tests/`). Migrated test files exist and follow the project's existing test naming conventions.

## Demo Data

No seeded data required. The demo uses the existing repository state after ST-0275 (layout consolidation).
