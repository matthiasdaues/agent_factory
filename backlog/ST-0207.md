# Complete fitting with minimal configuration by answering 6 questions and configuring one CLI

Add a `--minimal` flag to the capture-context skill and scope VIRGIL's model-matrix step to the user's active CLI, so a brownfield fitting completes in under 5 minutes instead of 30-60.

**Priority:** must-have

## Demo

The user starts a brownfield fitting. VIRGIL's step 0 asks "Which CLI(s) do you use?" -- the user picks Claude Code and configures 3 tiers instead of 12. Step 2 invokes `capture-context --init --scan --minimal`. The scan runs in full, the interview covers 6 fields (language, backend framework, frontend framework, running locally, testing, branching), and all other fields are written as `deferred: "full context pass pending"`. The user runs `context-lint` and the output is clean. VIRGIL offers: "Want to fill in the rest now, or come back to it later?"

## Acceptance Criteria

- `capture-context --init --minimal` asks at most 6 questions and produces context-lint-clean YAML with all other fields set to `deferred: "full context pass pending"` (design item 1)
- `capture-context --init --scan --minimal` runs the full discovery scan but interviews on only the 6 minimal fields; scan results for non-minimal fields are held, not presented (design item 1)
- `reading-guides.yaml` assembled from `--scan --minimal` prunes concerns whose referenced fields are all deferred (design item 1)
- A subsequent `capture-context --init` or `--init --scan` without `--minimal` detects existing deferred fields and presents only those for completion; already-valued fields are shown for confirmation, not re-asked from scratch (design item 1)
- VIRGIL's fitting step 0 asks "Which CLI(s) do you use?" before walking model tiers; only the selected CLI's three tiers are configured; `fitting.model_matrix_configured` is set to `true` once the active CLI is configured (design item 2)
- VIRGIL's fitting step 2 invokes `--init --scan --minimal` for brownfield and `--init --minimal` for greenfield by default (design item 1)
- VIRGIL offers the full pass as an explicit option after the minimal pass completes (design item 1)

## Scope

**Status quo:** capture-context SKILL.md defines two invocation modes (`--init` and `--init --scan`) with a 19-question interview. VIRGIL's fitting step 0 walks all 4 CLIs x 3 tiers. Step 2 invokes `capture-context` without a `--minimal` flag.

**Adds:**

- New `--minimal` invocation mode in capture-context SKILL.md: `--init --minimal` (greenfield) and `--init --scan --minimal` (brownfield); 6-question interview subset; deferred-field pre-fill; composition semantics with `--scan`; full-pass deferred-field detection for later completion
- VIRGIL step 0 CLI-scoping: "Which CLI(s)?" question before tier walk; only selected CLIs configured
- VIRGIL step 2 default change: `--minimal` by default, with explicit full-pass offer

**Out of scope:** Changes to the 19 questions themselves; configurable question sets; cross-session memory.
