# Create explain-concept skill

Create `factory/skills/explain-concept/SKILL.md` — the skill VIRGIL loads
when a user asks "what is a gate?" or "how do playbooks work?" Looks up the
requested concept in factory documentation and explains it calibrated to
the user's experience level.

**Priority:** should-have

## Acceptance Criteria

- `factory/skills/explain-concept/SKILL.md` exists with valid skill
  frontmatter.
- The skill instructs the agent to look up the requested concept in
  `factory/docs/factory-guide.md` and `factory/INDEX.yaml`.
- The skill calibrates explanation depth to the user's apparent experience
  level: plain language for a junior, precise contract details for a senior.
- If the concept spans multiple guide sections, the skill instructs
  synthesis rather than recitation.
- If the concept is not in the guide, the skill says so.

## Literary Frame

**Lucien** (Gaiman, *The Sandman*) — the librarian of the Dreaming,
who catalogues every book ever written and every book only dreamed of.
The explain-concept skill curates what exists in the factory AND what
could exist but doesn't yet — deferred features, planned skills, the
shape of things the user hasn't built. Look it up, synthesize it,
know where the gaps are.
