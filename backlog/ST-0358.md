# Resolve the surviving mutants a developer agent cannot resolve

**Priority:** must-have

## Goal

A surviving mutant that a developer agent cannot resolve becomes a `QA` finding for the test-strategy agent. After the wave, the test-strategy agent either changes the QA strategy's contract-owner table, or records the missing test and hands the finding to the planning agent.

## Contract

| Operation                             | Input state                                        | Outcome                                                                          | Persistence             |
| ------------------------------------- | -------------------------------------------------- | -------------------------------------------------------------------------------- | ----------------------- |
| `mutation-testing`                    | A mutant the developer agent cannot resolve        | `QA` finding with `owner: test-strategy-agent`                                   | `docs/findings/QA-*.md` |
| Implementation agent, after wave      | Open `QA` finding owned by the test-strategy agent | Dispatches the test-strategy agent                                               | None                    |
| Implementation agent, after wave      | Open `QA` finding owned by the planning agent      | No dispatch of the test-strategy agent                                           | None                    |
| Test-strategy agent                   | The contract sits at the wrong layer               | Contract-owner table changed; finding `resolved`                                 | QA strategy, finding    |
| Test-strategy agent                   | A test is missing                                  | Missing test recorded; `owner:` moves to the planning agent; status stays `open` | Finding                 |
| Merge of the story that adds the test | Open `QA` finding owned by the planning agent      | Finding `resolved`                                                               | Finding                 |

## Demo Scenario

1. The operator files `QA-0003` (Demo Data) after a wave.
2. The implementation agent dispatches the test-strategy agent. The agent records "missing boundary test for an empty path table" in `QA-0003` and moves `owner:` to `planning-agent`.
3. On the next wave, the implementation agent does not dispatch the test-strategy agent for `QA-0003`.
4. The planning agent reads `QA-0003` as a context input and adds the test to a story.

## Analysis

The story turns an unresolved surviving mutant into a `QA` finding and gives each step of its life an owner. Five files change, and one text check covers them (CAO-12-LN-01).

- `packages/factory/skills/mutation-testing/SKILL.md`: the `file-qa-finding` action files `docs/findings/QA-NNNN.md` per the finding format, with `owner: test-strategy-agent` and `status: open`.
- `packages/factory/agents/test-strategy-agent.md`: declares `docs/findings/QA-*.md` as output and context input. A new workflow step picks only the open `QA` findings it owns and resolves each one in one of two ways.
- `packages/factory/agents/implementation-agent.md`: a new step after `close-wave` dispatches the test-strategy agent for each open `QA` finding it owns. The same step sets a planning-agent finding to `resolved` once the story that names it has merged. The agent declares `docs/findings/QA-*.md` for that write.
- `packages/factory/agents/planning-agent.md`: reads `docs/findings/QA-*.md` as a context input and adds each missing test to a story that names the finding.
- `tests/factory/test_core_artifact_ownership_text.py`: the text check.

Scenarios covered: all six Scenarios of the Rule "Test-strategy agent resolves the surviving mutants that a developer agent cannot resolve".

Concerns:

- The developer agent should declare `docs/findings/QA-*.md` as working output (Boundaries). `developer-agent.md` is not in `touches:`, so this story leaves it out.
- The spec names no actor for the last contract row, the merge that resolves the finding. This story gives it to the implementation agent, because it runs the merge.
