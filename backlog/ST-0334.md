# Publish the architecture PDF with the glossary as chapter 12

**Priority:** must-have

## Goal

The project maintainer runs `publish-docs` on a migrated project and finds the
glossary's terms in chapter 12 of the PDF. The manifest needs no change:
wherever it selects `arc42/12_glossary.md`, by name or by glob, the PDF shows
`docs/spec/glossary.md`.

## Contract

| Operation           | Input state                                                                  | Outcome                                                                  | Persistence |
| ------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------------ | ----------- |
| Manifest resolution | Manifest entry `arc42/12_glossary.md`                                        | Resolves to the content of `docs/spec/glossary.md`                       | None        |
| Manifest resolution | Manifest glob `arc42/*.md`                                                   | Chapter 12 resolves to `docs/spec/glossary.md`; other chapters as before | None        |
| Manifest resolution | Manifest without chapter 12                                                  | No glossary in the PDF                                                   | None        |
| `publish-docs`      | Migrated fixture with `docs/spec/architecture.dsl` and `docs/assets/themes/` | PDF builds; chapter 12 contains "Ledger Entry"; manifest unchanged       | PDF file    |
| `publish-docs`      | No `docs/spec/architecture.dsl`                                              | Fails with a message that names `docs/spec/architecture.dsl`             | None        |

## Demo Scenario

1. The maintainer builds the `publish-docs` test fixture with the chapter 12
   addition of Demo Data and runs `packages/factory/scripts/migrate-spec-layout`
   on it.
2. The maintainer runs `packages/factory/scripts/publish-docs pdf` on the
   fixture. It builds the PDF.
3. The maintainer opens chapter 12 of the PDF and finds "Ledger Entry".
4. `git diff` of the manifest file shows no change.

## Demo Data

The story extends the generated fixture of `tests/factory/test_publish_docs.py`.

| File                        | Content                                                              |
| --------------------------- | -------------------------------------------------------------------- |
| `docs/arc42/12_glossary.md` | `# 12. Glossary` and a two-column table with the term "Ledger Entry" |
| Manifest                    | Gains the entry `arc42/12_glossary.md`                               |

  (DEC-11). The relative `theme` line must still resolve inside the build copy.
- `publish-docs` calls the `structurizr` wrapper of ST-0325.
