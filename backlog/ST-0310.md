# Render the build to PDF and stop on any silent failure

**Priority:** must-have

## Goal

The render image turns a build directory into a PDF, or it exits 1 and names
each failed check. A broken diagram, a compile error or a dead link never
reaches a PDF.

## Rule

The [publish-docs proposal](../docs/proposals/publish-docs.md#design) owns the
render image, the page style and the render checks. This story implements
Stages 4 and 5.

## Scope

1. A Dockerfile with Chromium, Node with `playwright-core`, Python with
   PyYAML, `poppler-utils`, and Quarkdown at a pinned version with its SHA-256
   checksum.
2. `render.js`: serve the compiled HTML over local HTTP, wait for Mermaid and
   paged.js, run every render check, print the PDF.
3. The raster check with `pdfimages -list`, counting only rows of type
   `image`.
4. `publish.css` with the house style: 10 pt body type, dotted lines between
   table rows, no diagram shadow.

## Acceptance criteria

- The end-to-end test in [ST-0311](ST-0311.md) covers this story, because
  the render needs the whole command.
- Commits name the story, as `feat: <what changed> (ST-0310)`.
