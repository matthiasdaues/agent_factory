# Start every appendix document on a new page

**Priority:** must-have

## Goal

In the published PDF, the appendix title stands alone on a divider page, and
each appendix document, such as an ADR, begins on a page of its own.

## Rule

Chapters already start on a new page, because Quarkdown breaks the page before
every top-level heading. Appendix documents are demoted one level, so they get
no break. The assembler adds a `.pagebreak` before each appendix document. It
adds none before a chapter, because a `.pagebreak` before a top-level heading
produces a blank page.

## Acceptance criteria

- A unit test checks that `main.qd` has one `.pagebreak` before each appendix
  document and none elsewhere.
- The end-to-end test checks that the appendix title and each ADR title are
  the first text on their pages.
- Commits name the story, as `feat: <what changed> (ST-0312)`.
