# Find a story's behaviour without use-case files

**Priority:** must-have

## Goal

A dispatched developer agent and the reconciliation agent find a story's
behaviour in the scope map and the feature files in `docs/spec/features/`, and
never look for a use-case file. `test-design-verify` finds the feature file of
a story's traced Rule in `docs/spec/features/`.

## Contract

| Operation                           | Input state                                                        | Outcome                                                                               | Persistence |
| ----------------------------------- | ------------------------------------------------------------------ | ------------------------------------------------------------------------------------- | ----------- |
| Developer agent on a story          | Migrated project without `use_cases/`                              | Reads `docs/spec/scope-map.md` and `docs/spec/features/*.feature`; no use-case lookup | None        |
| Reconciliation agent                | Same                                                               | Same reads; no use-case fallback                                                      | None        |
| `test-design-verify --story <file>` | Story traces a Rule whose feature file is in `docs/spec/features/` | Finds the Rule and its Scenarios; exit 0 when the tests cover them                    | None        |
| `test-design-verify --story <file>` | Feature file only at `docs/spec/<name>.feature`                    | Missing-feature-file result, exit 2, as for any missing file                          | None        |

## Demo Scenario

1. In the migrated fixture `story-project` (Demo Data), the maintainer
   dispatches a developer agent on `backlog/ST-0001.md`.
2. The agent's transcript shows reads of `docs/spec/scope-map.md` and
   `docs/spec/features/payments.feature`, and no read under `use_cases/`.
3. The maintainer runs
   `packages/factory/scripts/test-design-verify --story backlog/ST-0001.md` in the
   fixture. It finds the Rule in `docs/spec/features/payments.feature`.

## Demo Data

The agent part runs in a session with a hand-built fixture. The
`test-design-verify` part is covered by a test fixture in `tmp_path`.

| Fixture         | Content                                                                                                                                                                                                                                    |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `story-project` | `docs/spec/scope-map.md` with one row "Merchant receives a payout" pointing at `features/payments.feature`; `docs/spec/features/payments.feature` with that Rule and two Scenarios; `backlog/ST-0001.md` tracing the Rule; no `use_cases/` |
