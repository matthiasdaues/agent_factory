# Integrate charter-lint into validate skill

Add `charter-lint` to the `validate` skill so it runs when a charter exists in the project.

**Priority:** must-have

## Acceptance Criteria

- `validate` skill runs `factory/scripts/charter-lint` when `docs/charter/` exists
- When `docs/charter/` does not exist, the charter-lint step is skipped silently
- Charter-lint findings appear in the validate output alongside other lint results
- The validate skill's existing gate behavior (non-zero exit on errors) applies to charter-lint findings

## Implementation Notes

Conditional execution — the validate skill already handles optional gates (e.g., spec-lint only runs when spec exists). Follow the same pattern for charter-lint.
