# Block agent test commands via block-dangerous-git.sh

Extend `.github/hooks/block-dangerous-git.sh` deny patterns to include bare
test commands (`pytest`, `npm test`, `go test`, `cargo test`, and common
variants) so agents cannot run tests directly (BR-024). Agent attempts receive
exit `2` denial at PreToolUse with a message directing them to
`factory/scripts/run-tests --staged` or hook-triggered execution.

The agent allowlist includes `factory/scripts/run-tests --staged` for test
iteration during development; bare test commands remain blocked.

**Priority:** must-have

## Acceptance Criteria

- `.github/hooks/block-dangerous-git.sh` deny patterns extended with test
  commands:
  - `pytest`
  - `python -m pytest`
  - `uv run pytest`
  - `npm test`
  - `yarn test`
  - `go test`
  - `cargo test`
- Deny patterns are regex-based, matching bare commands and their common
  variants.
- Agent allowlist includes `factory/scripts/run-tests --staged` (explicit
  exception for agent test iteration).
- Denial message for test commands: "Test execution blocked. Tests run via
  hooks only (pre-commit/pre-push/phase advance). For test iteration, use:
  factory/scripts/run-tests --staged"
- Hook exits `2` (denial) when a blocked test command is detected, before the
  command executes.

## Implementation Notes

**Deny pattern additions:**

```bash
# Test execution (agents must not run tests; tests run via hooks only)
# BR-024, ADR-0003
if echo "$cmd" | grep -qE '^(pytest|python -m pytest|uv run pytest|npm test|yarn test|go test|cargo test)'; then
    echo "❌ Test execution blocked. Tests run via hooks only." >&2
    echo "   For test iteration: factory/scripts/run-tests --staged" >&2
    exit 2
fi
```

**Allowlist exception for factory/scripts/run-tests:**

```bash
# Allow factory/scripts/run-tests --staged for agent test iteration
if echo "$cmd" | grep -qE '^factory/scripts/run-tests --staged'; then
    exit 0  # Allowed
fi
```

**Pattern placement:**

Add the deny patterns before the final catch-all, after the existing deny
patterns for destructive git commands. The allowlist check should come before
the deny pattern, so `factory/scripts/run-tests --staged` short-circuits to
allowed.

**Testing the hook:**

Create a test script that attempts:

1. `pytest .` → should be denied
2. `npm test` → should be denied
3. `factory/scripts/run-tests --staged` → should be allowed
4. `factory/scripts/run-tests --full` → should be allowed (hook only runs for
   tool execution, not hook execution)
