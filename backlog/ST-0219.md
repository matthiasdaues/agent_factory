# Rewrite capture-context brownfield mode with documentation discovery and concern-based interview

Rewrite the `capture-context --init --scan` invocation mode so that it discovers existing documentation (handbooks, ADRs, supplementary specs, cookbooks) and proposes additional `Read:` paths per concern through a concern-based interview. The brownfield mode builds on the greenfield mode (ST-0218) by enriching concern sections with discovered documentation.

**Priority:** should-have

## Demo

The user runs `capture-context --init --scan` in a brownfield project that has `docs/handbook/backend/conventions.md`, `docs/adr/`, and `docs/spec/supplementary_specs/entity-model.md`. The skill runs the greenfield scan (detecting stack, proposing cross-cutting and technical concerns) and additionally discovers the handbook, ADRs, and supplementary specs. For the "backend" technical concern, the interview proposes: "I found `docs/handbook/backend/conventions.md` -- add to the backend concern? Anything missing?" The user confirms and adds a cookbook path. The resulting `agent-context.md` has enriched `Read:` paths per concern. `concern-lint` passes.

## Acceptance Criteria

- `capture-context --init --scan` discovers documentation under `docs/handbook/`, `docs/adr/`, `docs/spec/supplementary_specs/`, and cookbook directories.
- Discovered documentation is proposed as `Read:` paths for the matching concern section.
- The concern-based interview walks concerns in category order: cross-cutting first, then technical, then domain.
- For each concern, the interview proposes discovered paths and asks "anything missing?" before moving to the next concern.
- The output `agent-context.md` includes all confirmed `Read:` paths.
- `concern-lint` passes on the output file.

## Scope

**Status quo:** `capture-context --init` produces a greenfield `agent-context.md` with concern sections (ST-0218 deliverables). `capture-context --init --scan` still references the old YAML brownfield process.

**Adds:** Rewritten `--init --scan` mode with documentation discovery and concern-based interview. Interview walks concerns by category. Discovered paths proposed per concern.

**Out of scope:** YAML migration (ST-0220). Greenfield mode changes (already done in ST-0218).

## Notes for the Implementer

The documentation discovery scans for common project documentation patterns: `docs/handbook/**/*.md`, `docs/adr/**/*.md`, `docs/spec/supplementary_specs/*.md`, `docs/spec/*.feature`, cookbook patterns. The interview replaces the old per-field YAML interview with a per-concern interview that confirms names and file lists in batches.
