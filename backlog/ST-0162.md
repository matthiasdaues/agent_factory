# Add test coverage for arc42.projected gating in arch-lint

Create `tests/factory/test_arch_lint.py` with subprocess-based tests that verify arch-lint's behavior under different `arc42.projected` states.

**Priority:** must-have

## Acceptance Criteria

- Test: DSL with `arc42.projected "false"`, no ch5, no images → exit 0, no ERROR findings
- Test: DSL with `arc42.projected "true"`, no ch5 → exit 1, ARCH-MISSING error for ch5
- Test: DSL with `arc42.projected "false"`, no images → no diagram export attempt
- Test: DSL with `arc42.projected "true"`, no images → ARCH-STALE info and export attempt
- Test: DSL with no `properties` block at all, no ch5 → exit 0 (absent treated as false)
- Test: both DSL and ch5 present, `arc42.projected "false"` → coupling check still runs
- Test: ADR check runs regardless of property value
- Test: property parser returns correct values for `"true"`, `"false"`, and absent
- All tests pass in CI (subprocess invocation, no Docker dependency for staleness tests)

## Implementation Notes

- Run arch-lint as subprocess to avoid shebang/import issues
- Use `tmp_path` fixture to create minimal DSL/chapter fixtures
- Mock or use `--no-validate` to skip Docker-dependent structurizr validation
- For staleness/export tests, the export will fail (no Docker in CI) — test that the attempt is made (exit code, output) rather than the export result
