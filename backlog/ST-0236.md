# Add Goal column and Domain Rules subsection to create-backlog-write-epics

Extend the Phase 2 write-epics skill so the building-block inventory includes a Goal column (one sentence of concrete behavior per anticipated story) and each EPIC gains a Domain Rules subsection listing the invariants that govern its stories.

**Priority:** must-have

## Demo

1. Open `packages/factory/skills/create-backlog-write-epics/SKILL.md`.
2. The building-block inventory instruction now reads: "Building-block inventory listing each anticipated story with its capacity tier, day-range estimate, and Goal (one sentence of concrete behavior)."
3. A new instruction paragraph titled "Domain Rules subsection" explains: write a Domain Rules subsection per EPIC listing the invariants that govern the EPIC's stories, seeding each story's Domain Rule section in Phase 4.
4. The Junior Clarity checklist includes a check for the Goal column and Domain Rules subsection.

## Acceptance Criteria

- The building-block inventory description includes a Goal column: one sentence of concrete behavior per anticipated story (agent-ready-story-format.md § Changes to create-backlog-write-epics).
- A Domain Rules subsection instruction exists, requiring a bullet list of invariants per EPIC (agent-ready-story-format.md § Changes to create-backlog-write-epics).
- The Goal column is described as seeding the story's Goal section in Phase 4.
- The Domain Rules subsection is described as seeding each story's Domain Rule section.
- The Junior Clarity checklist checks that the Goal and Domain Rules are present and clear.

## Scope

**Status quo:** `packages/factory/skills/create-backlog-write-epics/SKILL.md` instructs writing a building-block inventory with capacity tier and day-range estimate per anticipated story. No Goal column. No Domain Rules subsection. Demo format is already a numbered step list.

**Delivers:** Goal column in the building-block inventory and a Domain Rules subsection instruction per EPIC. Updated Junior Clarity checklist.

**Out of scope:** Changes to the EPIC slice table format (that table is in create-backlog-epics, Phase 1). Demo format changes (already correct).
