# Thin native CLI adapter smoke suites

Limit Claude, Copilot, and Codex end-to-end tests to adapter-specific payload,
accounting, wiring, and one representative failure path. Shared persistence and
lifecycle behavior belong to their shared owners.

**Priority:** must-have

## Acceptance Criteria

- Record before/after collected cases and lines for all three adapter modules.
- Each CLI retains a happy path, its distinct accounting semantic, and only
  adapter-specific failure/wiring coverage.
- Remove repeated shared-core and lifecycle assertions with links/comments
  identifying their surviving owner.
- Demonstrate one malformed adapter payload is still caught or handled as the
  adapter contract requires.
- The adapter and full suites pass with warnings treated as errors.

## Implementation evidence

Collected adapter cases fell from 13 to 7 and source lines from 946 to 746:

| Adapter     | Before cases / lines | After cases / lines |
| ----------- | -------------------: | ------------------: |
| Claude Code |              8 / 527 |             3 / 362 |
| Copilot CLI |              3 / 234 |             2 / 195 |
| Codex       |              2 / 185 |             2 / 189 |

The surviving suites own only native payload translation, each adapter's
accounting semantics and wiring, plus one malformed/missing-transcript path.
Generic persistence, record reservation, transcript-copy, and lifecycle
contracts point to their owners in `test_usage_capture.py` and
`test_usage_capture_native_lifecycle_e2e.py`.

Fault evidence: each adapter's missing-transcript test invokes the installed
hook with a nonexistent transcript and verifies the adapter absorbs the
malformed input with exit status zero and no stdout. The affected adapter suite
and full suite pass with warnings treated as errors.
