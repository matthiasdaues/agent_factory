# Add arc42.projected property parser and gating logic to arch-lint

Add a `dsl_workspace_property(dsl, key)` function to `factory/scripts/arch-lint` that extracts workspace-level properties from the DSL preamble (before `model {`). Gate the staleness check (diagram export) and missing-ch5 error on `arc42.projected`:

- When `"arc42.projected"` is absent or `"false"`: missing `05_building_block_view.md` is INFO (not ERROR), diagram export is skipped with INFO.
- When `"true"`: behavior is identical to today.
- Coupling check still runs when both DSL and ch5 exist, regardless of property.
- `structurizr validate` always runs (syntax is orthogonal to projection).

Update the module docstring to document the new property.

**Priority:** must-have

## Acceptance Criteria

- `dsl_workspace_property(dsl, "arc42.projected")` returns `"true"`, `"false"`, or `None`
- Parser scopes to the workspace preamble (before `model {`) to avoid matching element-level properties
- When `arc42.projected != "true"`: arch-lint exits 0 with no errors when DSL exists but ch5 and images do not
- When `arc42.projected == "true"`: arch-lint errors on missing ch5 and auto-exports diagrams (unchanged behavior)
- Coupling check runs when both files exist regardless of property value
- ADR check runs regardless of property value
- Module docstring documents the property
