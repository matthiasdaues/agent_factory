# Complete a local installation with diagnosis consent and receipt

**Priority:** must-have

## Goal

A newcomer runs `install-agent-factory --from-local <path> --target <path>` and receives a read-only preflight diagnosis, a preview of planned changes, and an installation receipt after affirmative consent. The bootstrap discovers existing instruction files, prepends one marker-delimited Factory header to each, and records the injection in the install manifest. Blank input at any consent prompt stops the bootstrap without changes.

## Contract

| Operation                                                  | Input state                                                                                                             | Outcome                                                                                                                      | Persistence                                                                  |
| ---------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------------- |
| `install-agent-factory --from-local ./src --target ./proj` | Valid local source, valid target                                                                                        | Preflight reports one of `Ready`, `Ready with limitations`, or `Blocked` without changes                                     | No file changes                                                              |
| `install-agent-factory` with missing `--target`            | No target argument                                                                                                      | Usage message, non-zero exit                                                                                                 | No file changes                                                              |
| `install-agent-factory --from-local --from-remote`         | Two source selectors                                                                                                    | Usage message, non-zero exit                                                                                                 | No file changes                                                              |
| `install-agent-factory --from-local --version 1.0`         | `--version` with local source                                                                                           | Invalid combination reported, non-zero exit                                                                                  | No file changes                                                              |
| `install-agent-factory --from-local ./src --target /`      | Target is filesystem root, user home, or unsupported content                                                            | Unsafe target reported, non-zero exit                                                                                        | No file changes                                                              |
| Preflight on unsupported host                              | Unsupported platform, architecture, or shell                                                                            | Explanation of incompatibility, non-zero exit                                                                                | No file changes                                                              |
| Preflight finds missing prerequisite                       | Supported host, missing tool                                                                                            | Report states purpose, proposed fix, scope, reversal, and verification command                                               | No file changes                                                              |
| Installation preview after preflight                       | Readiness permits installation                                                                                          | Preview shows source, version, target, interfaces, affected paths, instruction files, and uninstall command                  | No file changes                                                              |
| Blank or declined input at consent prompt                  | Preview visible                                                                                                         | Bootstrap stops                                                                                                              | No file changes                                                              |
| Ambiguous interface selection, blank input                 | Zero or multiple detected interfaces                                                                                    | Bootstrap asks again or stops; never selects all                                                                             | No file changes                                                              |
| Approved installation                                      | Affirmative consent after preview                                                                                       | Receipt lists changed paths, selected interface, installed version, resolved source, uninstall command, and one next command | Factory tree installed; `.agent-factory/install.json` updated                |
| Installation with existing instruction files               | Regular `AGENTS.md` or `copilot-instructions.md` outside exclusions                                                     | One marker-delimited Factory header prepended per file with repository-relative links                                        | Headers and original newline state recorded in `.agent-factory/install.json` |
| Repeated installation on same target                       | Headers already present                                                                                                 | No duplicate header added                                                                                                    | Manifest unchanged for existing headers                                      |
| Instruction discovery in excluded trees                    | Files inside `.git/`, `.agent-factory/`, `.current-work/`, dependency trees, virtual environments, caches, build output | Files remain unchanged and are reported accurately                                                                           | No manifest entry for excluded files                                         |

## Boundaries

- All edits go to `packages/factory/`. Never edit `.agent-factory/factory/`.
- The bootstrap delegates to `init-factory` and does not rewrite the existing script.
- `remove-factory` is referenced in the uninstall command but not modified.
- Preflight must not install software, edit files, or run commands with side effects.
- Blank input is never treated as consent.

## Demo Scenario

01. Run `install-agent-factory --from-local ./factory-src --target ./my-project`.
02. Preflight reports `Ready` without changing any file in `./my-project` or the host.
03. The preview shows the source path, version, target, detected interfaces, affected paths, instruction files, and the uninstall command.
04. Approve the installation.
05. The receipt lists changed paths, the selected interface, the installed version, and one next command.
06. Inspect `AGENTS.md` in `./my-project`. A single marker-delimited Factory header is present with repository-relative links.
07. Run `install-agent-factory --from-local ./factory-src --target ./my-project` again and approve.
08. Inspect `AGENTS.md`. No duplicate Factory header appears.
09. Run `install-agent-factory --from-local ./factory-src --target ./my-project` and submit blank input at the consent prompt.
10. Verify that `./my-project` is unchanged.

- [ ] An unsupported host produces an explanation and exits without changes.
- [ ] A missing prerequisite report includes purpose, proposed fix, scope, reversal, and verification command.
- [ ] Blank, declined, or cancelled input at any consent prompt leaves the target unchanged.
- [ ] Ambiguous interface selection asks again or stops; never selects all interfaces.
- [ ] The receipt lists changed paths, selected interface, installed version, resolved source, uninstall command, and one next command.
- [ ] Each discovered instruction file contains exactly one marker-delimited Factory header after installation.
- [ ] Repeated installation on the same target adds no duplicate Factory header.
- [ ] The manifest records each header injection and the original newline state.
- [ ] Instruction discovery skips files inside documented exclusions.

## Stop Conditions

- The documented exclusion list for instruction header discovery is incomplete or ambiguous — report the list and ask for the full exclusion specification.
- `init-factory`'s interface (arguments, exit codes, expected directory state) is unclear from reading the script — report the ambiguity and ask.
- The marker-delimited Factory header format is not specified in the supplementary specs — report and ask.
- The install manifest schema (`.agent-factory/install.json`) needs extension beyond what the existing manifest supports — report what fields exist and ask what to add.
- Code in `packages/factory/scripts/` and the feature spec disagree on argument validation, preflight classification, or consent behavior — report the conflicting files and the decision needed; do not add a workaround.
