# Delete run-tests and mutation-analysis scripts

Delete `factory/scripts/run-tests` (265 lines) and `factory/scripts/mutation-analysis` (518 lines) from the repository. Both scripts encode assumptions about the project's test topology that Factory has no right to make. Deleting them entirely is the only clean resolution because `init-factory` symlinks the entire `factory/scripts/` directory.

**Priority:** must-have

## Acceptance Criteria

- `factory/scripts/run-tests` does not exist in the repository
- `factory/scripts/mutation-analysis` does not exist in the repository
- No consumer project receives either script through the `factory/scripts/` symlink
- `factory/scripts/crap-score` is unaffected and remains functional
- All other scripts in `factory/scripts/` remain functional

## Implementation Notes

- This is a pure deletion story: remove both files, verify nothing else in `factory/scripts/` breaks
- The `crap-score` script analyzes source code structure without invoking any test runner and is unaffected
- Downstream stories (ST-0148, ST-0149, ST-0150, ST-0151) depend on these deletions being in place
