# Print a seed command that continues every ID sequence

**Priority:** must-have

## Goal

The User runs `next-id --plan-seed` in a clone and gets one seed command whose pairs hold the highest number in use of each ID prefix, so every sequence continues after the seed without a jump. When the remote already holds the counter, the mode says so and prints no command. The mode changes no ref and no file.

## Contract

The pairs follow the order of `PREFIXES` in `next-id` (CIFP-C06). Every pair has the form `<PREFIX>=<n>` without leading zeros, as `next-id --seed` already accepts.

## Demo Scenario

1. The User builds the clone `/tmp/plan-demo` of Demo Data and runs `.agent-factory/factory/scripts/next-id --plan-seed` in it. It prints `next-id --seed 0 ST=380 ATAM=14 ADR=32` and a warning that names `docs/findings/ATAM-0014-some-title.md`, and exits `0`.
2. The User runs `git for-each-ref` in `/tmp/plan-demo` and `/tmp/plan-origin.git` and sees the same refs as before step 1.
3. The User copies the printed command and runs it in `/tmp/plan-demo`. Then `next-id ST` prints `ST-0381`, `next-id ADR` prints `ADR-0033`, and `next-id BUG` prints `BUG-0001`.
4. The User runs `next-id --plan-seed` again. It prints that the counter is in use on `/tmp/plan-origin.git` and exits `0`.
5. The User runs `next-id --plan-seed` in the empty clone `/tmp/plan-empty`. It prints `next-id --seed 0`. After that seed, `next-id ST` prints `ST-0001`.

## Boundaries

- `--plan-seed` changes no ref and no file, in the clone or on the remote (BR-098). It reads branches with read-only git commands, such as `git for-each-ref` and `git ls-tree`, and never checks out.
- The remote check reuses the read path of a claim: the same remote order, the same messages, the no-prompt mode, and the time limit of BR-076. It adds no second copy of the remote lookup or the redaction (DEC-07).
- The mode reads only file names in `backlog/`, `docs/findings/`, and `docs/adr/`, the `id` field of each line in `docs/findings/register/*.jsonl`, and lines that start with `## T-NNNN` in `docs/spec/work/todo.md` (BR-099, CIFP-C11). It never reads other body text.
- A file name counts when it starts with a prefix of `PREFIXES`, a hyphen, and digits (BR-100). An ADR file counts when its name starts with four digits and a hyphen (CIFP-C11).
- Standard output holds only the seed command or the in-use line. Each warning goes to standard error and does not change the exit code (CIFP-C10).
- Every remote in a message is redacted (BR-077). No test prints a remote URL or a git config.
- No re-seed of an existing counter and no IDs from branches that are neither local nor fetched. The proposal defers both.
