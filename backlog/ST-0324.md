# Move the terms of every vocabulary file into the glossary

**Priority:** must-have

## Goal

After `migrate-spec-layout` runs, each term of a `CONTEXT.md` with a
`## Language` section is a row in a glossary section named after that file's
title, and no `CONTEXT.md` keeps its `## Language` section. The output lists
every term that appears in more than one section, names the two follow-up
steps, and the script exits 0.

## Contract

| Operation             | Input state                                                                                           | Outcome                                                                                                                  | Persistence                      |
| --------------------- | ----------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------ | -------------------------------- |
| `migrate-spec-layout` | `docs/CONTEXT.md` titled "Billing" with `## Language` in the list form                                | Section "Billing" in `glossary.md`; each `_Avoid_:` entry in its term's Avoid cell; `## Language` removed                | Glossary edit, `CONTEXT.md` edit |
| `migrate-spec-layout` | `docs/arc42/CONTEXT-MAP.md` lists "Ledger" with `packages/ledger/CONTEXT.md`, which has `## Language` | Section "Ledger" in `glossary.md`; `## Language` removed from that file                                                  | Two edits                        |
| `migrate-spec-layout` | "Invoice" in `docs/CONTEXT.md` and in chapter 12                                                      | Both rows kept in separate sections; output lists "Invoice" as a duplicate; exit 0                                       | Glossary                         |
| `migrate-spec-layout` | `docs/CONTEXT.md` without `## Language`                                                               | File unchanged                                                                                                           | None                             |
| `migrate-spec-layout` | No chapter 12 and one `CONTEXT.md` with terms                                                         | `glossary.md` created with that one section                                                                              | New file, staged                 |
| `migrate-spec-layout` | Run ends with work done and `CONTEXT-MAP.md` present                                                  | Output names `capture-context --fold-context-map` and the cleanup of duplicate terms, for example with `domain-modeling` | None                             |
| `migrate-spec-layout` | A step fails after a `## Language` removal                                                            | Every `CONTEXT.md` and the glossary as before; exit 1                                                                    | Restored                         |

## Demo Scenario

1. The maintainer copies the fixture `old-layout-vocabulary` (Demo Data) into
   `/tmp/demo` and runs `packages/factory/scripts/migrate-spec-layout /tmp/demo`.
   It exits 0.
2. `docs/spec/glossary.md` has the section "Billing" with rows for "Invoice"
   and "Customer"; the Avoid cell of "Invoice" reads `Bill, payment request`.
3. The output lists "Invoice" as a term in more than one section, then names
   `capture-context --fold-context-map` and the cleanup of duplicate terms.
4. `grep -n '## Language' /tmp/demo/docs/CONTEXT.md /tmp/demo/packages/ledger/CONTEXT.md`
   finds nothing.

## Demo Data

The story extends the fixture helper with one fixture, built on

| File                         | Content                                                                                                                                               |

## Boundaries

- Two vocabularies never stop the script. It keeps both, lists the duplicates,
  and exits 0 (DEC-18).
- No definition and no `_Avoid_:` entry is dropped.
- A `CONTEXT.md` without `## Language` holds routing only and stays unchanged.
- The script never deletes a `CONTEXT.md` or `CONTEXT-MAP.md`. The fold does
  that work (E4).
- A `CONTEXT.md` with `## Language` counts as work for the no-work rule.
- Every edit joins the undo journal.

## Out of Scope

## Agent Stop Conditions

- A `CONTEXT.md` has a `## Language` section that is not in the template's list
  form. Report the file and the form; do not guess a conversion.
- The context map names a per-context `CONTEXT.md` path that does not exist.
  Report it; do not create the file.

## Resolve Before Implementation

1. Format of the duplicate listing. Default: the same stream and line form that
   ST-0321 records, one line per term:
   `duplicate term: <term> in <section>, <section>`.
2. Where the two follow-up steps print when the run has no duplicates.
   Default: the fold step prints whenever a `CONTEXT-MAP.md` or a routing-only
   `CONTEXT.md` remains; the cleanup step prints only when the listing has a
   duplicate.
