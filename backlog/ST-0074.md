# Create charter document templates

Create three charter templates under `factory/rulebooks/templates/`. Each template is the skeleton of its charter document — headings with one-line HTML comment prompts describing what belongs in each section. The prompts are HTML comments so they disappear from the finished document.

**Priority:** must-have

## Acceptance Criteria

- `factory/rulebooks/templates/charter-tech-stack.md` exists with sections: Languages & Runtimes, Frameworks, Data Stores, Infrastructure, Existing Systems, Licensing & Exclusions
- `factory/rulebooks/templates/charter-development.md` exists with sections: Repository Layout, Getting Started, Running the Project, Testing, Linting & Formatting, CI/CD, Branching
- `factory/rulebooks/templates/charter-house-rules.md` exists with sections: Commits & PRs, Review & Approval, Testing Discipline, Architecture Governance, Scope & Boundaries
- Each section contains an HTML comment prompt describing what belongs there
- Empty sections contain "To be decided." as placeholder text
- YAML frontmatter parses cleanly on all three templates

## Implementation Notes

The templates define the structure that `charter-lint` validates against and `capture-charter` scaffolds from. Refer to the proposal's Design section for detailed descriptions of each section's purpose and example content.
